# 需要 CW 书面确认的问题清单

> **原则**：即使我们通过调研、SPS 文档或行业惯例能确认，只要 CW 没写清，就通过 Tracy 问 CW，
> 并保留书面回复。罚款与流程以合同/合规指南为准，不以行业惯例为准。

状态说明：⬜ 待问 / 🟡 已问待回 / ✅ 已书面确认
