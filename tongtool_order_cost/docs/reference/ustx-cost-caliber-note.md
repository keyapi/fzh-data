# 美中仓库二次加工成本口径变更说明

> 数据：2026 年 7 月通途订单，美中仓库 **4,379 行**（`发货仓按销售汇总分类 = USTX分公司`）。
> 全部为**只读测算**，未改动任何线上数据。
> 底稿：`tongtool_order_cost/out/profitability_audit/2026年7月订单_ustx_ustx_compare_*/{audit.xlsx, 管理摘要.md}`。

## 1. 现在是什么口径

美中仓库（`FZH-DANEEY` 系列、`美中-FZH-DANEEY` 系列、`WayfairCG-McDonough仓` 等 9 个仓）
在成本表里挂的加工来源是 **`2CJG-SX`（绍兴）**，所以它们的「二次加工成本」这一栏，
记的是**绍兴的加工费**，不是美中当地的加工费。美东（`2CJG-US`）、波兰（`2CJG-PL`）各走各自的当地加工。

## 2. 变更后是什么口径

美中改走**当地 USTX 加工**，取数来自 EN 的成品 BOM（`importBOMCostList` 的「美中加工成本, USTX」＝美中包装成品 BOM 的 `total_cost`）；
并且按「绍兴发货方式」补上绍兴侧的包装成本：
半成品补 `绍兴包装半成品成本`、成品补 `绍兴包装成品成本`、皮壳不补。

## 3. 全月差额（仅美中，按发货数量加权，单位 ￥）

| 成本项 | 现状 A | 测算表口径 B1 | 变更后 B2 | 差额 B1−A | 差额 B2−A |
|---|---:|---:|---:|---:|---:|
| 皮壳成本 | 231,530 | 231,530 | 231,530 | 0 | 0 |
| 头程运费 | 52,666 | 52,666 | 55,910 | 0 | +3,244 |
| 二次加工成本 | 242,029 | 468,658 | 468,011 | +226,629 | +225,982 |
| 绍兴二次加工成本 | 0 | 0 | 38,930 | 0 | +38,930 |
| **合计** | **526,225** | **752,854** | **794,381** | **+226,629** | **+268,156** |

**一句话**：美中若改走当地加工，7 月这四个成本项合计从 **52.6 万** 升到 **79.4 万**（+26.8 万，+51%）。

## 4. 差额来自哪里

| 来源 | 金额 | 说明 |
|---|---:|---|
| 加工费本身变贵 | ≈ +22.6 万 | 现状用的是绍兴加工费（单价十几到几十），变更后用的是美中包装成品 BOM 的成本（单价两百上下） |
| 补了绍兴包装成本 | +3.9 万 | 半成品/成品发货时，EN 会额外把绍兴的包装半成品/成品成本算进去，现状这一栏整列是 0 |
| 头程重量口径 | +0.3 万 | 头程按「皮壳重量」重算，与订单现值有小差 |
| 皮壳成本 | ≈ 0 | 两种口径下皮壳成本基本一致 |

## 5. 需要财务/业务确认的点

1. **美中的二次加工成本该用哪套数**：绍兴加工费（现状）还是美中当地包装 BOM 成本（变更后）？
   两者相差约 22.6 万/月，是本表最大的一项。
2. **半成品/成品发货是否要补绍兴包装成本**：EN 的口径是补，现状是没补。这是 +3.9 万的来源。
3. **头程重量基准**：现在按「皮壳重量」算；若美中半成品应按「半成品重量」算，头程还会再变（本次尚未取到半成品重量数据）。
4. **工资口径**：EN 美中包装工站的工资计划从 **167.8 降到 105**（截至本说明撰写时**尚未调整**）。
   一旦落地，变更后的加工成本会**下降**，本表的 +22.6 万会相应缩小——建议按调整后的价目重算一版。

## 6. 表的口径说明（供交叉核对）

- **A 现状**：直接取订单表内四项现值。
- **B1 测算表**：把美中「二次加工成本」换成财务已建的 `测算 美中USTX二次加工成本`（取最新月度列）；
  该表缺的行用变更后公式补，并标来源（`measured` / `formula_filled` / `unmatched`）。
  **注意**：这张测算表的月度值是**人工填的**，不是公式算出来的，所以它和「变更后」是两套不同的数，差异属正常。
- **B2 变更后**：四项都按 import 表重建。
- 覆盖情况：变更后口径命中 4,328/4,379 行；未命中 51 行、3 个仓库/品类键存在歧义，均已单列在底稿中（不猜值）。
