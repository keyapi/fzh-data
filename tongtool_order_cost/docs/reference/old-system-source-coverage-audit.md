## 结论摘要

1. **「皮壳成本平均…（用于通途订单202502）」与 `绍兴二次加工成本`、`import皮壳成本` 三张表，在本次快照下对 7 月订单的
   `品类尺寸面料编码` 覆盖率为 100%（订单用到 332 个键，0 缺失；美中分支 177 个键，0 缺失）。**
   这与「这些表经常不全、每月要手工补行」的体感不一致，见「未证实 / 存疑」第 1 条。
2. **真正缺行最严重的源是 `测算 美中USTX二次加工成本`（新表的现成原型）**：
   对订单 332 键缺 **115（34.6%）**，对美中 177 键缺 **77（43.5%）**，折算 **1146 行订单（占美中 26.2%）** 取不到值。
   成因是**行本身不存在**（该表 621 行 `品类尺寸面料编码` 100% 已填，不是回填问题）→ **新规格未维护**。
3. **缺口第二大类是「编码列未回填 / 命名不一致」，不是缺行**：
   - 头程 `美国分公司USTX头程运费核算` 按 `品类尺寸面料编码` 看缺 78 键（23.5%），但其中 **77 键在表内有对应行**，
     只是该行的「品类尺寸面料编码」列为空，用 `(品类尺寸编码, 面料)` 复合键即可命中；**真正缺行的只有 1 个键**。
   - `品类尺寸编码` 作为**独立键不可用**：所有源表都缺 30%~40%（如 `绍兴二次加工成本` 缺 66/201＝32.8%），
     原因是源表该列大量留空、且存在 `KS0316-55`（订单侧）↔ `XZH-HS-006-C-55`（源表）这类**编码体系不同**。
     匹配必须走 `品类尺寸面料编码`。
4. **「头程运费合并」是所有源里最全的一张**：订单 332 键 0 缺失，美中 177 键 0 缺失。
5. 另有 **19 个被 7 月订单用到的键**在 `import皮壳成本` 里**有面料键但 `EN重量模板物料号` 为空**，
   构成 `面料键 → 重量模板 → BOM 成本表` 的**断链**（BOM 表的 EN 覆盖走不到这些键）。

### 判定口径

- **覆盖率按唯一键算**，不按行（同一键多行只计一次）；同时给出**行级影响面**作为补充。
- 缺失键按下列三类归因（不猜）：
  - **真缺行（新规格未维护）**：源表内既无该键，也无 `(品类尺寸编码, 面料)` 对应的行。
  - **编码列未回填（可 rematch）**：源表内**有**对应行，但该行的 `品类尺寸面料编码`（或 `品类尺寸编码`）列为空。
  - **命名不一致**：归一化（NFKC + 去空白 + 大写，重量模板另把 `x` 视同 `*`）后可对上。
- 源表全部**只读**：本地 CSV 快照 + gspread `get_all_values()`。

## 对「新建美中USTX二次加工成本表」的行完整度要求

以本次 7 月订单为基准（**单位=唯一 `品类尺寸面料编码` 键**）：

| 要求档位 | 需覆盖键数 | 说明 |
|---|---:|---|
| **下限（美中自用）** | **177** | 美中分支 7 月实际用到的键。低于此值就有订单取不到值 |
| **推荐（含其它分支复用）** | **332** | 四分支（除美国海外仓无键外）合计用到的键，可避免「同一张表被其它分支引用时又缺」 |
| **对齐既有主表** | **868 ~ 881** | `import皮壳成本` 868 键 / `绍兴二次加工成本` 881 键。与之等宽可 1:1 join，`import皮壳成本` 是 BOM 成本链路的上游 |

**增量**：现有 `测算 美中USTX二次加工成本` 有 615 行，要到「推荐 332 键」需补 **115 行**，
要到「美中下限 177 键」需补 **77 行**，要跟 `绍兴二次加工成本` 等宽需补 **约 266 行**。

**列的要求（比行更重要）**：

1. **必须同时填 `品类尺寸面料编码` 与 `品类尺寸编码` 两列**。
   现状反例：`绍兴二次加工成本` 903 个有面料键的行里只有 704 行填了 `品类尺寸编码`（22% 空），
   直接导致任何按 `品类尺寸编码` 的连接缺 32.8%。新表两列都要有值。
2. **必须带 `EN重量模板物料号`（或等价重量模板编号）**，否则 EN 侧 BOM 覆盖断链
   （现在有 19 个被订单用到的键就断在这里）。
3. **月份列命名沿用 `<指标>多月YYYYMM` + `<指标>系数多月YYYYMM` + `<指标>*系数多月YYYYMM` 三件套**
   （老系统硬编码月份列名；缺系数列时代码按 `系数=1.0` 兜底，`*系数 = 值`）。
4. **`品类尺寸面料编码` 不要留空**（头程核算表的教训：57% 的行该列为空，只能靠复合键补救）。

**键的写法要求**：`面料` 编码段与 `品类编码` 段必须与 `import皮壳成本` 完全一致
（如 `SX-KZSJ-100-DM`、`KS0398-100-HM`），不要出现 `- 140*50*24` 这类空格/乘号变体。
