# gsheet 源头错误根因诊断

> **⚠️ 本页更正 [26](26-answers-to-28-rows.md) §6 的判断。** 26 §6 断言「637 行指到 `KS0364` 是 gsheet 错误、应删/改」。**EN 反证该判断是错的** —— `ZLMB#KS0364-…` 对它那一行（床头靠枕）**本就是对的**。真因是**键撞车**，见下。

## 0. 先把链路钉死：改 `import皮壳成本` 是没用的

| 层 | 工作簿 / ws | 事实 |
|---|---|---|
| **显示层** | `二次加工成本2022 / import皮壳成本` | **A1 = `=IMPORTRANGE("15CjWsxoYt8fKtJaJIAdT-G_l6T6-2Np8hWtdh82vysk", "皮壳成本平均202409-202410-202411（用于通途订单202502）!E:F")`** ⇒ A/B 两列**整体是拉过来的**，本地改会被下次刷新覆盖 |
| **源层** | `财务部绍兴成本核算表单2023`（id `15CjWsxo…`）/ `皮壳成本平均202409-202410-202411（用于通途订单202502）` | **唯一可改点**。源表列：`A品类 B面料 C尺寸 D品类尺寸编码 E品类尺寸面料编码 F EN重量模板物料号 …` ⇒ **E:F 就是 `import皮壳成本` 的 A:B** |
| 旁证 | 同工作簿 `/ 品类使用面料`（品类→品类编码）、`/ 材料价格明细`（面料→材料编码） | `E = D + "-" + 面料码`；`D = 品类编码 + "-" + 尺寸` |

**结论：任何修正都必须落在 `财务部绍兴成本核算表单2023` 的源 ws 上，改 `import皮壳成本` 无效。**

## 1. 三个样例的精确根因

### 1.1 `TT0312576K0064149` — 真因 = **键撞车（品类编码被两款产品共用）**

**EN 一对一反证（决定性）**：

| `ZLMB#` 模板 | EN item_name | EN 归属品类 |
|---|---|---|
| `ZLMB#KS0364-XNEOSTH-153x65` | 重量模板#**欧式床头靠枕**-米白滚边吊穗款-雪尼尔欧式提花-**153x65cm** | **KS0364** |
| `ZLMB#KS0423-XNEOSTH-153x65x23` | 重量模板#**欧式米白滚边吊穗大靠背**-…-**153x65x23cm** | **KS0423** |

**两个模板都对**（各归属自己的产品）。问题在**键**：

```
品类使用面料 行247: 欧式床头靠枕-米白滚边吊穗款 → 品类编码 KS0423   ← 疑错
品类使用面料 行299: 欧式米白滚边吊穗大靠背       → 品类编码 KS0423   ← 与 247 撞车
```
⇒ 两张不同的脸共用 `KS0423` ⇒ 键 `KS0423-153-XNEOSTH` 在皮壳表里出现 **2 次**：

```
皮壳表 行637: 品类=欧式床头靠枕-米白滚边吊穗款   E=KS0423-153-XNEOSTH   F=ZLMB#KS0364-XNEOSTH-153x65     ← 键 0423 / 模板 0364（不自洽）
皮壳表 行702: 品类=欧式米白滚边吊穗大靠背         E=KS0423-153-XNEOSTH   F=ZLMB#KS0423-XNEOSTH-153x65x23 ← 键 0423 / 模板 0423（自洽）
```
大靠背订单（SKU 含 `153x65x23`）解析出 `KS0423-153-XNEOSTH` ⇒ 命中两行；Colab `drop_duplicates('品类尺寸面料编码')` **取第一行** ⇒ 若取到 637 → 拿 **0364 模板**（185.55），取到 702 → 拿 **0423 模板**（103.78）。

**系统性同形**（同批创建的三款，都撞车）：

| 床头靠枕（品类） | 品类使用面料给的码 | EN 真实码 | 大靠背（品类） | 共用码 |
|---|---|---:|---:|---|
| 欧式床头靠枕-**蓝色**滚边吊穗款 | KS0425 | **KS0366** | 欧式蓝色滚边吊穗大靠背 | KS0425 |
| 欧式床头靠枕-**米白**滚边吊穗款 | KS0423 | **KS0364** | 欧式米白滚边吊穗大靠背 | KS0423 |
| 欧式床头靠枕-**腰果花**吊穗款 | KS0424 | **KS0365** | 欧式腰果花吊穗大靠背 | KS0424 |

> **旁证（同类行已"迁移过"）**：皮壳表 行634/635（蓝滚边床头靠枕）用的键是 `YHX-HS-002-*`、行638/639（腰果花床头靠枕）用 `YHX-HS-003-*` —— **不是** 0425/0424。**只有米白（636/637）没迁**，仍扛着大靠背的 `KS0423` ⇒ 更像**漏改**，不是有意合并。

**实测影响（当前温和）**：7 月写回表 `TT0312576K0064149` 三行 → 键 `KS0423-153-XNEOSTH` → `二次加工成本=98.56`。`98.56 ≈ 103.78×系数` ⇒ **当前拿到的是 0423 模板（对）** ⇒ **本单此刻没错，但键撞车是未爆的雷**（取决于 `drop_duplicates` 取到谁）。

### 1.2 `TT0031054K0062974` — 真因 = **表里成本引用错误（F 列跨产品）**

```
订单产品名: 中控台车载狗窝 无光磨砂绒 棕色 45*22*27CM
订单键    : RD-YM-pet-006-45-WGMSR          ← 与「品类使用面料/材料价格明细」自洽（中控台车载狗窝=RD-YM-pet-006；无光磨砂绒=ML-WGMSR）
皮壳表行453: E=RD-YM-pet-006-45-WGMSR  F=ZLMB#KS0234-KJB-45
EN          : ZLMB#KS0234-KJB-45 = 重量模板#中控台车载狗窝【四季款】-【科技布】-45X22X27cm
```
- 订单键**没错**（品类/面料都对得上）。错在 **F**：把「中控台车载狗窝（`RD-YM-pet-006` / 无光磨砂绒）」指到了**另一款**「中控台车载狗窝**四季款**（`RD-YM-pet-017` / 科技布）」的模板。
- 佐证：`品类使用面料` **行103** `中控台车载狗窝 → RD-YM-pet-006 / 无光磨砂绒`；**行145** `中控台车载狗窝四季款 → RD-YM-pet-017 / 科技布` —— 是**两个码、两个面料**。
- EN 侧 `KS0234` 只搜到 `KS0234-KJB-45-BROWN`（科技布），**没有** WGMSR 变体 ⇒ 要么面料改过（无光磨砂绒→科技布）、要么 F 指错。**需业务确认哪边为准**（本页不猜）。
- 排除项：**不是** Colab 解析错（键对）、**不是** 品类使用面料错（行103 对）。

### 1.3 `TT0312705K0064584` — 键与皮壳表**自洽**，无表错

```
订单产品名: 鹅卵石套装 全涤针织磨毛布 6件套 深灰混搭
订单键    : SX-STH-SET6-YLR
皮壳表    : E=SX-STH-SET6-YLR  F=ZLMB#KS0251-YLR-SET6
EN        : ZLMB#KS0251-YLR-SET6 = 重量模板#深浅灰石头抱枕-摇粒绒-6件套
EN变体    : KS0251-YLR-SET6-DEEPGREYMIX = …-6件套-【深灰混搭】 ← 与产品名「深灰混搭」吻合
```
- 键/模板**自洽**，EN 变体后缀「深灰混搭」也吻合 ⇒ **表没错**。差异只在**显示名**（产品名「鹅卵石套装」vs EN 品类「深浅灰石头抱枕」）。
- 7 月写回表该单 `二次加工成本 = 0`（不是 26 §2 写的 101.07）⇒ **26 §2 的「卖价 101.07」数字需作废/重查**。

## 2. 结论：这三例**都不是 Colab 解析错**

| 样例 | 订单键 | 错在哪 | 归属 |
|---|---|---|---|
| TT0031054K0062974 | ✅ 对 | 皮壳表 **F 列**跨产品 | **表里成本引用错误** |
| TT0312705K0064584 | ✅ 对 | —（自洽） | 无 |
| TT0312576K0064149 | ✅ 对 | **品类使用面料** 品类编码撞车（连带皮壳表键重复） | **gsheet 数据源错误** |

## 4. 为什么**先不写**（风险）

1. **这是财务编码主表**，被多张表 / 多个月 / Colab 全局 IMPORTRANGE 引用；改 3 行品类编码 + 2 行键，影响面**不止这三个订单**。
2. **前提被推翻**：26 §6 说"删 637"，EN 证明 637 的 F 是对的 ⇒ 动手前需让**业务确认这不是有意合并的产品族**（虽然旁证倾向"漏改"）。
3. 原表**已多处内部不一致**（蓝滚边/腰果花用 `YHX-HS-00X`，米白用 `KS0423`）⇒ 单点改动可能只把不一致挪个地方。
4. 已备份三张表到 `~/.claude/backups/gsheet/财务部绍兴成本核算表单2023__*.csv`（2026-10-17），可回滚。

**建议**：把 §3 清单交给业务确认「A+B 按 EN 改」后执行；同时**在 Colab/新链路侧加"键→多模板必须阻断/报错、不得取第一行"的闸**（不改键也能止血）。
