## 结论摘要

- **主键三段的公式**（cell_066 L1552-1562 / cell_141 L1325-1335，两处逐字相同）：
  - `品类尺寸编码 = 品类编码 + '-' + 尺寸`
  - `品类尺寸面料编码 = 品类尺寸编码 + '-' + 材料编码.replace('ML-','')`（材料编码为空则退化为 `品类尺寸编码`）
- **三段的权威来源各不相同**：
  | 段 | 权威来源 | 落点 |
  |---|---|---|
  | **品类编码** | GS `品类使用面料`（品类→品类编码）+ `产品用料工时明细`（品类尺寸编码反推品类编码） | cell_004 / 009 / 032；订单侧 cell_066 L1549 |
  | **尺寸** | 从「产品名称」正则提取 + 大量特例改写（**不来自 GS**） | cell_066（4.2） / cell_141（4.7.2） |
  | **面料** | GS `材料价格明细`（材料名称→材料编码，只取 `材料类别=='面料'`） | cell_012 / 018 / 020；订单侧 cell_066 L1536-1542 |
- **两条订单路径并存、逻辑统一**：**4.2 = cell_066（非 FBA 订单）**，**4.7.2 = cell_141（FBA 订单）**；
  注释「20230105 统一 4.2 4.7.2」出现 8 次，4.7.2 直接复用 4.2 里定义的 `str_fabric_name`/`fabric_list_sorted`/`extract_txt_by_priority`（cell_141 L482/L490）。
- **推导链是闭合的**（在「品类」能被提取出来的前提下）：`产品名称 → 品类 → (品类使用面料) 品类编码`；`产品名称 → 尺寸`；
  `产品名称 → 面料提取 → (材料价格明细) 材料编码` → 三段拼出 `品类尺寸面料编码`。**但仍是「拼接 + 硬编码改写」的启发式，
  不是纯查表**；大量边界靠条件改写兜。
- **海绵（HM）特例**分三层：品类层（弧形+海绵→弧形海绵）、面料提取层（`海绵` 被强制排到候选末位，让它「只在没别的面料时才命中」）、
  物料层（`材料价格明细` 里 `面料/海绵→ML-HM`，键尾缀成 `-HM`）。

### 尺寸提取主流程（cell_066，行号为 cell_066 物理行）

1. **去品类**：L949 `产品名称去除品类 = [a.replace(str(b),'') for a,b in zip(产品名称, 品类)]`（字面替换）。
2. **清噪声**：L956-960 依次删 `^\d+\.`、`;\s*\d+\.`、`\d{5,}`（≥5 位数字，如 TBA 单号）。
3. **首个数字**：L971 `尺寸 = 产品名称去除品类.str.extract(r'(\d+(?:\.\d+)?)(?!\s*件套)')` —— 取第一个整数/小数，**但不取「件套」前的数**。
4. **带 `*` 尺寸**：L1032 `带*尺寸 = 产品名称.str.extract(r'(\d+(?:\.\d+)?[\*|X|x|×]\d+(?:\.\d+)?[\*|X|x|×]?\d+(?:\.\d+)?)')`；L1035 分隔符统一成 `*`。
5. **先大后小排序**：L1066-1078 `sort_size()`（float/int 区分、逆序）→ `尺寸先大后小`。
6. **默认取最大**：L1095-1100 `尺寸 = 尺寸先大后小.split('*')[0]`，**排除** `ls_cat_size_no_large_first = ['弧形PP棉靠枕-拉链款','弧形海绵靠枕-拉链款']`。
7. **取长×宽（去分隔符）**：L1110-1111 品类含 `方形有扣|车载宠物窝|长方形枕套` → `str[:2].str.join('')`。
8. **整串保留**：L1133-1145 产品名称含 `长方|床品|防雨罩|里程碑` → 用完整 `尺寸先大后小`，
   **排除** `儿童泡沫攀岩块` 与 `ls_cat_size_no_large_first = ['长方形枕套','弧形PP棉靠枕-拉链款','弧形海绵靠枕-拉链款']`（L1131 覆盖了 L1093 的旧清单）。
9. **猫吊床**：L1150 → 取最后一个数字 `(\d+$)`（如 120*...*50 → 50）。
10. **件套 → SETn**：L1166-1182 `尺寸 = 'SET'+件套数`，**排除** `欧式床头靠枕-花边款`（L1178）。
11. **创意床品**：L1186-1209 美版 → `美版5尺寸(Twin|Full|Queen|King|CaKing) + 件套`；欧版 → `尺寸先大后小` 去 `*` + 件套。
12. **狗床**：L1226-1228 品类含 `长方形狗床|拐角狗床|狗护膝|狗狗出行辅助带` → 提取 `M|XXL|XL|L`。
13. **手工指定**：L1232-1245 `科技布系列抱枕→SET4`、`多功能猫窝→101.5`、`毛毡猫隧道→44.5`、`冥想垫(上垫+下垫)→SET2`。

> **`尺寸` 只从「产品名称」来**：L984-993 曾尝试用 `规格` 列兜底，**整段被注释**，实测「实际没有作用」。
> 另有 cell_066 内的尺寸硬编码改写：三角新面料 138→140、床楔形枕头 150→153、云仓沙发产品/颈椎枕头→`0`、五件套靠枕 65→60；

## 海绵特例

海绵在这套引擎里有 **三层**独立处理，缺一层结果就不同：

### ① 品类层：`弧形* + 海绵 → 弧形海绵`（cell_066 L458-507；cell_141 L336-368 同构）

顺序是**先默认、后覆盖**：

```python
# 默认：含"弧形"一律先当 弧形PP棉
df_order.loc[产品名称或原品类含'弧形','品类'] = '弧形PP棉'              # L461-462
# 覆盖：同时含"弧形"和"海绵" → 弧形海绵（注释：'错误！品类不应该都是 弧形海绵'）
df_order.loc[(含'弧形') & (含'海绵'),'品类'] = '弧形海绵'              # L480-483
df_order.loc[(含'拉链款') & (品类=='弧形海绵'),'品类'] = '弧形海绵靠枕-拉链款'  # L486-487
df_order.loc[(产品名称含'圆柱颈枕弧形海绵靠枕'),'品类'] = '圆柱颈枕弧形海绵靠枕'  # L490-491
df_order.loc[(含'三角') & (含'碎海绵'),'品类'] = '三角靠枕(碎海绵款)'   # L494-495
```
另有 `海棉→海绵` 错别字修正（L35-36）。**注意 L476 的自述坑**：「带有『海绵』字样的**不都是**『弧形海绵靠枕』」
—— 作者自己标注该规则过宽，故 L479-483 用 `含弧形 AND 含海绵` 收紧（尤其狗床产品名也可能带「海绵」）。

### ② 面料提取层：`海绵` 排在候选末位（cell_066 L624-628）

注释原文：「`海绵` 需要放在 `cat_list_sorted` 排序的最后，**防止 面料没提取，却先提取了海绵**」。
含义：一个产品名若同时含真面料与「海绵」，优先命中真面料；只有**没有**任何真面料时才落到「海绵」→ 材料编码 `ML-HM` → 键尾缀 `-HM`。

### ③ 物料层：`面料/海绵 → ML-HM`（`材料价格明细`，2026-10-16 只读）

| 材料类别 | 材料名称 | 材料编码 | 用途/备注 |
|---|---|---|---|
| **面料** | 海绵 | **ML-HM** | 「弧形海绵靠枕-拉链款 填充物 海绵，松饼大沙发-放大版」 |
| 填充物 | 海绵 | HM-HX45 / HM-HX60 | 「海绵弧形靠枕多出海绵？分成45和60」 |
| 填充物 | 海绵 | HM-DOGM/L/XL/XXL | 狗床长方形 M/L/XL/XXL |
| 面料 | 海绵复合面料 | ML-HMFHML | 便携收纳U形枕 |

**与旧键 `HM` 的关系**：`HM` 是**海绵语义**。品类编码里也带它——`品类使用面料` 中 `弧形海绵靠枕 → SX-KZHX**HM**`
（拉链码注释亦为 `KZHXHM-45/-60`）。因此「HM」在旧键里同时出现在**品类段**（`SX-KZHXHM`）
和**面料段**（`-HM`）两处，正是 [13-codex-review-corrections.md](13-codex-review-corrections.md) §5.3 所说
「`HM` 是旧键里的海绵语义，不是 EN 整件面料」的由来。
> ⚠️ **只有 `材料类别=='面料'` 的 `ML-HM` 参与拼键**；`填充物` 的 `HM-HX45` 等**不参与**（订单侧 merge 显式过滤 `材料类别=='面料'`）。
