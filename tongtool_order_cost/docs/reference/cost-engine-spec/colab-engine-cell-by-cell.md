## 结论摘要

- **总公式**（cell_211 L378-401、cell_125 L378-401）：
  `1件产品成本 = 皮壳成本 + 绍兴二次加工成本 + 二次加工成本`；
  `订单总成本 = 产品成本*数量 + 头程运费*数量 + 运费 [+ 海外仓成本*数量]`；
  `订单利润 = 售价*汇率 − 订单总成本`。`*系数` 轨结构相同，只是各列换成 `*系数` 列。
- **主联合键**：`品类尺寸面料编码 = 品类尺寸编码 + "-" + 材料编码.replace("ML-","")`；
  `品类尺寸编码 = 品类编码 + "-" + 尺寸`。EN 侧等价键 = `重量模板编号`（并入订单时更名 `EN重量模板物料号`）。
- **成本仍在本引擎（Colab + GS）算、未被 EN 接管的**：皮壳含/不含包装成本（由 BOM 工时+材料+人工日常费现算）、
  头程运费金额（GS 表 + 可选 EN 替换）、二次加工成本/绍兴二次加工成本（GS 表 + 可选 EN 覆盖）、
  海外仓成本_USHWC / FBA成本_USFBA（GS 表，只统计不参与），尾程 `运费`（通途导出列）。
  **已被 EN 覆盖的**：`皮壳成本`、`绍兴二次加工成本`（半成品/成品两档）、`头程运费金额`（EN 列名对照后替换）。
- **开关**：本 notebook 里可数的"用户可切换"开关约 **13 个**（见 §6 表）；其中最关键 3 个：
  `option_head_source`（头程用 GS 原始还是 EN 替换）、`if_use_EN_cost_sxbzbcp`/`if_use_EN_cost_sxbzcp`
  （绍兴二次加工成本以 EN 半成品/成品成本为准）、`if_use_test_cost`（是否用测算成本改编码）。
- **"未启用 / 自述坑" 条目**：本文标出 **17 处**（含大段被 `"""..."""` 注释掉的 deprecate 段、`mask_EUHWC`「暂未用到」、
  `if_delete_fangyuzhao`、`内胆真空袋`「202206未计算入成本」等），见 §8。
- **大量历史硬编码**（品类/面料/尺寸的条件改写、含年月的工作表名、渠道账号别名替换）散布在
  cell_034 / 066 / 108 / 141 / 192 中，逐条列在 §6。

1件产品成本      = df[['皮壳成本','绍兴二次加工成本','二次加工成本']].sum(axis=1)
