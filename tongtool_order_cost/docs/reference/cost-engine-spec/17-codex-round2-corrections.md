## 2. 公式更正：歧义必须**阻断取值**，不是「加个标记」

原写法只做了「搜对列」，**仍会在歧义键上取到某一条**。正确形态：

```
取 wt  →  若 MATCH 命中数 ≠ 1 → 返回 ""（并在「取数来源」列标 ambiguous）
        →  否则再判 缺失 / 字面 0 → 取 INDEX(U:U, ...)
```

**要点**：**「标记列」是给人看的，「公式本身不取值」才是闸门**。两者都要有，不能只加标记。

> 并结合 [16](16-customer-sku-direct-path.md)：**若改用「通途SKU → 客户物料号」路径，本公式整块弃用**（不再两跳）。

## 3. 建表隔离（执行级）

| 风险 | 说明 |

| **名字撞车** | notebook **按名字自动读**工作簿里的 ws；若新表叫「美中USTX二次加工成本」并放回 `二次加工成本2022`，**会被自动读到**——「不启用」是假隔离 |

**处置**：① 放**独立工作簿**；或 ② 用**加载器明确排除**的测算表名（现有 `cell108` 排除含「测算/import」的页）；或 ③ 建好后**先不进任何被读的工作簿**。
