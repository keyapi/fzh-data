# 规则列 → 订单列

## 系数 (coeff)

| 规则列 | 目标列（= 备份 × 系数） |
|--------|-------------------------|
| 销售额系数 | 售价*汇率 |
| 皮壳成本系数 | 皮壳含包装成本, 皮壳不含包装成本, 皮壳成本, 皮壳成本*数量, 皮壳成本*系数, 皮壳成本*系数*数量 |
| 绍兴二次加工成本系数 | 绍兴二次加工成本及相关*数量/*系数 |
| 二次加工成本系数 | 二次加工成本及相关 |
| 头程运费系数 | 头程运费金额, 头程运费*数量 |
| 海外仓成本系数 | 海外仓成本, 海外仓成本*数量 |
| 尾程运费系数 | 运费 |

## 参考值 (ref)

`￥单件 = 参考值 × 汇率`；数量列 = ￥单件 × 发货数量。

| 规则列 | 单件列 | 数量列 |
|--------|--------|--------|
| 发货数量1皮壳成本*系数参考值 | 皮壳含包装成本, 皮壳不含包装成本, 皮壳成本, 皮壳成本*系数 | 皮壳成本*数量, 皮壳成本*系数*数量 |
| 发货数量1绍兴二次加工成本*系数参考值 | 绍兴二次加工成本, 绍兴二次加工成本*系数 | 对应*数量 |
| 发货数量1二次加工成本*系数参考值 | 二次加工成本, 二次加工成本*系数 | 对应*数量 |
| 发货数量1头程运费参考值 | 头程运费金额 | 头程运费*数量 |
| 发货数量1海外仓成本参考值 | 海外仓成本 | 海外仓成本*数量 |
| 发货数量1订单尾程运费 | — | 运费（自发货始终写入；FBA 仅当参考值 < 0 时写入账期差异，正数/0 跳过以免与账期重复） |
