## 2. 目标（ZJ 要的）

衡量 **3 家各自的「工人工资率」与「管理费率」是否合理**。方法：

```
① 用 7/8/9 月通途自发货订单 × 各国外包装成品 BOM 的工序，模拟出
   每家每月的【理论工时 H_model】
② 财务：实际工人工资 W / H_model   → 实际工资率，与表 1 的 hour_rate_labour 比
   财务：实际管理成本 M / H_model   → 实际管理费率，与表 1 的 hour_rate_manage 比
③ 另：PP棉用量也用同样方法模拟，与财务实际棉用量/棉金额比
```

## 3. 模拟公式（逐行可复现）

**理论工时**（单位：小时）：

```
H_model(分公司, 月) = Σ_{订单行} 发货数量 × ( Σ_{该行 BOM 的工序} time_in_mins / 60 )
```

- BOM 取该产品的**国外包装成品** BOM（`USTXBZCP#` / `USNJBZCP#` / `PLBZCP#`），条件 `is_active=1 AND is_default=1 AND docstatus=1`。
- `time_in_mins` 取 `tabBOM Operation.time_in_mins`；**注意**：国外 BOM 的工时 = 绍兴 × 分公司系数（PL/USNJ=1、USTX=1.5），系数配置在 `Manufacturing Settings.foreign_branch_time_multipliers`。
- **不得**把同一成品拆包裹的多行重复计（见 `30-design-merge-split-no-double-count.md`）。

**PP棉用量**：

```
PP_model(分公司, 月) = Σ_{订单行} 发货数量 × BOM 内 item_group='PP棉' 行的 qty
```
（国外成品 BOM 为**单行、全 PP棉**；用量与绍兴 1:1。）

## 5. 先行诊断：**管理费率与"工人反推工时"不自洽**（供 ZJ 预警）

若用「工人 ÷ 工资率」反推工时（**仅为诊断，非最终口径**），再乘现行管理费率：

```
现行费率应发管理 = hour_rate_manage × (工人 / hour_rate_labour)
```

> ⇒ **现行 `hour_rate_manage` 明显低于实际管理负担**（美中≈4×、美东≈16×）。**但这只是"工人反推工时"的诊断**，**最终须用 ② 的 `H_model` 重算**——若 `H_model` 显著大于"工人反推工时"，差距会缩小。**这正是本轮要算 H_model 的原因。**

## 6. 计算步骤（执行）

1. 取 7/8/9 月通途自发货订单（按分公司分类），**先按拆包裹合并规则合成成品行**，避免重复计。
2. 每行查其**国外包装成品 BOM** → 工序 `time_in_mins` 求和 /60 × 数量 → 累加得 `H_model`。
3. 同时取 PP棉行 qty × 数量 → `PP_model`。
4. 与财务实际相除，得**实际 vs 现行** 的偏差表（逐家逐月）。
5. 缺口行按 `overseas_gap_classified.csv`：**Manufacture 无 BOM 的 42 行**需先补；**Purchase 28 行**不参与（无国外加工）；**EN 查无 32 行**待修映射。

## 7. 校验点（必做）

- 抽样 3 个产品，手算 `Σ time_in_mins` 与脚本一致。
- 同一成品多包裹行**只计一次**（件数 = Σ皮壳行）。
- 分公司系数：USTX 的工时 = 绍兴 × 1.5（实证 `KS0001-100` 10.584 → 15.876）。
