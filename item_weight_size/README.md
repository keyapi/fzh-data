# item_weight_size — 赛狐商品重尺导入

将 EN 重量模板中手工填写的国外发货尺寸重量数据，按 SKU 前 3 段（品类-面料-尺寸）匹配到赛狐全部 SKU，生成赛狐「商品重尺」导入文件。

## 背景

- 赛狐需要导入商品的国外发货尺寸重量（用于尾程物流如 UPS/FedEx）
- ERPNext 刚添加了国外发货重量尺寸自定义字段，但数据尚未填充
- 同事从 ERPNext 下载重量模板，手动填写了 5 个字段
- **重量模板**：不含颜色（前 3 段相同 = 重尺一致），物料编码前缀 `ZLMB#`

## 管道

```
赛狐商品导出（SKU 列）──── 提取匹配键（前3段）──┐
                                              ├── left join ──→ 校验 + 字段映射 ──→ 输出
彭建重量模板（物料编码等）── 去除 ZLMB# 前缀 ──┘
```

## 匹配规则

- 重量模板 `ZLMB#KS0368-CTTM-270x180x60` → 键 = `KS0368-CTTM-270x180x60`
- 赛狐 SKU `KS0368-CTTM-270x180x60-BLACK`（4 段）→ 键 = `KS0368-CTTM-270x180x60`
- 键相同的 SKU 共享该重量模板的重尺数据

## 使用方法

```bash
cd item_weight_size
python build_saihu_weight_import.py

# 指定文件
python build_saihu_weight_import.py \
  --weight-data "彭建已填 重尺数据.xlsx" \
  --saihu-export "商品导出 填重尺.xlsx" \
  --template "模板 商品重尺.xlsx"
```

## 数据源与输出

| 角色 | 默认位置 | 说明 |
|------|----------|------|
| 重量数据 | `./数据源/`（文件含「重尺数据」） | 同事手工填写的 xlsx |
| 赛狐导出 | `./数据源/`（文件含「商品导出」「填重尺」） | 赛狐下载的 SKU 全量 |
| 模板 | `./数据源/`（文件含「模板」「商品重尺」） | 赛狐导入模板 |
| 输出 | `out/` | 主结果 + 问题报告 |

若目录中多个文件，取修改时间最新的。

## 输出文件

- `赛狐_商品重尺导入_YYYYMMDD_HHMMSS.xlsx` — 模板格式，2214 行全量 SKU，工作表名 `商品`
- `重尺处理_问题报告_YYYYMMDD_HHMMSS.xlsx` — 4 类报告

## 校验规则

| 规则 | 行为 |
|------|------|
| 长宽高不全 | 不填充该重量模板对应的任何 SKU |
| 装箱量缺失 | 长宽高都有值时默认 1 |
| SKU 无匹配 | 对应行全部留空 |
