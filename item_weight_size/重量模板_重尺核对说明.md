# 重量模板 · 重尺数据核对说明

> 关联改动：产品物料库（vilavi_pim `item_group_browser`）成本表 FBM/FBA 的「箱规」取值口径调整。
> 用途：把重量模板里的重尺数据（外包装 / 单个包装 / 单重）导出成表，供业务同事核对，并复现系统联动算法。

## 一、重量模板是什么

- 物料编码：`ZLMB#{型号}-{面料}-{尺寸}`（**不含颜色**，同型号+面料+尺寸共享一份重尺）
- 物料组：`重量模板#<品类>`（如 `重量模板#三角靠枕`）
- 承载的数据：皮壳/成品/半成品**单重**，以及**外包装**和**单个包装**的长宽高、体积。

## 二、外包装 → 单个包装 的联动规则（系统自动计算）

来源：`light_mes/public/js/item.js`（Item 表单的 `handle_outer_logic` / `calculate_volume`）。

```
单个包装长 = 外包装长
单个包装宽 = 外包装宽
单个包装高 = 外包装高 ÷ 外包装内数量
体积       = 长 × 宽 × 高
```

- **触发条件**：外包装 长/宽/高 **均 > 0** 且 **内数量 > 0**。满足时系统写入单个包装并置为只读；不满足时（外箱缺失/为 0）单个包装字段**可手工填写**。
- 半成品（sfg）用同一套规则，字段前缀为 `custom_sfg_`。
- 校验用 `ROUND(...,6)` 比高，避免浮点误差。

字段对照：

| 含义 | 成品 | 半成品 |
|---|---|---|
| 外包装长/宽/高 | `custom_outer_package_length/width/height` | `custom_sfg_outer_package_length/width/height` |
| 外包装体积 | `custom_outer_package_volume` | `custom_sfg_outer_package_volume` |
| 外包装内数量 | `custom_quantity_per_outer_package` | `custom_sfg_quantity_per_outer_package` |
| 单个包装长/宽/高 | `custom_package_length/width/height` | `custom_sfg_package_length/width/height` |
| 单个包装体积 | `custom_package_volume` | `custom_sfg_package_volume` |
| 皮壳/成品/半成品单重 | `custom_cover_weight_per_unit` / `custom_fg_weight_per_unit` / `custom_sfg_weight_per_unit` | 同左 |

## 三、产品物料库「箱规」取值口径

产品物料库成本表的「箱规」取值（`vilavi_pim/.../item_group_cost_service.py` → `_attach_carton_fields`）：

| 分组 | 箱规字段 |
|---|---|
| **FBA**（目的仓 USFBA/DEFBA/UKFBA/JPFBA） | **单个包装** 长/宽/高（`custom_package_*`） |
| **FBM** 皮壳 / 成品 | **单个包装** 长/宽/高（`custom_package_*`） |
| **FBM** 半成品 | **半成品单个包装** 长/宽/高（`custom_sfg_package_*`） |

> 头程运费 = `Logistic Price.actual_weight_rate`（该目的地单价）× 对应计费重量；箱规是运费的「重尺依据」。

## 四、导出工具

`export_weight_template_dims.py` —— 从 ERPNext 拉取全部重量模板，生成带联动公式的 xlsx。

```bash
cd item_weight_size
python export_weight_template_dims.py            # 默认 --env prod
python export_weight_template_dims.py --env test # 测试环境
```

**凭证**：从 `.env` 读取 `PROD_ERP_API_KEY / PROD_ERP_API_SECRET`（查找顺序：`item_weight_size/.env` → 仓库根 `.env` → `EN_API/.env`）。`.env` 已被 `.gitignore` 排除，**请勿提交**。

**输出**：`out/重量模板_重尺数据_YYYYMMDD.xlsx`（`out/` 已被 gitignore）。

三个 Sheet：

| Sheet | 内容 |
|---|---|
| 重量模板数据 | 数据库**原值** + 末尾两列「校验」。冻结 A~I 列（编号/名称/物料组/单重），可按「物料组」筛选，如 `重量模板#三角靠枕` |
| 重尺联动（可编辑） | 黄色格为输入（外包装长/宽/高、内数量，初值取自库），**单个包装各列与体积为公式**；改外箱或数量即自动重算（复刻系统联动）。冻结 编号+物料名称 |
| 说明 | 规则与口径 |

**「校验」列取值**（核对用）：

| 取值 | 含义 |
|---|---|
| `OK` | 库里存的「单个包装」与联动规则**一致** |
| `不符` | 与规则**不一致**（可能手工改过，或改了外箱但没重算） |
| `不适用` | 外包装 或 内数量 有缺失（为 0），规则**不触发**，单个包装是**手工填写**的——这类值没有规则背书，**排查重点** |
