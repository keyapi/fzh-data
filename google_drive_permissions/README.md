# Google Drive 权限管理 — 使用指南

> 本文给人（非 Agent）看。Agent 请直接读 [AGENT_HANDOFF.md](AGENT_HANDOFF.md)。

## 这是什么

一套把 Google 表格（spreadsheet）和 Colab notebook 的**共享权限**管起来的能力。能：
- 查清某账号在哪些表有权限、某表被谁共享；
- 给同事加编辑/只读权限，或取消离职/不需要的人；
- 把文件托管给**服务账号**，让自动化不依赖会 7 天过期的登录凭证。

## 数据在哪

所有共享关系都汇总在 **Google Sheet 权限台账**（一个在线表格）：
https://docs.google.com/spreadsheets/d/1TTVVHQOe5VCmdLZynGFAKXSPUVIvtlB6kOOqgszIqD0

它有两个表：
- **账号主清单**：一账号一行，标了「在职/离职/自己/服务账号」和「保留/清理/不取消」，是**决策依据**。
- **现状明细**：一文件×一账号一行，标了「电子表格 / Colab」，是**底账**。

> 注意：这些含同事邮箱的明细**只存在这个在线表格里**，不会进 git 仓库，避免泄露隐私。

## 日常怎么用

**1. 想看谁有权限** → 打开台账，看「现状明细」，按账号或按文件名筛。

**2. 要给同事加权限** → 告诉他邮箱 + 想要的权限（只能读 `reader` / 可编辑 `writer`）+ 涉及哪几个表。交给 Agent，读台账后台自动加。

**3. 离职的人要清理** → 台账「账号主清单」里把该账号的「处理方式」改成 `清理`。Agent 据此批量执行移除。

**4. 想让自动化长期跑** → 把文件分享给服务账号。这样脚本不依赖某人登录，可长期运行。

## 为什么服务账号能长期用、而你登录会过期

- **服务账号**：是个"程序身份"，用**私钥**认证，只要不删就长期有效。缺点是只能看你**明确分享给它**的文件。
- **你手动登录的授权**：是"本人身份"，能看**你所有**文件，但外部应用处于测试期时，授权**7 天就过期**。
- 所以：固定业务表用服务账号管；要全盘审计就用你自己登录的凭证，但留意过期时间。

## 安全提醒

- 表里全是同事邮箱，**别转发、别截图外传**。
- 加权限前先确认对方是**在职**。不确定就看「账号主清单」的状态。
