# 负责人按变化折叠；Amazon 只建国家站

1. **不要按月插 Owner 行。** 表有 `运营人员202511`…`运营人员202608`。同一人连续多个月只对应 EN 一条 `from_date`。2026-08-25  naive 月切 367 行，折叠后 189 行。
2. **开卖后的空格子不是「跳过」。** 用户要求写成 `待分配`（例如 `WMRongnuoUS` 202608、`WMJunyuanUS` 从 202606）。开卖前的空月才跳过。
3. **Amazon 没有欧洲站这个粒度。** 用户明确 EUR 非法。拆法抄 Johna 九国。Wayfair `WFEU` 不要套用这条。
4. **生产写被 IDE 拦截时，先看 canary HTTP 状态，再要本机批准。** 不要把拦截当成 EN 校验失败。
5. **中文名继续写。** 包括 `&` 组合名。不要「纠正」成邮箱。
