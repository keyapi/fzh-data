# 预测/补货方法调研综合（Codex + Claude，2026-11-12）

> 两份独立调研：`FORECAST_RESEARCH_CODEX_20261112.md`（18 来源）、`FORECAST_RESEARCH_CLAUDE_20261112.md`（36 来源）。以下只保留双方一致或证据充分的结论；分歧/未证实单列。

## 1. 计划窗：不是 97/157，也不是 7/30 倍数

**一致结论**：硬约束是 **覆盖累计交期 L + 复盘周期 R**（Oracle/Infor/Microsoft time fence）。没有权威来源要求预测窗必须是 7/30 的整数倍；周/月倍数是展示与评估口径，不是计划理论。

- 97 天 = 13.86 周，157 = 22.43 周，都不是整周；按周汇总时末周不完整。
- 波兰 L≈100.6 天 > 97；中国线 L≈71.5 天，97 够。
- **建议规则**：`H_key = ceil((L_p90 + R + buffer)/7)×7`，R=7 天，buffer≥7 天；标准展示桶 **98（14 周）/154（22 周）**，需要 23 周用 **161**；季度用 **91（13 周）**；波兰单独 **112（16 周）**。
- **157 的来源**：项目里没有文档依据；只能说它是“5 个月敏感性”。不应机械改成 154/161 来解决春节；实际终点由供给日历决定。

## 2. 春节：建“供给日历 + bridge 窗”，不是拉大需求窗

**一致结论**：成熟做法是 **pre-build/build-ahead + 停工日历 + 两批排产 + 节后爬坡**，把春节当“临时交期延长”，不是需求尖峰。

- 工厂日历：1/24–2/22 产能 0；2/22–3/8 爬坡 30–50%；3/15 后 100%（用本厂 2024–2026 实际曲线校准）。
- **Bridge 窗** = 停工开始 → **首批复工货到目的地 + 1 个复盘期**：
  - 波兰：2/22 + 43.6 + 2 + 55 ≈ **2027-06-02**（约 212 天）；
  - 中国线：2/22 + 71.5 ≈ **2027-05-04**（约 183 天）。
- 97 天到 2/07、157 天到 4/08，**都不够**；157→161 也只多 4 天，解决不了 6 周真空。
- **Pre-build 量** = `q_α(bridge 需求) − 停工开始时在手 − 停工前可到在途 − 停工前已确认 PO`；α 按 Q4 服务档（A 类 97.5–98%）。
- 下单节奏：最终生产单 11 月中前；12 月中前确认出货；节前 bridge 批 + 节后补货批。

## 3. 分位与服务：q95 的问题比模型更大

**关键**：`q95` 只有在“分位窗口 = 风险窗（L+R）”时才对应 95% CSL。固定 97 天会导致：
- 短交期键（L+R≈35 天）实际 CSL 远高于 95%，**压库存**；
- 波兰键（L+R≈108 天）q95(97) 反而**低于** 95% CSL，**欠库存**。

**建议**：
- 分位窗口改为每键的 **L+R**；H 只用于计划/汇总。
- 服务档：用 **95/90/85 作为政策先验**，但公开资料只支持“90–98% 常见、85% 对 C/Z 慢销合理”，**不是业界标准**；建议 A 97.5–98、B 95、C 90、D 85 或 fill-rate，季度用回测校准。
- 季节/新品：newsvendor 临界比 `Cu/(Cu+Co)`；间断品：fill-rate 目标。
- **不要 cap q95/p50 或 sigma**（无标准，且 p50=0 会爆炸）；用业务上限（A 类安全库存≤8–12 周均值、C 类≤16–20 周）或金额上限；校准用 PIT/覆盖率，不调 sigma cap。
- CSL≠fill rate；95% CSL 通常对应 98–99% fill。

## 4. 模型：naive 不是病，adopted 不一致才是病

**一致结论**：FVA 的逻辑就是“打不过 naive 就用 naive”；naive 占比高本身不是错。真正的 bug 是 **`3_分类.adopted_model` 与 `4_回测_asof.adopted` 不一致**（4 个墙围键中 2 个用错）。

**建议**：
- D4 产出**唯一 selection 表**（key, origin, h, model, params, metric, FVA, reason），D3b 只 join，不再自己算；pipeline 断言 `D3b.model == D4.model`，否则 fail closed。
- 候选集补 **ETS(A,Ad,N)、ETS(A,A,A)/STL+ETS、Theta**；间歇品 Croston/SBA/TSB；LightGBM/ensemble 只作聚合/高量挑战者。
- 回测：rolling origin、expanding、至少 12–18 个 origin；selection 在 validation，最终 6 个月 holdout 只评估不选择；按 horizon 报 WAPE+pinball+覆盖率；FVA≥5% 且 ≥60% origin 胜出才采用。
- 区间：经验残差分位或 conformal；不要用正态假设外推 Croston/SBA 的 97 天分位。

## 5. 趋势/情景：必须逐产品，不能一刀切

- 全量 D3b 键 2026 年 1–10 月同比：**down>30% 652 键、down10–30% 162、stable 115、up10–30% 58、up>30% 272、无 2025 基数 263**。
- 墙围 6 个 SKU：5 个同比 **−31% 到 −58%**，1 个 +13%；q95 仍受 2025 峰值影响，456 vs 66 主要是趋势/模型问题，不是真实销量差 7 倍。
- 建议：先做 STL/ETS(A,Ad,A)/Prophet 趋势诊断（damped trend），按产品/segment 生成 **base/upside/downside + 概率 + 触发条件**；触发看近 4–8 周 sell-through、同比、weeks of cover、广告转化；不统一砍 -20/-30%。
- 新闻 60–70% 备货是行业媒体样本，不是平台统计；Adobe 预计线上 +6.7%、Amazon 招 30 万临时工，信号矛盾。
