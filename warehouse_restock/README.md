# warehouse_restock — 赛狐海外仓备货单导入

EN BOM Cost List → 三成本拆分 → 赛狐海外仓备货单导入。

## 快速运行

```bash
cd warehouse_restock
python build_saihu_warehouse_restock.py
```

## 管道

```
EN BOM成本列表 → 成本借用(同重量模板) → 三成本拆分(绍兴/头程/加工)
    → 通途仓库映射(SKU出现在哪个仓) → 赛狐SKU白名单
    → 填入海外仓备货单模板 → 输出
```

## 成本映射

| EN BOM 拆出 | → | 赛狐模板列 | 公式 |
|-----------|---|------|------|
| 绍兴发货成本 | → | `指定采购单价` | 直接填入 |
| 头程运费 | → | `物流费用` | × 1000（赛狐自动除以数量） |
| 国外加工成本 | → | `其他费用` | × 1000 |

## 关键决策

- 通途仓库判定：SKU 出现在仓库就算（含库存=0）
- 备货数量：1000（安全冗余，避免订单无法标记发货）
- 头程/税费分摊方式：统一"自定义"
- 重尺/规格列：留空（已有数据）
- 移动模板到 `warehouse_restock/数据源样例/` 下

## 数据源

| 文件 | 说明 |
|------|------|
| `EN产品BOM成本列表*.xlsx` | ERPNext BOM Cost List 导出 |
| `通途合并库存结存清单*.xlsx` | 通途库存结存页面导出 |
| `商品导出*.xlsx` | 赛狐商品管理页导出（SKU 白名单） |
