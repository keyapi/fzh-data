# warehouse_restock — 赛狐海外仓备货单导入

EN BOM Cost List → 三成本拆分 → 赛狐海外仓备货单导入模板。

## 管道概要

```
EN BOM成本列表 → 成本借用(同重量模板) → 三成本拆分(绍兴/头程/加工)
    → 通途仓库映射(SKU出现在哪个仓，通途SKU清理已知后缀) → 赛狐SKU白名单过滤
    → 填入海外仓备货单模板(三格式可选) → 输出
```

## 赛狐模板写入规则

用 `--fmt` 控制输出格式：`1`/`2`/`3`/`all`。**默认 `--fmt=2`**。

### 格式 2（默认，`_2加工并入采购.xlsx`）

| 模板列 | 列号 | 公式 | 说明 |
|--------|------|------|------|
| `指定采购单价` | 13 | 绍兴发货成本 + 国外加工成本 | |
| `*备货数量` | 14 | 1000 | |
| `单个头程费用` | 20 | 头程运费 | col 20，不是 col 15! |
| `物流费用` | 16 | 留空 | |
| `其他费用` | 17 | 留空 | |

> 赛狐显示：采购单价=绍兴+加工，头程费用=纯头程。销售负责人要求单独看头程。

### 格式 1（兼容，`_1三成本分开.xlsx`）

| 模板列 | 列号 | 公式 |
|--------|------|------|
| `指定采购单价` | 13 | 绍兴发货成本 |
| `物流费用` | 16 | 头程运费 × 1000 |
| `其他费用` | 17 | 国外加工成本 × 1000 |
| `单个头程费用` | 20 | 留空（赛狐自动算） |

> 赛狐自动计算 `单个头程费用 = (物流费用+其他费用+税费)/备货数量`。

### 格式 3（兜底，`_3三成本全并入采购.xlsx`）

| 模板列 | 列号 | 公式 | 说明 |
|--------|------|------|------|
| `指定采购单价` | 13 | 绍兴+头程+加工 | 三成本全累加 |
| `单个头程费用` | 20 | 留空 | |
| `物流费用` | 16 | 留空 | |
| `其他费用` | 17 | 留空 | |

> 背景：Amazon 订单标记发货后利润明细只有采购成本无头程费用（可能是赛狐 bug）。三成本全灌入采购单价可保利润不偏。

### 公共列

| 模板列 | 列号 | 值 |
|--------|------|-----|
| `*收货仓库` | 2 | CENTRADE / DANEEY / POLAND |
| `*头程分摊方式` | 3 | 自定义 |
| `*税费分摊方式` | 4 | 自定义 |
| `*SKU` | 10 | 赛狐 SKU |
| `*备货数量` | 14 | 1000 |
| `店铺` / `FNSKU` 等 | — | 留空 |

## 成本拆分逻辑

按 `绍兴发货方式` 分三条路径:

| 方式 | 绍兴发货成本 | 头程运费 | 国外加工成本 |
|:---:|---|---|---|
| 皮壳 | 皮壳成本 | 头程皮壳运费 | 对应仓库加工成本 |
| 半成品 | 皮壳成本 + 绍兴包装半成品成本 | 头程半成品运费(0时用皮壳) | 对应仓库加工成本 |
| 成品 | 绍兴总成本 | 头程成品运费 | 0 |

`split_cost_for_row()` 返回三个原始单价（不×1000），×1000 在格式1的 `_fill_single_file` 中处理。

详见 `docs/bom_cost_explanation.md`

## 通途仓库映射规则

通途库存结存清单中，**只要 SKU 出现在某个仓库（哪怕库存=0）**，就认为该 SKU 在此仓有售。

### SKU 后缀清理

通途 SKU 可能被人工添加后缀（如 `TT0031128K0063817-淘汰`），匹配 BOM 客户物料号时两边都剥离已知后缀再比较：

```python
KNOWN_SKU_SUFFIXES = ["-淘汰"]
```

- 匹配用清理后 SKU，**输出到赛狐仍用 BOM 原始 SKU**
- 新增后缀加入 `KNOWN_SKU_SUFFIXES` 列表即可

## 成本借用

同 `重量模板` 内的 SKU，同一成本列中 0/空值 被同组非 0 最大值替换。
借用范围：皮壳成本、绍兴包装成本、绍兴总成本、头程运费列、加工成本列。

## 赛狐导入规则（实测）

- **单个备货单 ≤ 500 条**（弹窗未注明，赛狐内部校验，超过全部失败）
- 总计 ≤ 5000 条
- 超过 500 条需拆批次（不同临时单号，脚本自动拆）
- 临时单号可选（单批导入时），多批需各自不同
- 同一备货单整体成功或失败，不同备货单互不影响
- 模板 2 行表头 + 7 sheet（4 hidden Data Validation）
- **去重**：同 (SKU, 仓库) 只保留一条（BOM 多客户物料号→同赛狐 SKU 导致重复）

## 踩坑

### 坑 1：500 条隐藏限制
赛狐弹窗未注明单个备货单上限，导入 852 条全部失败。错误信息"单个备货单商品数量不能超过500个"。

### 坑 2：去重后才能导入
同一赛狐 SKU 通过多个通途客户物料号映射到同仓，产生重复行。赛狐报"同一备货单下存在相同的SKU"。

### 坑 3：BOM 列名分隔符
BOM Excel 列名用 `, ` （逗号+空格）分隔。脚本需用 `norm_col` 统一标准化。

### 坑 4：通途 SKU 人工后缀
通途 SKU 可能被人加 `-淘汰` 后缀，导致与 BOM 客户物料号匹配不上。
修复：`_clean_sku()` 两边剥后缀再 match（见上）。
