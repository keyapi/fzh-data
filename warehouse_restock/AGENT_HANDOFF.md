# warehouse_restock — 赛狐海外仓备货单导入

EN BOM Cost List → 三成本拆分 → 赛狐海外仓备货单导入模板。

## 管道概要

```
EN BOM成本列表 → 成本借用(同重量模板) → 三成本拆分(绍兴/头程/加工)
    → 通途仓库映射(SKU出现在哪个仓) → 赛狐SKU白名单过滤
    → 填入海外仓备货单模板 → 输出
```

## 赛狐模板写入规则

| 模板列 | 公式 | 说明 |
|--------|------|------|
| `*收货仓库` | CENTRADE / DANEEY / POLAND | 按通途出现判断 |
| `*头程分摊方式` | 自定义 | 不启用赛狐自动分摊 |
| `*税费分摊方式` | 自定义 | |
| `*SKU` | 赛狐 SKU | |
| `指定采购单价` | 绍兴发货成本（单价） | |
| `*备货数量` | 1000 | 安全冗余 |
| `物流费用` | 头程运费 × 1000 | 总金额，不是单价 |
| `其他费用` | 国外加工成本 × 1000 | 总金额，不是单价 |
| `单个头程费用` | 留空 | 赛狐自动算: (物流+其他+税费)/数量 |
| `店铺` / `FNSKU` | 留空 | 共享库存 |
| 其余列 | 留空 | |

### 赛狐隐含分摊逻辑

赛狐自动计算 `单个头程费用 = (物流费用 + 其他费用 + 报关税费) / *备货数量`，
因此填物流费用/其他费用时需 × 备货数量。

未来如果确认赛狐订单里不能分开显示头程和加工成本，可简化为只填 `单个头程费用 = 头程运费 + 国外加工成本`，
物流费用/其他费用留空。

## 成本拆分逻辑

按 `绍兴发货方式` 分三条路径:

| 方式 | 绍兴发货成本 | 头程运费 | 国外加工成本 |
|:---:|---|---|---|
| 皮壳 | 皮壳成本 | 头程皮壳运费 | 对应仓库加工成本 |
| 半成品 | 皮壳成本 + 绍兴包装半成品成本 | 头程半成品运费(0时用皮壳) | 对应仓库加工成本 |
| 成品 | 绍兴总成本 | 头程成品运费 | 0 |

详见 `docs/bom_cost_explanation.md`

## 通途仓库映射规则

通途库存结存清单中，**只要 SKU 出现在某个仓库（哪怕库存=0）**，就认为该 SKU 在此仓有售。
不要求可用库存 > 0 —— 库存=0 意味着曾经有货、将来可能有货。

## 成本借用

同 `重量模板` 内的 SKU，同一成本列中 0/空值 被同组非 0 最大值替换。
借用范围：皮壳成本、绍兴包装成本、绍兴总成本、头程运费列、加工成本列。
