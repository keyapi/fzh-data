# 账期业绩（渠道账号维度）月度报表设计

> 状态：**设计与只读核对完成；本 PR 未写线上 Google Sheet、未改 Colab 生产逻辑。**
> 并行对话已于 2026-11-18 在 `通途订单202607/202608/202609` 建 `账号-按应收`；其中 202607 误用 1.7.0，需按本文件 §8.4 重写；202610 尚未建。
> 核对脚本：[`scripts/build_account_period_performance.py`](../../scripts/build_account_period_performance.py)。
> 数据快照：2026-11-18。金额均为人民币；文中只列汇总数，账号明细留在本地 `out/`（gitignore）。

## 1. 结论先行

1. **主成本口径用通途 `写回YYYY年M月FBA订单和非FBA订单`，不用 `账号` ws；默认不套 1.7.0。**
   即使某月存在 `通途订单YYYYMM-特殊规则` 副本（如 202607），本报表也**不自动使用**；只有用户明确指定才用。202607 曾误用 1.7.0，导致成本少约 45.1 万，已按无规则口径重算。`账号` ws 是历史某次管道运行的快照，与当前写回差异很大（202609 少约 55.6 万），只能作对照。
2. **四段成本必须用各自的系数列**：
   - 绍兴产品 = `皮壳成本*系数*数量 + 绍兴二次加工成本*系数*数量`
   - 国外二次加工 = `二次加工成本*系数*数量`
   - 头程 = `头程运费*数量`
   - 尾程 = `运费`
   - 海外仓 = `海外仓成本*数量`（另计，本期全 0）
   **不能**用 `产品成本*系数*数量` 一列代表「绍兴产品 + 国外二次加工」。
3. **收入保留两套基准，不二选一**：
   - A 应收：`应收金额_人民币`（财务可对银行到账）。
   - B 剔预留：`销售额_人民币 − 收款费用累加人民币`（= 应收 + 应收账款，剔除预留变动）。
   两套都并列含税/不含税。
4. **Tax 是显式开关**：OA 应收没有扣 Tax；销售额是否含税尚未由财务最终确认。证据（EU Tax/销售额 15%–27%、US 5%–7%、非 Amazon 0）倾向“销售额含税”，但只作候选，不写死。
5. **附加费只单列**，不并入业绩主列；另给「扣附加费后」版本。已验证附加费 = 4 个分项之和，且**不包含**在收款费用内，不重复扣。
6. **成本按整月订单，不做 04–03 二次过滤**（用户 2026-11-18 明确口径：自发货按发货日期归月、FBA 按付款/销售日期归月，合起来就是一个月的订单）。收入按 OA 账期，成本按整月；期间差异是现有算法的固有差异，不作为错误。窗口成本列仅作敏感性参考，不进入主列。
7. **已知缺口必须写进表**：尾程是 EN 预估不是实际账单；退款未做可售退货 COGS 冲回；FBA 配送费是否已含在应收未证实；`账号` ws 来源未证实。

## 2. 数据流

```text
渠道账号主表（和运营部共享）
  渠道账号 / 渠道账号别名 / 运营人员YYYYMM
        │  explode 别名 → alias→canonical 映射（去重）
        │
OA 钉钉收款（账期 04–03）
  ├ 外币层 YYYYMMDD-YYYYMMDD     应收/销售额/收款费用（按账号）
  ├ 人民币层 人民币YYYYMMDD-…     11 项费用 + Tax + 附加费（按账号+运营人员）
  └ 原始审批明细 …原始            应收账款 / 返还上期预留 / 本期预留
        │
通途订单（自然月）
  ├ 写回…订单（非FBA，带发货日期）
  ├ 写回…FBA订单（月度汇总，无发货日期）
  └ 账号 ws（历史快照，仅对照）
        │
        ▼
账号×运营人员 聚合 → 业绩列 → 本地 xlsx / 未来 GS「账期业绩」
```

`选择平台, 渠道, 渠道账号, 运营人员, 货币中文名, 收款币种, 汇率, 收款归属,

客户退货至我司运费_人民币, 广告费_人民币, 佣金_人民币, UPS重新测量包裹费用_人民币,

### 3.3 OA 原始审批 `…原始`

一行一条审批明细（202608 183 行、202609 167 行、202610 146 行），含审批状态/结果。
关键列：`应收金额, 应收账款, 销售额, 汇率, 返还上期预留金额, 本期预留金额,
应收金额_人民币, 销售额_人民币` + 11 项费用 + `渠道账号, 运营人员`。

### 3.4 独立 `附加费&Tax` 表

`附加费YYYYMM`：`渠道账号, 运营人员, 附加费累加人民币, 账号单独费用,
账号销售费用附加费, 账号头程运费附加费, 账号尾程运费附加费`。
`TaxYYYYMM`：`渠道账号, amount, Tax amount人民币`。
实测与 OA 人民币层**完全相等**（202608 5,070.00；202609 13,065.33；202610 附加费 0、Tax 192,773.60）。

### 3.5 通途写回

非FBA：`写回YYYY年M月订单`（202608 10,819 行、202609 6,219、202610 6,236），**有 `发货日期`**。
FBA：`写回YYYY年M月FBA订单`（202608 1,966 行、202609 1,269、202610 1,550），**无 `发货日期`**，是 MSKU/SKU 月度汇总。
合并表 `写回…FBA订单和非FBA订单` = 两张表按行拼接（行数、金额完全相等），但**同样没有发货日期**；因此需要日期时直接拼两张明细表。

关键成本列：
`皮壳成本*系数*数量, 绍兴二次加工成本*系数*数量, 二次加工成本*系数*数量,
产品成本*系数*数量, 头程运费*数量, 海外仓成本*数量, 运费, 订单总成本*系数`。

## 4. 字段映射（源 → 新表）

| 新表列 | 来源 | 公式/说明 |
|---|---|---|
| 渠道账号 | 主表 `渠道账号` | 订单/OA 的别名先归并到主账号 |
| 运营人员 | OA `运营人员`，缺失用主表 `运营人员YYYYMM` | 多值用逗号；另列 `运营人员数` |
| 平台分类 | OA `选择平台`；订单-only 用 `渠道` | Amazon / 非Amazon / 未分类 |
| 收款归属 | OA `收款归属` | 欧洲/美国/北京/绍兴 |
| OA_销售额_人民币 | OA 外币层 | 原币销售额 × 汇率 |
| OA_收款费用_人民币 | OA 外币层 | = 11 项费用合计（行级差 <0.01） |
| OA_应收_人民币 | OA 外币层 | `应收金额 × 汇率` |
| OA_应收账款_人民币 | OA 原始层 | `应收账款 × 汇率` = 本期预留 − 返还上期预留 |
| OA_销售减费用_人民币 | 计算 | `销售额 − 收款费用` = `应收 + 应收账款`（逐行恒等） |
| OA_Tax_人民币 | OA 人民币层 | 与独立 `TaxYYYYMM` 相等 |
| OA_附加费_人民币 | OA 人民币层 | 与独立 `附加费YYYYMM` 相等 |
| 成本_绍兴产品 | 写回 | `皮壳成本*系数*数量 + 绍兴二次加工成本*系数*数量` |
| 成本_国外二次加工 | 写回 | `二次加工成本*系数*数量` |
| 成本_头程 | 写回 | `头程运费*数量` |
| 成本_尾程 | 写回 | `运费`（当前 EN 预估） |
| 成本_海外仓 | 写回 | `海外仓成本*数量`（本期 0） |
| 成本_合计 | 计算 | 五项之和 = `订单总成本*系数`（逐行恒等） |
| 成本_窗口 | 写回（当前月 + 次月 1–3 日 + FBA 整月） | 见 §6 |
| 业绩_应收_不含税_不扣附加费 | 计算 | `应收 − 成本`（主列之一） |
| 业绩_应收_不含税_扣附加费 | 计算 | `应收 − 成本 − 附加费` |
| 业绩_应收_含税_不扣附加费 | 计算 | `应收 − 成本 − Tax` |
| 业绩_应收_含税_扣附加费 | 计算 | `应收 − 成本 − Tax − 附加费` |
| 业绩_剔预留_* | 计算 | 把 `应收` 换成 `销售减费用`，其余相同 |
| 业绩_*_窗口 | 计算 | 把 `成本` 换成 `成本_窗口` |

## 5. 公式与四套基准

收入：

```text
A 应收       = OA 应收金额_人民币
B 剔预留     = OA 销售额_人民币 − OA 收款费用累加人民币
             = A + 应收账款_人民币
```

成本：

```text
C = 绍兴产品 + 头程 + 国外二次加工 + 尾程 + 海外仓
```

主公式（用户原话）：

```text
账期业绩 = 收入基准 − C − （可选）Tax − （可选）附加费
```

四套基础 + 附加费两版（脚本全部输出，财务自选）：

| 收入基准 | Tax | 附加费 | 列名 |
|---|---|---|---|
| A 应收 | 不扣 | 不扣 | `业绩_应收_不含税_不扣附加费`（**默认主列**） |
| A 应收 | 不扣 | 扣 | `业绩_应收_不含税_扣附加费` |
| A 应收 | 扣 | 不扣 | `业绩_应收_含税_不扣附加费` |
| A 应收 | 扣 | 扣 | `业绩_应收_含税_扣附加费` |
| B 剔预留 | 不扣 | 不扣 | `业绩_剔预留_不含税_不扣附加费` |
| B 剔预留 | 不扣 | 扣 | `业绩_剔预留_不含税_扣附加费` |
| B 剔预留 | 扣 | 不扣 | `业绩_剔预留_含税_不扣附加费` |
| B 剔预留 | 扣 | 扣 | `业绩_剔预留_含税_扣附加费` |

### 5.1 Tax 含税判断（未证实，候选并列）

- OA 表单没有 Tax 字段，应收也没扣 Tax；Tax 只出现在人民币层。
- 实测 Tax/销售额：EU 账号 15%–27%（FR/IT/DE），US 账号 5%–7%，非 Amazon 0。
  该分布与“销售额含 VAT/销售税”一致，但**不是财务确认**。
- 处置：同时输出含税/不含税；等财务 ZJ 确认后，在表头标注 default。
  **需要证据**：Amazon Date Range / Settlement V2 同期原币销售额与 Tax 的逐店对平（ZJ 或税务顾问签字）。

### 5.2 附加费勾稽

- `附加费累加人民币 = 账号单独费用 + 账号销售费用附加费 + 账号头程运费附加费 + 账号尾程运费附加费`（逐行零差；本期只有“账号单独费用”有值）。
- 11 项 `收款费用` 明细**不含**附加费 → 不重复扣。
- 202610 独立附加费表存在但金额为 0：**需确认是“本月无附加费”还是“尚未录入”**，脚本在“输入就绪”页标出。

## 6. 期间对齐（按现有算法：成本整月）

- OA 账期：**每月 04 日 ~ 次月 03 日**（收入侧）。
- 通途成本：**按整月订单**。自发货导出按发货日期归月；FBA 导出按付款/销售日期归月；两者各自进当月 `通途订单YYYYMM`，合起来就是该月订单。
- **不做 04–03 二次过滤**。9/1–9/3 在 9 月成本里、不在 20260904–20261003 账期里，是现有算法的固有差异，不是漏数。
- 脚本仍输出“同窗口成本”作为**敏感性参考**（当前月 04–03 + 次月 1–3 非FBA + FBA 整月），但不进入主列；主列用自然月成本。
- 202609 实测（与并行 A/B 核对一致）：
  - 自然月非FBA成本 1,938,631.39；FBA 整月 153,991.40；自然月合计 **2,092,622.79**
  - 窗口外 9/1–9/3 非FBA成本 **309,727.57**（15.98%）
  - 次月 10/1–10/3 成本 **170,988.29**（补入窗口）
- 202610 的次月 `通途订单202611` 尚未建 → 窗口成本**缺 11/1–11/3**，脚本在“输入就绪”标缺失。

> 结论：**不要假装账期应收和自然月成本是同一期间。** 过渡期主表并列两版；财务对账用窗口版，运营考核可先用自然月版并写清楚。

### 8.3 恒等式与校验（17/17 通过）

1. `销售额 − 收款费用 = 应收 + 应收账款`（逐账号、逐行）。
2. `应收账款 × 汇率 = 本期预留 − 返还上期预留`。
3. 11 项费用合计 = `收款费用累加人民币`。
4. OA 人民币层 = 外币层的收款费用。
5. 附加费：人民币层 = 独立附加费表 = 4 个分项之和。
6. Tax：人民币层 = 独立 Tax 表。
7. 写回：四桶 + 海外仓 = `订单总成本*系数`。
8. 写回：`产品成本*系数*数量` = 绍兴产品 + 国外二次加工（本期实测成立；仍不把它当唯一来源）。
9. 非FBA 写回发货日期齐全；FBA 写回无日期（129 行/月级别，整月计入窗口）。
10. 主表订单成本合计 = 写回合计；主表 OA 应收合计 = 外币层合计。
11. 逐账号：`销售减费用 = 应收 + 应收账款`（不只看总额）。
12. 逐账号：`成本合计 = 五桶之和`（不只看总额）。
13. 未匹配别名的订单成本单独成行（`UNMATCHED`），不并入真实账号、也不从总额中消失。
14. 逐行：五桶之和 = `订单总成本*系数`（不只看总额）。

## 9. 边界条件矩阵

| 组合 | 表现 | 处理/标记 |
|---|---|---|
| OA 有、订单无 | 应收有、成本 0 | `仅OA（无通途成本）`；业绩=应收，不可当真实毛利 |
| 订单有、OA 无 | 成本有、应收 0 | `仅订单（无可收/应收）`；业绩可能为负，不得删行 |
| 两边都有 | 正常 | `双边` |
| 主表有、两边都无 | 0 行 | `仅主表（本月无OA无发货）`；默认保留（`--active-only` 可过滤） |
| 订单别名匹配不上 | 原代码 `null` | 单列 `UNMATCHED`，不并入真实账号 |
| 非 Amazon 平台 | `选择平台=新平台/独立站` 或订单 `渠道=Wayfair/OSTK/PotteryBarn/...` | `平台分类=非Amazon`；若只有应收无成本，标 `仅OA` |
| 一个账号多个运营人员 | OA 人民币层可能有旧/新两条 | 主表按账号汇总；`运营人员数>1` + `运营人员不一致` 标记 |
| 一个运营人员多个账号 | 正常 | 运营人员汇总页累加 |
| 主表别名重复 | 2 条实测 | 保留首条 + 异常页列出，避免订单重复行 |
| 月初 OA 未生成 | 缺输入 | `输入就绪` 报“缺失”；不静默按 0 计算 |
| 通途月表未生成 / FBA 无日期 | 缺输入 | 同上；窗口成本标“缺次月 1–3 日”或“FBA 整月” |
| 尾程未导入实际账单 | 只有 EN 预估 | `尾程来源` 列固定标“EN预估”；不得伪装实际 |
| 退款退货 | OA 退款已在费用内 | `退货冲成本=未实现`；需可售性报告才能冲 COGS |
| 202610 审批中 52/146 | 应收未定稿 | `输入就绪` 列出“完成/审批中”行数 |
