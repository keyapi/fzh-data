## 五、脚本说明

### 新建脚本

| 脚本 | 用途 | 使用方式 |
|------|------|---------|
| `move_item_groups.py` | **物料组重新归类工具** | `python move_item_groups.py --env test\|prod [--dry-run]` |

### `move_item_groups.py` 关键逻辑

1. **验证阶段** — 连接 EN 系统，获取全量物料组，验证所有源节点和目标父节点均存在
2. **执行阶段** — 逐个调用 PUT API 更新 `parent_item_group` 字段
3. **叶子节点保护** — 遇到"不能是一个叶节点"错误时，自动设置 `is_group=1` 后重试
4. **重建嵌套集树** — 移动完成后调用 `rebuild_tree` 确保浏览器正确显示
5. **操作报告** — 输出 Excel 报告到 `out/` 目录

### 移动清单定义

移动清单硬编码在 `MOVE_LIST` 列表中，格式 `(源物料组名称, 目标父节点名称)`：

```python
MOVE_LIST: list[tuple[str, str]] = [
    ("笔记本地垫", "儿童类"),
    ("薯条沙发升级款", "儿童类"),
    # ...
]
```

如需新增/修改移动项，直接编辑该列表即可。

## 七、注意事项

### 名称精确匹配
ERPNext 的 Item Group 按 `name` 字段精确匹配，名称必须与系统中完全一致（含空格）：
- ✅ `床上用品印花套装- 小长方形枕`（减号后有空格）
- ❌ `床上用品印花套装-小长方形枕`（无空格 — 匹配失败）

### 父节点名称
- 用户说的"功能枕"对应系统中 `功能枕类`

### 后续维护
如需新增归类调整，编辑 `move_item_groups.py` 的 `MOVE_LIST` 后执行：
```bash
# 先预览
python move_item_groups.py --env test --dry-run
# 确认后执行
python move_item_groups.py --env test
python move_item_groups.py --env prod
```
