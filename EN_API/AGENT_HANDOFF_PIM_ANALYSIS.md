## 1. 业务背景

EN 系统（ERPNext）的物料组（Item Group）有一个自定义子表 `custom_pim_images`，用于存储 PIM（Product Information Management）图片。

**需求**：统计"产品"根节点下所有叶子节点物料组的**上一级父节点**是否在 `custom_pim_images` 子表中配置了图片。

### 统计粒度说明

| 路径示例 | 叶子节点 | **统计对象（父节点）** |
|:---|:---|:---|
| 所有物料组/产品/儿童类/儿童泡沫攀岩块类/儿童泡沫攀岩块-拱桥套组 | 儿童泡沫攀岩块-拱桥套组 | **儿童泡沫攀岩块类** |
| 所有物料组/产品/宠物类/毛毡猫隧道 | 毛毡猫隧道 | **宠物类** |
| 所有物料组/产品/家居类/收纳/抽屉收纳 | 抽屉收纳 | **收纳** |

> 相同父节点去重，只查询一次。例如"儿童泡沫攀岩块类"下有 7 个叶子产品，只需检查该类一次。

---

## 2. 分析流程

```
ERPNext 全量物料组拉取 (列表接口 → 建立树结构)
  → get_subtree("产品", idx) 获取产品子树
  → 筛选所有叶子节点 (is_group=0)
  → 按 parent_item_group 分组去重，得到唯一父节点列表
  → 逐条调用 GET /api/resource/Item Group/{父节点name} (含子表数据)
  → 提取 custom_pim_images 字段 → 判断是否为空
  → 统计有图/无图的父节点数，及对应覆盖的叶子数
  → 输出 Excel 报告
```

### 性能优势

优化前：需查询全部子孙节点（430+ 次 API 调用）
优化后：只需查询唯一父节点（~41 次 API 调用），效率提升约 10 倍

## 3. 关键函数

| 函数 | 作用 |
|------|------|
| `ErpnextClient.fetch_all(fields)` | 全量拉取 Item Group 列表（树结构） |
| `ErpnextClient.get_full(docname)` | 获取单个物料组完整数据（含 `custom_pim_images` 子表） |
| `build_index(data)` | 按 `name` 建立字典索引 |
| `get_subtree(name, idx)` | 获取指定节点及其所有子孙节点 |
| `analyze(client, root_name)` | 主分析流程：取叶子→按父分组→去重→逐条查子表 |
| `generate_report(results, ...)` | 生成 Excel 报告 |

---

## 4. API 端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/resource/Item Group` | GET | 获取物料组列表（树结构） |
| `/api/resource/Item Group/{name}` | GET | 获取单个物料组完整数据（含子表） |

### 测试 vs 生产对比

| 项目 | 测试系统 | 生产系统 |
|:---|---:|---:|
| 物料组总数 | 1,661 | 3,674 |
| "产品"下叶子节点 | 377 | 405 |
| 唯一父节点（去重） | 41 | 42 |
| 父节点有 PIM 图片 | 10 (24.4%) | 13 (31.0%) |
