# 美国床型与近寸

EN / 赛狐尺寸用厘米。Amazon 标题常用 inch、twin/full/queen/king。

权威表：[`../../knowledge/us-size-map.yaml`](../../knowledge/us-size-map.yaml)。

| 标题词 | EN 近寸（cm） |
|--------|----------------|
| twin / twin xl | 97, 100 |
| full / double | 137, 138 |
| queen | 152, 153 |
| king | 193, 194, 200 |
| cal king | 183, 184 |

已知例外：通途规则里 `FoamFBAKZ159410287-BLACK-97` 应对 `...-BLACK-100`。近寸互为别名，不能当属性冲突。
