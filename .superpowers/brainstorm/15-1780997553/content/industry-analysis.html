行业方案对比：资产组编辑器布局

研究了 Shopify、Amazon、IPV Curator、WordPress、StreamYard 等 7 个系统的 Collection/Lightbox/图片组 UI 模式

行业共识（所有系统都这样做）

  • 拖拽手柄 + 视觉落点指示 — IPV Curator 用绿色横线，Shopify 用蓝色阴影
  • Position = 导出顺序 — 第 1 张 = 主图，导出时映射到各平台列名
  • 显式保存按钮 — Shopify/Amazon 都不自动保存，需要点 Save
  • 缩略图 + 角色标签 — 每张图片上标明 main/alternate/lifestyle
  • 备选排序方式 — 除了拖拽，还有"按名称/按日期"下拉排序作为备选

推荐：🅰️ 右侧抽屉 + 可展开

理由：

  1. 贴合现有架构 — Asset 详情面板已经是右侧滑出，Collection 编辑器复用同一模式，用户零学习成本
  2. 边浏览边策展 — 资产网格始终可见，可以对比不同图片决定"哪张做主图"，这是电商运营的核心操作
  3. SortableJS 已就绪 — 只需把 Sortable 绑定到 Collection 面板内的列表上，不需要重构布局
  4. 窄面板对列表够用 — Collection 内是有序列表（不是网格），200px 宽的缩略图+角色标签在 360px 面板里空间充裕
  5. 加个展开按钮 — 点一下面板宽度从 360px → 520px，解决看大图的需求
