核心设计结论

Tag vs Collection Tag = Asset 是什么 | Collection = Asset 用于什么
Collection 模型 type 枚举约束灵活度, context JSON 按 type 有固定 schema
listing context {skus: ["KS0001",...], channel: "amazon", marketplace: "US"}
UI 模式 AEM 替换视图（点 Collection → 主区域切换编辑器）
导出 多行 Excel（N 个 SKU → N 行）
访问控制 Phase 3b 默认 Public, 按创建者过滤

Phase 3b 范围

包含 (8项)

  • 后端增量 item 操作 API
  • 多 SKU 多行 Excel 导出
  • Collection 编辑器 (AEM 替换视图)
  • SKU 列表 + 图片编辑区
  • SortableJS 拖拽排序
  • 添加/删除资产
  • 角色设置 per item
  • 导出按钮

不包含

  • 版本历史查看/回滚 UI
  • ERPNext Item API 对接
  • 文件夹上传
  • Private Collection
  • Smart Collection
