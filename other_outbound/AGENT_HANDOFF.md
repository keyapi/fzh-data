# other_outbound — 赛狐其他出库导入

赛狐库存明细导出 → 其他出库单（清零库存）。

## 管道概要

```
赛狐库存明细导出 → 过滤非零库存 → 过滤组合商品(-ALL后缀)
    → 填入其他出库模板 → 按仓库输出 3 文件
```

## 赛狐模板写入规则

| 模板列 | 值 |
|--------|-----|
| 临时单号 | OB+时间戳（全仓共享） |
| `*出库仓库` | CENTRADE / DANEEY / POLAND |
| `*出库类型` | 其他出库 |
| `*SKU` | 赛狐 SKU（逐行保留库存明细数据） |
| `店铺` | 库存明细中的店铺 |
| `FNSKU` | 库存明细中的 FNSKU |
| `可用出库量` | 库存明细中的可用数 |

## 赛狐导入规则

- 模板 1 行表头 + 7 sheet（4 hidden Data Validation）
- 同一 (出库仓库+SKU) 已有待确认记录时，新导入被拒绝
- 组合商品 SKU（-ALL 后缀）不支持其他出库
- 同一临时单号的多行合并为一笔出库单
- 导入后需手动确认出库

## 函数索引

| 函数 | 职责 |
|------|------|
| `auto_select(pattern)` | 自动选取最新数据文件 |
| `generate_outbound_rows(df)` | 提取要出库的行，跳过组合商品 |
| `_fill_single_file(rows, path)` | 填入单个仓库的模板 |

## 踩坑

### 坑 1：库存明细含店铺/FNSKU 维度
同一 SKU+仓库 可能有多行，对应不同店铺。不能按 SKU+仓库 聚合出库量，必须逐行保留。

### 坑 2：组合商品不能出库
`-ALL` 后缀 SKU 是组合商品，其他出库不支持。需过滤掉，否则整个批次被拒。

### 坑 3：操作前必须重新导出库存
库存明细数据在出库后会变化，操作前必须重新从赛狐导出最新数据。


## 踩坑

### 坑 1：库存总数 ≠ 可用数
赛狐库存明细中 （精确成立）。
其他出库只能用**可用数**列清零。用库存总数会导致赛狐拒绝确认（弹窗报可用良品库存不足）。
占用数是被已有订单锁定的库存，其他出库无法操作。

### 坑 2：单临时单号 ≤1000 条
同一临时单号不超过 1000 条。POLAND 仓（1038 条）需拆 2 批，每批独立临时单号。

### 坑 3：确认出库等待 loading mask
确认出库后赛狐出现  遮罩，大单（500+行）处理需 10-60 秒。
不可用 JS evaluate 点击按钮（绕过遮罩导致服务器拒绝）。
必须用 Playwright 原生 click + 等待遮罩消失。
