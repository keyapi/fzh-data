# SPS Selenium 自动化使用指南

## 🚀 快速开始

### 第一次使用

1. **确保环境准备**
   - 安装 Python 3.8+ (推荐 3.10+)
   - 安装 Chrome 浏览器
   - 确保网络连接正常

2. **运行自动化**
   ```cmd
   双击运行: install_and_run.bat
   ```

3. **设置定时任务**
   ```cmd
   右键 setup_schedule.bat -> "以管理员身份运行"
   ```

### 日常使用

- **手动执行**: 双击 `install_and_run.bat`
- **查看日志**: 打开 `logs/sps_automation.log`
- **查看截图**: 打开 `screenshots/` 目录

## 📋 定时任务说明

### 任务设置
- **任务名称**: SPS_Selenium_Daily
- **执行时间**: 每天北京时间 12:35
- **运行权限**: 系统权限

### 管理命令

```cmd
# 查看任务状态
schtasks /query /tn "SPS_Selenium_Daily"

# 手动运行任务
schtasks /run /tn "SPS_Selenium_Daily"

# 禁用任务
schtasks /change /tn "SPS_Selenium_Daily" /disable

# 启用任务
schtasks /change /tn "SPS_Selenium_Daily" /enable

# 删除任务
运行: remove_schedule.bat (需要管理员权限)
```

## 🔧 配置修改

### 修改登录信息

1. 创建 `.env` 文件:
   ```env
   SPS_EMAIL=your_email@example.com
   SPS_PASSWORD=your_password
   ```

2. 或直接修改 `config.py` 文件

### 修改执行时间

1. 删除现有任务:
   ```cmd
   右键 remove_schedule.bat -> "以管理员身份运行"
   ```

2. 修改 `setup_schedule.bat` 中的时间:
   ```cmd
   set SCHEDULE_TIME=12:35  # 改为你想要的时间
   ```

3. 重新创建任务:
   ```cmd
   右键 setup_schedule.bat -> "以管理员身份运行"
   ```

### 修改模板选择

修改 `config.py` 中的模板设置:
```python
'template_cutoff_date': '2025-10-02',
'template_before_cutoff': 'IA Template 20250925 0xBlack138 till1009',
'template_after_cutoff': 'IA Template 20250605 x100',
```

## 🐛 故障排除

### 常见错误

1. **"Python 未安装"**
   - 从 python.org 下载安装 Python 3.8+
   - 安装时勾选"Add to PATH"

2. **"权限不足"**
   - 右键批处理文件
   - 选择"以管理员身份运行"

3. **"依赖安装失败"**
   - 检查网络连接
   - 重新运行 `install_and_run.bat`

4. **"ChromeDriver 下载失败"**
   - 检查网络连接
   - 可能需要配置代理

5. **"登录失败"**
   - 检查 `config.py` 中的凭据
   - 确认 SPS Commerce 账户状态

6. **"元素找不到"**
   - 网页可能有更新
   - 查看截图了解页面状态
   - 可能需要更新 XPath

### 调试模式

如需查看浏览器运行过程:

1. 修改 `config.py` 中的 headless 设置:
   ```python
   'headless': False  # 改为 False 显示浏览器窗口
   ```

2. 重新运行:
   ```cmd
   install_and_run.bat
   ```

### 日志分析

日志文件位置: `logs/sps_automation.log`

重要日志标识:
- `✅` - 成功操作
- `❌` - 失败操作
- `[错误]` - 错误信息
- `[信息]` - 一般信息
