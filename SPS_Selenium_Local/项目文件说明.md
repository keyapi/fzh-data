# SPS Selenium 项目文件说明

## 📁 项目结构

### 🔧 核心文件（必需）
- `sps_automation.py` - 主自动化脚本
- `config.py` - 配置文件
- `requirements.txt` - Python 依赖包
- `SPS_selenium_send_inventory_advice.ipynb` - 原始 Jupyter notebook（保留作参考）

### 🚀 执行脚本
- `install_and_run.bat` - **主执行脚本**（推荐使用）

### ⏰ 定时任务管理
- `setup_schedule.bat` - 设置定时任务
- `remove_schedule.bat` - 删除定时任务
- `update_schedule.bat` - 更新定时任务

### 📊 数据目录
- `screenshots/` - 自动化过程截图
- `logs/` - 执行日志文件

### 📖 文档文件
- `README.md` - 详细使用说明
- `使用指南.md` - 中文快速指南
- `项目总结.md` - 项目完成总结
- `项目文件说明.md` - 本文件

### 🔧 其他文件
- `.gitignore` - Git 忽略文件配置
- `__pycache__/` - Python 缓存目录

## 🚀 使用方法

### 日常执行
```cmd
双击运行: install_and_run.bat
```

### 设置定时任务
```cmd
右键以管理员身份运行: setup_schedule.bat
```

### 管理定时任务
```cmd
# 更新任务
右键以管理员身份运行: update_schedule.bat

# 删除任务  
右键以管理员身份运行: remove_schedule.bat
```
