## 🔧 技术特性

### 版本管理
- **Chrome**: 使用系统安装的 Chrome 浏览器
- **ChromeDriver**: webdriver-manager 自动下载匹配版本
- **Selenium**: 4.15.0 (最新稳定版本)
- **Python**: 支持 Python 3.8+ (测试使用 3.13.7)

### 环境特性
- 直接在 Windows 本地运行，无需 Docker
- 自动管理 ChromeDriver 版本兼容性
- 支持 headless 模式，后台静默运行
- 完整的中文支持和时区处理

### 错误处理
- 完善的日志记录系统
- 自动截图保存（成功和失败时）
- 重试机制（登录等关键操作）
- 详细的错误信息和堆栈跟踪

### 自动化特性
- Windows 任务计划程序集成
- 每天北京时间 12:35 自动执行
- 一键设置和删除定时任务
- 支持手动执行和测试

## 🚀 使用流程

### 首次设置
1. 确保安装了 Python 3.8+ 和 Chrome 浏览器
2. 运行 `install_and_run.bat` 安装依赖并测试
3. 以管理员身份运行 `setup_schedule.bat` 设置定时任务

### 日常使用
- 自动执行：每天 12:35 自动运行
- 手动执行：双击 `install_and_run.bat`
- 查看结果：检查 `logs/` 和 `screenshots/` 目录

## 📊 项目优势

### 相比原 Deepnote 方案
1. **本地控制** - 完全本地运行，不依赖第三方平台
2. **成本节约** - 无需付费云服务
3. **数据安全** - 敏感信息保存在本地
4. **执行稳定** - 不受云平台政策变化影响

### 相比 Docker 方案
1. **部署简单** - 无需 Docker 环境，直接运行
2. **启动快速** - 无需构建镜像，立即执行
3. **资源占用少** - 不需要容器开销
4. **版本自动匹配** - webdriver-manager 自动处理兼容性
