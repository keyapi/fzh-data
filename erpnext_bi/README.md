# erpnext_bi — EN 生产 BI 看板

实时跟进销售订单的 **下单 → 生产 → 发货** 进度，按订单号归并其拆分单，
一眼看清每张订单生产了多少、发货了多少。

## 快速开始
```bash
cd /d/AI/fzh-data
uv run uvicorn erpnext_bi.app:app --host 127.0.0.1 --port 8099 --log-level info
```
浏览器打开 **http://127.0.0.1:8099/**

## 功能
- 汇总卡：进行中订单数、总下单/生产/发货量、整体生产/发货完成率
- 订单列表：每单的下单量 + 生产/发货进度条（点击行展开看每个物料的明细）
- 搜索框：按订单号 / 客户 / 拆分单号过滤
- 强制刷新按钮：重新从 EN 生产环境拉取最新数据（默认内存缓存 5 分钟）

## 数据说明
- 数据实时取自 ERPNext 生产环境（凭证在 `EN_API/.env`，不进仓库）
- "一个订单号多个订单"已自动合并（如 `SO-24-00030` 与 `SO-24-00030-1` 归并为同一单）
- 生产/发货数量取自销售订单行项目的 `produced_qty` / `delivered_qty` 字段
- 下单日期取自销售订单的 `transaction_date`

## 已知范围（MVP）
- **发货数量** = 销售订单行项目的 `delivered_qty`（ERPNext 提交销售出库单 DN 后回写的真实已发数量）
- **发货日期（销售出库时间节点）暂缺**：当前 API 用户无"销售出库单(Delivery Note)"列表权限（403），无法枚举 DN 取发货日期。需给该 API 用户开放 Delivery Note 读取/列表权限（或换有权限的 key）后补上
- **包装阶段暂未纳入**：待确认取数来源后扩展（疑似 `Tongtool Package` 通途包裹）
- 看板只读展示，不做任何写操作
