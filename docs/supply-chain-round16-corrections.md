# round16 交付纠正

结论：**v2 只能作为讨论材料，不能作为采购依据；v3b 的补充页也不能替代主表。** 下一版 v4 必须统一重建主表、汇总和行动清单。

## 1. 服务目标被替换

- 原方案区分 A 级“周期无断货 95%”与 B 级“需求满足率 95%”。
- 现程序把任一指标达到 95% 都算通过，等于事后换更容易的指标。
- 在 31 个可复核键中，**14 键/584 件未达各自原目标**；其中 27 个所谓可确认里占 12 键/480 件，4 个首批晚于停工里占 2 键/104 件。
- v4 必须按 `放行等级` 分别判定：A 看 cycle，B 看 fill，不能二选一。

## 2. 催已有与新增被二选一

- D6 当前 105 个催已有键中，**71 个同时需要新增，合计 5,309 件**。
- 逐商品表有数量，但“催已有订单”说明写成“不是新增”，日常汇总也没包含这 5,309。
- v4 必须同时保留两列：`催已有量`（合计约 7,869）和`新增补货量`（5,309）；状态写“催已有+新增”。

## 3. PO “缺 2,417 件”不是采购缺口

- 2,417 是 17 个 60cm 键的**历史销量**，被错误写成 PO 欠采购量。
- 对应 D6 当前净需求合计约 **316.1**，新补参考约 **324**。
- 例：ANTHRACITE 历史 680，当前新补参考 22。
- v4 必须分列：历史销量 4,001 / PO 无覆盖历史 2,417 / 当前 D6 净需求 316 / 新补参考 324；不能把历史销量当欠采购。

## 4. 四项“首批晚于停工”口径错误

- 工厂 1/24 停工限制的是**生产**，不是海外仓收货；2 月到海外仓不能据此判不可执行。
- 4 键均为 B 级（满足率 95%）：
  - CMM-140、CMKTR-100：fill 95.10% / 97.17%，达原目标；
  - GDR-153、CMPR-100：fill 87.04% / 80.95%，未达原目标。
- 改空运不改善服务；不能再说“四项均可执行”。
- v4 删除“首批晚于停工”阻断，按原目标判定；2 键可确认、2 键需调整。

## 5. 周一时点重核

- 以 2026-11-09 为决策时点，D6 日常补货候选“下单日已过”从 203 键/11,916 件增至 **209 键/12,125 件**；新增 **6 键/209 件**。
- CNY 首批下单日 11-06 也已过；v4 必须按 11-09 重排/标注。
- 数据源仍为 D5 截至 11-02、库存 11-05；不能声称已更新到 11-09。

## v4 验收

- 催已有+新增两列；
