## 1. family不是SKU也不是物料合并

- 规划汇总允许把两个leaf归为同一family；事实、BOM、成本、库存与数量单位保留原leaf、规范物料和完整通途SKU。
- 两个leaf各1件→family2，但不是一个SKU2件；成本、无扣/有扣、面料/尺寸的区别继续保留。
- 中文“自产-三角靠枕-*”“三角”“三角靠枕”只生成候选。不能把全部含三角的行直接归KS0001/KS0248；也不能先用不可信品类筛掉P1已证明属于family的行。
- KS0001/KS0248是用户提供的业务标识；G1需从导出元数据核其与实际group/template/item字段的关系，不靠产品前缀或名字推断。

20261016导出对4–9月属于**事后可用映射快照**；若没有有效期，不自动证明4月当时映射相同。保留`mapping_temporal_unverified`，G1可核当前映射和历史订单关联的一致性，不能冒称历史as-of模型输入。已有查询器/成本引擎只复用已核规则，不另造全量映射链。

## 3. 匹配顺序与预期异常

1. 保留原SKU与源行；仅做有记录的空白/格式规范化，大小写、后缀和历史改名不无条件折叠。
2. P1完整码精确匹配，核规范物料→leaf归属、行角色/UOM和版本；再判family。空客户码不补猜。
3. 同一通途SKU多EN物料，或同时跨两个leaf命中→`conflict(reason=ambiguous)`；不按成本、最大数量、最新文件名、先命中自动选一个。
4. 删除前缀/标记按来源实际规则记录并单列；不能凭自编前缀批量删行。`-Cover/-Foam`分别标记，精确映射后继续核部件/独立销售角色，禁止剥后缀后当成整件。
5. P2/P3只补充候选/证据；fallback不隐入P1成功数。无法明确的SKU继续保留，不因GSheet中文品类相近而强归族。

| 预期类别 | 处置及要保留的证据 |
|---|---|
| 空客户码/目标SKU完全无匹配 | `unmatched`＋源文件/行/原码，不置空EN物料后继续计算 |
| 删除标记/已删除前缀 | `blocked`＋实际命中规则/字段；记录其数量去向，不静默删除 |
| -Cover/-Foam部件 | 标记component后缀；若无精确匹配→unmatched，若已映射→仍核角色/UOM，不能直接计成品件数 |
| 多EN命中/跨leaf歧义 | `conflict`＋全部候选及来源；fail-closed |
| EN物料已知但leaf缺失/版本不明 | `unknown`＋待补元数据；不是0或自动归KS0001 |
| 精确映射到family之外 | `blocked(reason=outside_family)`，单列范围外数量 |
| 历史改名/导出时点不符 | 保留旧码/有效期与候选，缺历史证据标temporal_unverified，不伪造改名链 |
| P1冲突而P3恰好命中 | 仍conflict，不用fallback消除冲突 |
| 同源重复行/一订单多包裹 | 稳定源行ID去重，包裹/部件按既有规则归一；原始行数与成品件数分开守恒 |
| 两仓切换/转仓/渠道改变 | 保留来源仓/发货日期和服务池；不能把一仓销量归零自动判断货 |

## 4. 两仓、六个月与库存cutoff

- 两仓仅包含已确认的仓ID/精确别名。名字含DANEEY/CENTRADE不代表全部子仓都纳入：皮壳、半成品、退货、损坏仓的角色须另核，不按字符串包含全收。
- 2026-04..09是**订单契约回放期**，不叫最近三个月、不用来定季节模型。GSheet原始月表与本地`2026年{4..9}月订单_order_cost_*.xlsx`要记录版本/日期/数量/行号差异；二者不是两份可相加销量。
- cutoff是另一个明确时点，库存用当前通途整仓快照，不是low-stock过滤后的结果；记录分页完整性、字段定义、抓取开始/结束、仓范围和质量。
- 当前快照只证明其准确cutoff截面。没有期间流水不能把当前库存反推4–9月余额，也不能无事件向未来平推。历史订单累计已发与当前open/供应状态不能不加时点筛选直接抵扣。
- 独立的每日全量归档不阻塞G1；仅低库存告警行不能当全量历史档案。

## 5. PB信号子集与G2/G3边界

PB只覆盖约30个涤麻SKU，且历史仓从Daneey/Centrade切换；此为用户补充，**不是全family、全渠道、全仓、全时段的断货真值**。本轮不读Notion/邮件/check0stock原记录。

G1不需要断货标签。C20仅验证“无标签→未知、换仓不自动断货、PB局部信号不外推”；不从订单缺口直接推真实流失需求，也不能在没有分母/提前期时算历史覆盖月数。G2/G3按有来源和范围的信号做raw/censored敏感性；无信号的0销量即使经完整读取确认是“观测销量0”，潜在需求仍未知。
