# BOM Cost List Excel 成本读取说明

> **用途**: 解释 ERPNext 自定义报表 `BOM Cost List` 导出的 Excel，拆解每个 SKU 在美东USNJ(CENTRADE)、美中USTX(DANEEY)、波兰PL(POLAND) 三个仓库下的成本。
> **来源**: 开发服务器上 ERPNext `bom_cost_list` 自定义报表
> **原始整理**: 2026-05-26

## 1. 仓库名称和别名

| 业务仓库 | Excel 表头关键词 | 可能的外部叫法 |
|----------|-----------------|---------------|
| 美东仓 | `美东USNJ` 或 `USNJ` | `CENTRADE` |
| 美中仓 | `美中USTX` 或 `USTX` | `DANEEY` |
| 波兰仓 | `波兰PL` 或 `PL` | `POLAND` |

## 2. 黄色总成本列的含义

以 `pllc_` 开头的"尾程前成本"列，表头形式：

- `发皮壳尾程前成本<br>美东USNJ`
- `发成品尾程前成本<br>美东USNJ`
- `发皮壳尾程前成本<br>美中USTX`
- `发成品尾程前成本<br>美中USTX`
- `发皮壳尾程前成本<br>波兰PL`
- `发成品尾程前成本<br>波兰PL`

**注意**: `发皮壳尾程前成本` 同时兼容"皮壳"和"半成品"两种路径。

## 4. 黄色总成本拆成三部分

### 4.1 绍兴发货方式 = 皮壳

- 绍兴发货成本 = `皮壳成本`
- 头程运费 = `头程皮壳运费<br>对应仓库`
- 国外加工成本 = 对应仓库加工成本

校验: `发皮壳尾程前成本 = 皮壳成本 + 头程皮壳运费 + 加工成本`

### 4.2 绍兴发货方式 = 半成品

- 绍兴发货成本 = `皮壳成本` + `绍兴包装半成品成本`
- 头程运费 = `头程半成品运费<br>对应仓库`
- 国外加工成本 = 对应仓库加工成本

校验: `发皮壳尾程前成本 = 皮壳成本 + 绍兴包装半成品成本 + 头程半成品运费 + 加工成本`

如果半成品头程为 0，可用皮壳头程近似替代。

### 4.3 绍兴发货方式 = 成品

- 绍兴发货成本 = `绍兴总成本`
- 头程运费 = `头程成品运费<br>对应仓库`
- 国外加工成本 = 0

校验: `发成品尾程前成本 = 绍兴总成本 + 头程成品运费`

## 5. 成本缺失时的重量模板补值

1. 用 `重量模板` 分组
2. 同组内找非 0 最大值
3. 当前行缺失时用同组最大值补
4. 同组无非 0 值则保持缺失

## 6. 不在本说明范围内

- 通途 SKU 尾缀(-Cover/-Foam/-PPCotton/-1)造成的成本拆分
- 拆分多包裹成本系数
- 国外尾程派送费、平台费、交易费、广告费
- FBA 仓库（仅处理 USNJ/USTX/PL）

## 7. 表头标准化规则

表头可能含真实换行、`<br>`、空格或 `-`。读取时统一标准化：去掉空格 → 换行替换为 `<br>` → `-` 视为换行分隔符。
