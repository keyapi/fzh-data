## 2. 关键口径

- 需求曲线：`forecast-20261027-r4` → `run-2026-10-26-r6` 的 27 个周桶，逐键 `period_demand`；
  视界内历史需求为 0。
- **不给精确 97/157**：97 落在桶中；按项目约定取「桶结束 ≥ 目标」的第一个桶（w14→102 天、
  w22→158 天），绝不插值；窗口含下单前 3 天（10-26..10-29），桶不可拆、宁可多算。
- 已承诺未履约 SO：48 键 `so_pipeline_qty=0`，无需去重。
- IP = 10-28 同仓已证可发（合计 7）+ 已证未到货（0）；未证在途/PO/SO（全 0）不抵扣。
- SS = 档位系数 × z(SL) × σ_daily × √H，政策 A 1.5×/95%、B 1.0×/90%、C 1.0×/85%，
  **仅 σ>0 时应用**；本批 8 行（A 5 / B 1 / C 2）。
- Q = max(0, 需求 + SS − IP)；最晚下单日 = 首次缺口起始 − 提前期（P50 67/72 天、规划 105/110 天）。

## 3. 与旧口径的关系

- 旧 35 天参考 116 → 真实曲线 97/157 需求 356.52/551.83，比值 3.07×/4.76×，**非线性**；
  逐键比值中位数 2.06，最大 6.9×、最小 0.006×（预测近零）。
- 8 行 C 档预测近零（Q<1），按旧参考各补 1 个会多补；这些行应归「不补/观察」。

## 4. 限制

1. 精确 97/157 需要日粒度曲线，本地只有周桶；
2. 需求来自未提升为 CURRENT 的 r4（与 h180 包同源，manifest 有记录）；
3. SS 只覆盖需求侧误差，供应侧延误体现在「最晚下单日已过 48/48」；
4. IP 只认已证 → Q 偏保守（偏大）；
5. 原型不是采购单。
