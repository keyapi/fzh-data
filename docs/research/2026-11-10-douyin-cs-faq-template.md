# 抖店飞鸽客服话术表（模板）

> 2026-11-10。配套阅读：[生态调研 §4](2026-11-10-douyin-live-commerce-ecosystem.md)（客服三条路线与官方机器人边界）。
> **用途**：今天就能填进抖店后台「智能机器人」；将来换 ISV 或自研飞鸽插件时，这张表原样复用，不用重做。

---

## 一、三条硬纪律（先看，再填）

1. **不承诺做不到的事** —— 不写"保证 48 小时到"、不写"绝对不掉色"。平台考核按**真实揽收**，承诺越满，投诉越多。
2. **不做站外导流** —— 不出现微信号、手机号、二维码、"加我""私聊下单"。抖音对站外导流处罚很重。
3. **不用绝对化用语** —— "最好""第一""100%""国家级"违反《广告法》，AI 自动回复同样受约束。

> 另：**不要让机器人碰个人信息**。买家报手机号/地址时，回复统一为"请您在订单里填写，客服这边不需要您的地址哦"。

---

## 二、字段定义（对照行业标准，不是自创）

> 这套字段不是我发明的，是对齐成熟的 FAQ 知识库标准：**钉钉开放平台「标准问答对」**（标准问题必填 + 相似问题非必填）、**电商智能客服知识库设计通用做法**（标准问题 + 相似问法 + 答案）、**Intercom**（FAQ 问题要用客户原话，从真实会话里取）、**人人都是产品经理知识库方法论**（树状分类 + 多维标签）。

| 字段 | 行业对应 | 说明 | 示例 |
|---|---|---|---|
| `id` | 记录编号 | 唯一编号，不要复用 | `A-01` |
| `category` | 分类/一级类目 | 便于统计命中率与分工 | 发货物流 |
| `standard_question` | **标准问题**（必填） | 一句规范问法，用客户的原话写 | 什么时候发货？ |
| `similar_questions` | **相似问法**（选填） | 用 `\|` 分隔，越具体越好；这是"触发词"的正规叫法 | 什么时候发\|几天发货\|发货时间 |
| `answer` | 标准答案 | 口语化，不超过 80 字 | 亲，现货订单 48 小时内发出… |
| `auto` | 是否自动答 | 对应官方「回复方式」：自动发送 / 仅推荐 | `Y` / `N` |
| `handoff` | 转人工条件 | 命中即转，对应官方「转人工策略」 | 买家追问具体到货日 |
| `scope` | 适用范围 | 商品/类目，`*` 表示全部 | `*` / 靠枕类 |
| `owner` | 负责人 | 谁维护 | 客服主管 |
| `updated` | 更新日期 | 最后修改 | 2026-11-10 |

## 四、转人工规则（建议直接照此配置）

| 触发条件 | 处理 |
|---|---|
| 命中 `handoff` 非空 | 立即转人工，机器人不再追问 |
| 出现"退款/投诉/起诉/曝光/12315" | 最高优先级转人工 |
| 买家连续 2 次表达不满（负面情绪词） | 转人工 |
| 涉及定制、改址、加急 | 转人工 |
| 机器人连续 2 次答非所问（买家重复问） | 转人工 |
| 非营业时间 | 机器人先接，留言 + 次日优先回 |

## 五、维护流程（不做这步，三个月后表就废了）

1. **每周**：导出飞鸽会话，统计「机器人回答后买家仍转人工」的 top 10 问题 → 补话术或改判定。
2. **每两周**：把新出现的高频问题加进表，`owner` 与 `updated` 必须填。
3. **每月**：复核 `auto=Y` 的条目，凡是近 30 天引发过投诉或退款的，降级为 `N`。
4. **每次平台规则变更**（发货时效、售后政策）：同步改 A、E 两类。

## 七、给运营同事（ZQ）的操作手册：飞鸽后台怎么配

> 依据：抖音电商学习中心官方文档《提升人工客服回复效率——飞鸽机器人智能辅助自动回复》（2022-04-12）＋《一文搞懂飞鸽机器人转人工配置》。
> 本手册只写**官方后台里点得到的路径**，不涉及任何插件或脚本。

### 7.1 第一步：开通并开启「智能辅助」

1. 抖店后台 → **客服** → **飞鸽客服管理** → 进入 **机器人设置**。
2. 点击开关**开通「飞鸽机器人」**（免费，无任何收费项）。
3. 打开 **「智能辅助接待模式」** 开关。
4. 两种辅助能力，按需选：
   - **推荐话术回复**：输入框上方推荐，客服点一下就发；
   - **自动话术回复**：机器人直接发（准确率高的问答才会自动发）。

### 7.2 第二步：逐条录入知识库（本表 `auto=Y` 的 30 条）

1. 进入 **机器人设置 → 知识库**（有的版本叫「问答管理」）。
2. 新增一个问答场景，按本表填：
   - **标准问题** ← `standard_question`
   - **相似问法** ← `similar_questions`（用 `|` 分隔，逐条粘贴进去）
   - **答案** ← `answer`
   - **回复方式** ← `auto=Y` 选"自动发送"；`auto=N` 选"仅推荐/不自动回复"
   - **分类** ← `category`
3. 保存后**马上用测试号问一遍**，确认命中的是正确答案。

> ⚠️ **官方后台不支持 Excel/CSV 批量导入**（截至 2026-11-10，官方文档只提供「在知识库中逐条设置」，未见导入入口）。所以上面的表是**录入对照清单**，不是「一键导入文件」。
> 30 条手工录入约 1–1.5 小时；**先录 A、E 两类**（发货物流 + 售后退换）——它们占咨询量最大。

### 7.3 第三步：配置转人工（本表 `handoff` 非空的 15 条）

1. 进入 **机器人设置 → 转人工配置**（官方专文《飞鸽机器人转人工配置》）。
2. 设置触发关键词，建议至少包含：
   - `人工` `转人工` `客服` `投诉` `举报` `退款` `起诉` `12315`
   - 以及本表 `handoff` 栏里的条件词（如"改地址""破损""发错""发票""定制""加急"）。
3. 设置**重复回复暂停次数**与**撤回回复停止次数**（高级设置 → 智能辅助设置）：
   - 同一会话同一答案超过 N 次就暂停自动发；
   - 客服连续撤回 M 次，该答案对当前客服停止自动发。

### 7.4 第四步：一线客服的日常开关

- 右侧「智能助手」面板顶部有**设置图标**，可关闭自己这个子账号的智能辅助；
- 单个买家可以关掉"该买家自动回复"，改成机器人只提示、客服自己发（遇到情绪激动的售后尤其要关）；
- 机器人发错可**手动撤回**，撤回后该答案不再自动发；
- 面板里可点 **「机器人实时调优」**，直接改答案——改完记得同步回这张表。

### 7.5 第五步：看什么指标（一周后复盘）

| 指标 | 在哪看 | 目标 |
|---|---|---|
| **3 分钟回复率** | 抖店后台 → 数据 → 客服分析 | 不低于同行线（第三方说法：<70% 会限流，需以官方最新规则为准） |
| 机器人应答率 / 转人工率 | 飞鸽数据面板 | 转人工率过高 → 补话术；过低 → 检查是否硬答复杂问题 |
| 撤回次数 | 智能助手面板 | 某条频繁被撤回 → 该条改文案或降级为 `auto=N` |

> 飞鸽考核时段为 **8:00–22:59**（第三方整理，需以官方为准），夜间咨询建议配离线回复。

**若将来交给 ISV 做导入，转成 CSV 时的格式约定**：

- 编码 **UTF-8 with BOM**（Excel 中文不乱码）；
