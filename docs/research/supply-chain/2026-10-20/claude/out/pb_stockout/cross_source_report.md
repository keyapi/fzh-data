## 3b. 关键观测（三源不一致）

- WX 源仓口径下，名单内 **没有任何 SKU 在任何一个快照日合计为非正或 1–3 低**（非正 0 格、低 0 格）；但同一窗口内这些 SKU 的 PB 订单被**反复阻断**（名单内事件 152 次）。
- 同时，WX 的可用量主要落在 `皮壳仓库`（组件仓）等非成品仓：SKU 合计为正≠PB 成品可发；单仓 0 的格数每 SKU 有 11–44 个，但本表不按单仓下断货结论。
- 因此三源**没有同向样本**：WX 不能证实断货，只能用 checked0stock 与发货断档描述受阻区间。


## 4. 可信度分级

三源同向 **高 0**；两源 **中 3**；仅一源 **低 24**。

同向定义：WX 有非正/低快照、checked0stock 有事件、发货窗口内有断档。
**高可信为 0 的原因**：WX 源仓合计在窗口内始终为正，三源不可能同向；这不是缺数据，而是三源本身不一致。

## 5. 红线逐条检查

1. **通途正几件不自动判恢复**：1–3 件一律记 `low_1_3`，**不当作恢复**；本批名单内低库存快照 0 个、非正快照 0 个，因此没有任何「由正转恢复」的判定被使用。
2. **低销量不直接判断货**：PB 累计销量 < 100 的 SKU 标 `low_volume=yes`，不进入断货结论；名单内此类行 2 个。
3. **人工宽表 scope 未证不并入**：`warehouse_scope != source_warehouse` 的 137241 行全部排除，只在名单里记数量。
4. **不填每日假库存**：输出只有快照点与区间，没有按天插值。

## 6. 已知限制

- WX 源仓快照只覆盖 2026-06-09..2026-07-31 共 11 个日期；此后的宽表日期范围未证，未并入。
- checked0stock 事件跨 2023–2026，与 WX 窗口只有部分重叠；跨窗口的事件只用于「是否存在断货历史」，不用于区间计算。
- 发货断档按月判断，月内节奏不可见。
- 本报告不评价 WX/LH 谁更好，只给事实与区间。
