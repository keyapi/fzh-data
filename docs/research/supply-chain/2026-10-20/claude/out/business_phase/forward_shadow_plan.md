# 前向影子方案

> 目的：在**未来真实到来的月份**上，用同一套嵌套规则观察“选择流程 vs 固定 MA3 / naive”的
> 差异，决定是否更换默认预测方法。
> 当前主表沿用 AutoETS 只是**规则默认（裁定 A）**，不是效果改进；在本文的判定条件满足前，
> 不得把任何候选称为“更好”。
> 口径：WAPE 是加权绝对百分比误差，不是“错 SKU 比例”或“准确率”，也没有通用阈值。

## 2. 每次必须记录什么

| 记录项 | 粒度 | 备注 |
|---|---|---|
| 各候选 WAPE | 每个候选 1 组 | 共同子集 = 七个候选均有预存预测的同一批 (SKU, origin) 单元格；字段 `candidate_metrics.<候选>.wape_with_zero`（零需求保留在分子）与 `.wape_excluding_zero`（仅非零实际量，对照口径）；某候选在该块不可评时写 `unavailable_candidates` 的原因，不猜 |
| 各候选 Bias | 每个候选 1 个值 | 字段 `candidate_metrics.<候选>.bias` = `Σ(F−A)/ΣA`，读作方向，不读作准确率 |
| 各候选上限覆盖率 | 每个候选 1 个值 | 字段 `.upper_coverage`：实际 ≤ 点预测（单边上界）的单元格占比；**只作观察，不构成保证** |
| 被选中模型 | 每个 SKU 1 个 | 含内层选模理由（mean\|err\|/A 与窗口数）；字段见预存文件 `selection` |
| 零分母单元格数 | 每个候选/每块 | 字段 `.zero_count` 与 `.zero_share`（占比 = 零分母格数 / 该块共同可评格数）；仅当某聚合的总实际量为 0 时该聚合才无定义、单独列出且不参与计算 |
| 各候选样本量 | 每个候选/每块 | 字段 `.n_cells`；七个候选必须相等（同一共同子集），不等即报告为异常 |
| 失败与 fallback 次数 | 按模型×原因 | `tiny_datasets`、`KeyError`、`history_lt_*` 分开计数 |
| 与 MA3 / naive 的差异 | 每块 1 组 | 含重抽 SKU 的 5–95% 区间，迭代次数固定 300 |

**零分母口径（与 T12 修正后一致）**：

1. 零实际量单元格的预测误差**保留在 WAPE 分子**（`Σ|F−A|` 中的 `|F|` 照算），不剔除；
2. 仅当某个聚合（候选 × 块／分层）的**总实际量为 0** 时，该聚合的 WAPE 才无定义，
   单独列出、**不参与任何计算**；
3. 每次记录必须写明零分母单元格的**数量与占比**（占该块可评单元格数）；
   **T24/T25**：脚本已输出数量与占比（字段 `.zero_count` / `.zero_share`，
   占比 = 零分母格数 / 该块共同可评格数）。
4. 其余记录项、执行时间与执行者、§3 判定规则与阈值均保持不变。

## 3. 判定规则（改默认的唯一路径）

同时满足以下三条，才**可以提议**更换默认模型：

1. **连续 3 个月**（三次影子评估）选择流程相对同一基线的差异**同向**；
2. 每三次中，差异的 **5–95% 区间不含 0**；
3. 数据负责人复核记录完整（零分母、失败、fallback 均无遗漏）。

满足后仍只是“提议”：是否更换由业务决定；未满足则**继续维持规则默认 AutoETS**，
并在下一次月度记录中写明“未满足判定的原因”。

## 4. 红线

- **旧测试期只作探索**：2025-10..2026-03 的结果不进入改默认判定，也不得称为留出验证。
- **不写评价性结论**：不使用“改进 / 稳健 / 分仓有效 / 独立验证”等说法，只记录
  “在未见样本上的差异与不确定性”。
- **WAPE 不是准确率或错 SKU 比例**，也没有通用阈值；跨层比较必须同时给出样本量。
- 不得用一次月度结果直接改默认，不得用测试结果反向挑选模型。
- 影子方案只产出评估记录，不产出订单、不排产、不改主表数量。

## 5. 记录落点与归档

- 每月输出：`forecast_eval/shadow_YYYY-MM.json` + 一段文字记录（写入当月 review 记录）。
- 三次完成后汇总一份 `shadow_decision_YYYY-MM.md`，逐条对照 §3 的三条判定。
- 所有记录随 git 提交；数据源仍为只读，原始明细不入库。
