## 5. 三条事实（附边界）

1. **显式关联只能靠 WO/DN**：外部 226/294（76.9%）、内部 1829/2310（79.2%）行有关联证据；其余 **68 / 481** 行记「未观测」。来源拆解：SO `po_no` 解析到 EN PO —— 外部 0 / 内部 0 行（**外部 197 / 内部 1381 行有 `po_no` 但无同名 PO**，实测 `po_no` 是客户订单号不是 EN PO 单号）；Delivery Plan 关联 0 / 0 行；WO 按 `sales_order` 且同物料 215 / 1438 行；DN 按 `so_detail` 184 / 1328 行。
2. **守恒**：有显式 DN 的行里，外部 matched 184、field_mismatch 0；内部 matched 1328、field_mismatch 0；无 DN 可核验的外部 110、内部 982 行；DN 只有 SO+物料级关联且无法归属的 外部 0 / 内部 0 行。`delivered_obs + remaining_obs = demand` 恒成立，真正被检验的是它与存储 `delivered_qty` 是否一致。
3. **供给/需求比值**：可归属样本 外部 184 行、内部 866 行；中位数 外部 1.00、内部 1.00；其中恰好等于 1.0 的外部 181 / 内部 862 行；>1.2 外部 3 / 内部 2 行，<0.9 外部 0 / 内部 1 行；共享未计入 外部 0 / 内部 502 行，UOM 不一致 外部 0 / 内部 0 行。比值只说明单据上的数量关系，**不**说明库存是否真实超补或缺补。

## 6. 方法要点

- 只认显式字段：SO 表头 `po_no`、WO 表头 `sales_order`、DN `so_detail`/`against_sales_order`、DP `so_detail`；**不按同物料推断**。
- 同一 `po_no` 被多张 SO 引用、同一 WO 面对同一 SO 多行同物料、DN 仅 SO+物料级关联——都记为共享/无法归属，**不重复计入**任何单行比值。
- 有 PO 又有 WO 的行记 `multi_source`，**不把两者相加**（会重复计算）。
- WO 只有**已提交**(docstatus=1)的计划量进入比值；草稿量单列 `wo_draft_qty`，已取消 WO 只计数不求和。`produced_qty` 仅记录——既往核查已发现该字段会失真。
- 「显式关联」只认**能解析到具体单据/行**的证据：有 `po_no` 但查不到同名 PO 不算关联。
- 分页按 `name asc, idx asc` 稳定排序，子表行 id 兜底去重；CSV 排序含行哈希，保证可复现。
- 只读；CSV 只含哈希化 SO/行标识与物料编码，不含客户名与单据号。
