## 证据等级

| 等级 | 含义 |
|---|---|
| A | 一手数据 / 同行评审 / 官方规范 |
| B | 独立机构评测 / 可复核方法 / 有代码与数据的工程复盘 |
| C | 厂商文档或案例（只能证明「厂商声称」） |
| D | 博客 / 轶事 / 无方法说明的二手转述 |
