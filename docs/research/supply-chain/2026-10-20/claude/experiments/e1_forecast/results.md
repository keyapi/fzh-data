# E1 预测基线回测 — PB 楔形枕 8 SKU

> 数据：通途订单月表 `通途订单202301`–`202607`（43 张），按「发货日期 / 通途SKU / 发货数量 / 发货仓库」聚合到 SKU × 月。
> 切片：8 个床楔形枕头 SKU；主口径 `qty_daneey`（美中 Daneey 仓族），敏感性口径 `qty_all`（全仓）。
> 只读；原始数据与汇总数据见 `data/wedge_{raw,monthly}.csv`，拉取日志见 `data/pull_log.txt`。

## 1. 结论先行

1. **组合法（ens5）聚合 WAPE 0.441，比 naive 的 0.562 低 21.5%**，满足「≥10%」的通过线。
   组合 = `median(MA3, MA6, MA12, Croston, TSB)`。
2. **但没有任何单一方法能稳定排第一**：23 个滚动原点里，最好的单一方法（MA6）只有 26% 的原点排第一；
   ens5 的排名标准差 1.97、进入前三 39%，是「最不坏」的稳定选择。
3. **业务现用的 M1 运行率（12 月均值）WAPE 0.458，只比 ens5 差 3.7%**。
   复杂方法带来的边际收益有限；V1 用 `ens5` 或 `MA6+TSB` 组合即可，暂不需要深度模型/时序基础模型。
4. **组合法整体低估 11.2%**（bias −0.112）。补货场景会放大缺货风险；若目标是服务水平，需要做偏差校正
   （与 03 号调研中「偏差校正比换模型更有效」的结论一致）。
5. **季节性方法在这个切片上失效**：seasonal naive 0.574、M3b 0.588、M2 0.630，均差于 naive。
   原因：历史短（2023-07 起）、断货与到货冲量扭曲了去年同期、且多个 SKU 月销只有个位数。

## 2. 数据与设计

| 项 | 设置 |
|---|---|
| SKU | 2870/2871/2876/2877/2878/2879/2880/2881（通途 SKU 尾 4 位） |
| 历史 | 2023-07 → 2026-07（2023-01–06 无这 8 个 SKU 的发货记录） |
| 粒度 | SKU × 月，发货数量 |
| 主口径 | 美中 Daneey 仓族（`FZH-DANEEY` / `美中-FZH-DANEEY` 等） |
| 滚动原点 | 2024-06 → 2026-02，共 23 个；预测跨度 h=3 |
| 评估单元 | 2,262 个 SKU-原点-方法单元（断货月删失后） |
| 断货删失 | 2880：2026-03/04/05；2878：2026-06/07；2876：2026-05（来源：10-16 决策包三源交叉） |
| 训练 | 每个原点只用该月及以前的数据；M3b 已修正为不使用预测月真实值 |

### 方法

`naive`（最后一个非断货月）、`seasonal_naive`（去年同月）、`MA3/6/12`、
`M1`（近 12 月均值）、`M2`（去年同期 × 近期同比）、`M3`（近 12 月线性趋势外推）、
`M3b`（同日历月历史均值，仅用 origin 之前）、`Croston`（简化经典）、`TSB`（α=β=0.3）、
`ens3 = median(MA6, Croston, TSB)`、`ens5 = median(MA3, MA6, MA12, Croston, TSB)`。

## 4. Pass / Falsify

| 判据 | 结果 | 判定 |
|---|---|---|
| 最佳方法聚合 WAPE 比 naive 低 ≥10% | 0.441 vs 0.562（−21.5%） | **PASS** |
| 排名稳定（单一方法持续领先） | 最好单一方法仅 26% 原点排第一；ens5 排名标准差 1.97 | **FAIL（严格口径）** |
| 分 SKU 稳定 | 2880 组合优；2878 MA6 优；低量 SKU 全部高误差 | 部分 |

**结论**：**「用简单统计方法能显著优于 naive」成立；「存在一个稳定的单一最优模型」被证伪。**
生产上应采用**组合法 + 月度回测**，而不是挑一个模型长期使用；并且把评估指标定在聚合层（WAPE/Bias）
与服务水平上，不要用单 SKU 的 MAPE 排名。

## 5. 限制

1. 2026 年之前的断货窗口没有三源交叉标签，backtest 未删失，可能低估历史需求；2026 年的断货月已删失。
2. `qty_daneey` 在 2023-07–09 为 0（当时货在美西备用仓）；主口径从 2023-10 起才有意义，
   但模型仍会看到前面的 0。`qty_all` 敏感性结论一致。
3. 销量用**发货量**代理需求；PO 下单量、平台结算口径不同（见 `01-existing-assets.md` §6）。
4. 只有 8 个 SKU、43 个月、无促销/节假日/价格特征；结论不能直接外推到全品类。
5. 2026-10 月表不存在，最近一个月数据缺失。
6. 未测试时序基础模型（TSFM）与 LightGBM；本实验只回答「统计基线怎么选」。

## 7. 对 V1 的建议

- 预测器：`ens5`（或 `MA6 + TSB` 两法组合）；每月滚动回测，保留 naive 作为守门基线。
- 治理：聚合 WAPE + Bias + 服务水平（缺货损失/覆盖月数）三项一起看；单 SKU 误差只做诊断。
- 偏差：对 ens5 的 −11% 偏差做显式校正或安全库存补偿，不要静默使用。
- 暂不引入：TSFM / 深度模型 / 自动调参；等基线被稳定击败 >10% 再说。
