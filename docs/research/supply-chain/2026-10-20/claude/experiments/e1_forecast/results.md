# E1 预测基线回测（修正版）— PB 楔形枕 8 SKU

> 数据：通途订单月表 `通途订单202301`–`202607`（43 张），按**发货日期**解析到 SKU × 月。
> 切片：8 个床楔形枕头 SKU；主口径 `qty_daneey`（Daneey 仓族），敏感性口径 `qty_all`。
> 只读；原始数据与汇总数据见 `data/wedge_{raw,monthly}.csv`（不入库），
> 逐 SKU-月数量状态见本地生成的 `data_status.json`（含数量，不入库）；汇总计数见本文。

## 1. 结论先行

1. **修正后，ens5 在 held-out 测试期（2025-07→2026-02，60 个 SKU-原点）WAPE 0.520，naive 0.602，低 13.6%**；
   主口径最佳是 TSB（0.511，低 15.1%）。另两种口径同样通过「优于 naive ≥10%」：`qty_all` ens5 0.416 vs 0.497（−16.3%），
   `qty_daneey/raw` TSB 0.503 vs 0.601（−16.3%，ens5 0.507）。
2. **但验证期没有选中 ens5**。验证期（2024-12→2025-06，50 个 SKU-原点）WAPE 最优是 MA3（0.415），
   ens5 为 0.436（与 ens3 同值，排序第 4）。按验证期选择 MA3，测试期只有 0.575，**三种口径下都差于 ens5**
   （ens5 分别 0.520/0.416/0.507）。说明 7 个 origin 的选择规则不稳定，不能声称「验证选出 ens5」。
3. **TSB 修复是实打实的**：在完全相同的测试单元上，旧 TSB（零需求期把 d 也衰减）WAPE 0.521，
   修正后 0.511；ens5 仅 0.522→0.520（中位数组合稀释了单方法修复）。
4. **聚合优势不是每个 SKU 都成立**：测试期 2880 的 naive（0.162）明显优于 ens5（0.288）；
   2871/2876/2877 的 ens5 也差于 naive。优势主要来自 2870、2878、2879、2881。
5. **诚实结论**：修正后仍支持「简单统计组合显著优于 naive」，但**不支持「存在稳定最优模型」**；
   ens5 可作为稳健默认候选，但必须保留 naive 守门并持续滚动回测，不能宣称它被验证期选中。

## 2. E1 修正记录

| Review 项 | 处理方式 | 证据 / 位置 |
|---|---|---|
| 1. TSB 实现错误（d 不应随零需求衰减） | 重写：z 初值=非零期占比，d 初值=非零需求均值；非零期同时更新 z、d，零需求期只 `z←(1−α)z`，d 不变；预测 `z·d`；α=0.3 | `backtest.py:tsb()`；同单元旧 0.521→新 0.511 |
| 2. 缺失月被当 0 | 每个 SKU-月打 `observed / zero_confirmed / pre_launch / missing`；`missing` 不进训练、不计入实际值；目标窗含 missing 的单元整格剔除 | `data_status.json`；本次 43 张月表全部拉取成功，missing=0，parse_error=0 |
| 3. `date[:7]` 日期归属 | 新增 `parse_month()`，支持 `YYYY-MM-DD`、`YYYY/M/D`、点号、中文日期、datetime；`pull_data.py` 与 `backtest.py` 都按**发货日期**归月 | raw 重聚合 vs 既有 `wedge_monthly.csv` 不一致=0 |
| 4. 早期 origin 历史不足 | 最小训练长度 18 个已确认月；不足的 origin/SKU 丢弃并记录 | 丢弃 origin：2024-06…2024-11（6 个，无任何 SKU 达标）；另丢 54 个 SKU-原点 |
| 5. 选择与验证未隔离 | 固定切分：验证 2024-12→2025-06 选方法；测试 2025-07→2026-02 只报告；另列测试期 oracle 仅供诊断 | `results_*.json` 的 `validation` / `test` / `selection` |
| 6. 重跑并重判 ens5 | 三口径/模式全部重跑；ens5 在测试期 2/3 口径为最佳或次佳，但验证期未选中，判定见 §5 | 下表 |

## 3. 数据状态与回测设计

| 项 | 设置 |
|---|---|
| SKU | 2870/2871/2876/2877/2878/2879/2880/2881 |
| 月表范围 | 2023-01 → 2026-07（43 张，全部拉取成功） |
| 状态（qty_all） | observed 264、zero_confirmed 26、pre_launch 54、missing 0 |
| 状态（qty_daneey） | observed 239、zero_confirmed 51、pre_launch 54、missing 0 |
| 上市月 | 2870/2876/2877=2023-07；2871/2879/2880/2881=2023-08；2878=2023-09 |
| 滚动原点 | 2024-06 → 2026-02，共 21 个；h=3 |
| 最小训练 | ≥18 个已确认月（observed+zero_confirmed，剔除 missing/pre_launch/删失） |
| 验证期 | 2024-12 → 2025-06，50 个 SKU-原点（早期 SKU 未满 18 月，故各 origin 只有 3/7/8 个 SKU） |
| 测试期 | 2025-07 → 2026-02，60 个 SKU-原点（删失 4 格：2880 三个 origin、2876 一个 origin） |
| 断货删失 | 2880：2026-03/04/05；2878：2026-06/07；2876：2026-05（censored 模式） |

**分类口径**：2023-01–06 所有 SKU 尚未上市，记为 `pre_launch`——这是「确认没有可发需求」，
不是 missing，也不等同于正常需求期的 0，因此训练时剔除。上市后月表成功拉取但该口径为 0 的月份才是
`zero_confirmed`（例如 `qty_daneey` 在货走美西备用仓的 2023-07–09 仍按 0 处理）。
`missing` 仅用于月表打不开/读取失败/缺列——本次没有出现；若出现，该月既不补 0，也不参与训练和评估。

**方法**：naive、seasonal_naive、MA3/6/12、M1（=MA12）、M2、M3、M3b、
Croston（经典：仅非零期更新规模与间隔，间隔含零需求月、不含 missing）、TSB（α=0.3）、
`ens3=median(MA6,Croston,TSB)`、`ens5=median(MA3,MA6,MA12,Croston,TSB)`。

## 4. 结果

### 4.1 验证期（用于选方法，qty_daneey/censored）

| 方法 | WAPE | Bias | 方法 | WAPE | Bias |
|---|---:|---:|---|---:|---:|
| **MA3（选中）** | **0.415** | −0.153 | ma12 / M1 | 0.468 | −0.329 |
| Croston | 0.428 | −0.247 | M3 | 0.491 | −0.138 |
| ens3 | 0.436 | −0.246 | seasonal naive | 0.519 | −0.386 |
| **ens5** | **0.436** | −0.248 | M2 | 0.531 | −0.084 |
| TSB | 0.437 | −0.236 | M3b | 0.553 | −0.442 |
| MA6 | 0.437 | −0.257 | naive | 0.580 | −0.094 |

### 4.2 测试期（held-out，qty_daneey/censored，60 格）

| 方法 | WAPE | Bias | 相对 naive |
|---|---:|---:|---:|
| **TSB** | **0.511** | −0.029 | −15.1% |
| MA12 / M1 | 0.518 | −0.053 | −14.0% |
| **ens5** | **0.520** | −0.014 | **−13.6%** |
| Croston | 0.530 | +0.002 | −12.0% |
| MA6 | 0.565 | +0.025 | −6.1% |
| MA3（验证期选中） | 0.575 | −0.032 | −4.5% |
| naive | 0.602 | −0.086 | — |

测试期 oracle 最佳单方法为 TSB；ens5 与前两名（TSB 0.511、MA12/M1 0.518）只差 0.009。
验证期选择的 MA3 在测试期排在 ens5 之后，说明「7 个 origin 选单一模型」过拟合。

### 4.3 三口径/模式重跑（测试期）

| 口径 / 模式 | 测试最佳 | WAPE | naive | ens5 | 选中方法（验证期） | 选中方法测试 WAPE |
|---|---|---:|---:|---:|---|---:|
| qty_daneey / censored | TSB | 0.511 | 0.602 | 0.520 | MA3 | 0.575 |
| qty_all / censored | ens5 | 0.416 | 0.497 | 0.416 | MA3 | 0.488 |
| qty_daneey / raw | TSB | 0.503 | 0.601 | 0.507 | MA3 | 0.563 |

三种口径下，验证期选中的 MA3 在测试期都不如 ens5——这是本次最重要的负面结论。

### 4.4 修正前后对照

| 版本 | 样本 | ens5 | naive | 改善 |
|---|---|---:|---:|---:|
| 修正前（旧快照） | 23 origins（2024-06→2026-04），174 格/方法，同一样本内选方法 | 0.441 | 0.562 | −21.5% |
| 修正后（验证+测试合并） | 15 origins，110 格/方法 | 0.481 | 0.591 | −18.6% |
| 修正后（仅 held-out 测试） | 8 origins，60 格/方法 | 0.520 | 0.602 | −13.6% |

> 三者样本不同，**不能直接相减归因**。旧 0.441 含早期历史不足的 origin、TSB 的 d 衰减 bug，
> 且方法选择与评估未隔离。修正后在更严格的设计下，ens5 的优势缩小到 13.6%，但仍超过 10% 线。

## 5. Pass / Falsify

| 判据 | 结果 | 判定 |
|---|---|---|
| 最佳方法测试期 WAPE 比 naive 低 ≥10% | TSB/ens5 三种口径均达标（−15.1%…−16.3%） | **PASS** |
| 存在一个稳定的单一最优模型 | 验证选 MA3，测试 TSB/ens5 更优；分 SKU 各有赢家 | **FAIL** |
| 验证期选择规则可外推 | 选中 MA3 在三种口径测试期均差于 ens5 | **FAIL** |
| ens5 仍是「最佳」 | 测试期 1/3 口径第 1（qty_all），另两口径第 2–3；验证期第 4 | **部分成立**，不是稳定最佳 |

## 6. 限制

1. 验证期只有 50 个 SKU-原点（早期 SKU 未满 18 月），选择噪声大；本实验不能证明任何单一模型长期最优。
2. 只有 8 个 SKU、15 个有效 origin；结论不能直接外推到全品类。
3. 2026 年之前的断货窗口没有三源标签，未删失，可能低估历史需求；2026 年断货月已删失。
4. `qty_daneey` 仍包含 `FZH-DANEEY-半成品仓/皮壳仓库/退货产品仓` 的少量发货（全部 8 SKU 合计约 19 件），
   口径未在本轮改动，属既有定义。
5. 销量用发货量代理需求；PO 下单量、平台结算口径不同。
6. 无促销/节假日/价格特征；未测 TSFM/LightGBM；未做显著性检验。
7. `missing` 路径已实现但本次 43 张月表全部成功，真实缺失场景未被实测。

## 7. 复现

```bash
cd docs/research/supply-chain/2026-10-20/claude/experiments/e1_forecast
uv run python pull_data.py            # 只读拉取（需父仓库 secrets）
uv run python backtest.py --measure qty_daneey --mode censored
uv run python backtest.py --measure qty_all    --mode censored
uv run python backtest.py --measure qty_daneey --mode raw
```

可选参数：`--min-train 18`、`--val-start/--val-end`、`--test-start/--test-end`。
输出 `results_<measure>_<mode>.json`（含 validation/test/combined 与丢弃清单）和 `data_status.json`。

## 8. 对 V1 的建议

- 预测器：保留 **naive 守门**；候选用 **TSB** 或 **ens5**。测试期 TSB 略好，但 ens5 对单方法失误更稳，
  两者差距 0.009，不足以强推一个；建议先用 ens5，按月滚动回测监控。
- **不要**用「最近 7 个 origin 选单一模型」直接上线——本次该规则三种口径全部跑输 ens5。
  若要做选择，至少用 expanding-origin（只用 t 之前的数据）并设最小样本。
- 偏差：测试期 ens5 bias 仅 −1.4%，比旧快照的 −11% 明显改善；验证期 −24.8%，仍需监控。
- 暂不引入深度模型/TSFM；先把滚动回测、缺失月状态和服务水平指标做扎实。
