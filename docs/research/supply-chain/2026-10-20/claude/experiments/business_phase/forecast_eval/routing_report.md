# A 包：预测分型路由与全局模型对照

> 只本地离线；DB 只读。所有方法在同一批 (SKU, 起点) 单元、同一个 90 天窗口上评分；路由只用起点之前的数据。

## 0. 运行参数

- 耗时 **11.5 s**（预算 900 s）；单元 **2763** 个（共同子集）；评分 SKU **774** / 候选 1237
- 起点（实际使用）：2025-03, 2025-06, 2025-09, 2025-12, 2026-03；窗口 90 天；最少历史 18 个月
- 全局树模型：可用；版本 {'mlforecast': '1.1.0', 'lightgbm': '4.7.0', 'pandas': '3.0.2'}；每起点预测行 {'2025-03': 1620, '2025-06': 1812, '2025-09': 1972, '2025-12': 2552, '2026-03': 3096}
- 环境：本轮为对照安装 `mlforecast==1.1.0`（lightgbm 4.7.0 已有）；`uv pip install` 曾临时降 pandas 到 2.3.3，但 `uv run` 按项目锁定仍用 pandas 3.0.2，树模型在 3.0.2 下跑通（版本见上行）。

## 1. 特征可得性（SKU × 仓 × 品类）

| 特征 | 可得 | 来源 |
|---|---|---|
| 历史长度（月） | 是 | monthly_series 首月到起点 |
| 零占比 | 是 | 同上 |
| 间歇度 ADI / CV² | 是 | 非零月间隔与波动 |
| 季节强度 | 是 | 月份均值方差占比（需 ≥24 月） |
| 销量分层 | 是 | 训练窗累计需求 |
| 仓库数 / 主仓占比 | 是 | monthly_series.sku × warehouse |
| 品类 | 是 | item_attr.item_group（经 destinations 映射） |
| 促销/折扣 | **否** | DB 无字段 |
| 价格与价格变动 | **否** | DB 无字段 |
| 上新/停产日历 | **否** | DB 无字段 |
| 竞品活动 | **否** | 无数据源 |

> 不可得项不参与路由，也不做代理变量臆造。

## 2. 路由规则与训练内选模

| 分型 | 判定（仅用起点前数据） | 候选 |
|---|---|---|
| short | 历史 < 24 月 | tsb, naive |
| intermittent | 零占比 ≥ 0.4 或 ADI ≥ 2.0 | tsb, croston |
| seasonal | 季节强度 ≥ 0.3 | seasonal_naive, seasonal_yoy |
| simple | 其余 | naive, ma3 |

- 型内取舍：在起点前 3 / 6 个月各做一次内层回测，取 MAE 更低者；内层窗口必须在起点内结束（无外层信息）。

- 分型分布：short 281、simple 209、seasonal 173、intermittent 111；选模来源（按单元）：{'inner_mae': 2763}

- 评分 SKU **774**；未评分 **463** 个；原因计数：{'history_lt_min_train': 463}
- 未评分不进入任何指标；原因只写观测（历史不足 / 无共同单元）。

## 5. 口径更正

- `attribution_report.md` 的共同 **151 SKU / 446 窗**上，MAE 为 **TSB 12.063、SES 12.694、类目借力 13.118、naive 14.299**。
- 因此此前「类目借力最差」的结论**失效**；本轮只用它作对照，不宣称任何方法最优或适用所有品类。

## 6. 边界

- 只报未见样本；路由与选模均不使用外层数据。
- 缺促销/价格/上新日历时不编造代理变量；这会让季节性/间歇性判断偏粗。
- 全局树模型是**同一批**数据上的对照，不调参追求最优；其预测行数见第 0 节。
- 单位是 SKU-月（跨仓汇总）；仓库信息只作为特征（仓库数、主仓占比）。
