## 2. 读法（逐列）

| 列 | 怎么读 | 不能怎么读 |
|---|---|---|
| `suggested_qty_or_range` | **建议量或区间**，按数值升序 `最小 ~ 最大`；相等时给单值；HOLD 行写**「不可算（证据不足）」** | 不能当采购量；不能把"不可算"读成 0 |
| `qty_min` / `qty_max` | 升序两端，可直接参与业务判断 | 不能跨 UOM 把不同行的数相加 |
| `need_time` | **需要时间** = 首个出现未履约的月桶（2026-10 剩余 / 2026-11 / 2026-12） | 不是"下单日"，也不是"到货日" |
| `can_make_it` | **能否赶上**：全表都是「无法判断（无 ETA/在途证据，WO not_observed）」 | 不能当成"能赶上"或"赶不上" |
| `forecast_basis` | 依据哪档预测：T5 等效率；逐行标 **AutoETS** 或 **MA3 回退**，附版本 | 不是新模型，也不代表已验证 |
| `stock_basis` | 库存口径：**physical / net / unknown**；unknown 时缺口是两端并列的区间 | 不能把 unknown 当 physical |
| `scenario_id` | 条件行 = `S_phys_overlap0_onhand`；HOLD 行 = `S0_证据不足` | 不能跨情景比大小 |
| `readiness` | **条件**（2,058）/ **HOLD**（251） | HOLD 不是"不需要补"，是"算不了" |
| `forecast_rate` | 预测率（件/月）。**null = 上游缺失，绝不写 0**；真正的 0 有 829 行（真·零预测） | 不能把 null 当 0 |
| `forecast_rate_status` | `ok` 2,058 ／ `null · 缺库存证据` 160 ／ `null · 缺需求依据` 91 | 不能把两种缺失混成一类 |
| `missing_evidence` | 逐行缺证项（预测率缺失 / 库存口径 / 无 WO / SO 重叠 / 去重 / 负率钳 0） | — |
| `reviewer` / `reviewer_note` | **空栏**，留给业务复核人签字与批注 | 签字 ≠ 采购批准（见 §6） |

## 5. 三个代表算例

### 例 1 · 最大缺口（条件）`TT0312614K0064238` @ 美中-FZH-DANEEY

| 环节 | 值 |
|---|---|
| 预测 | 10 月剩余 **51.85** / 11 月 **155.55** / 12 月 **160.73** 件/月（T5 等效率，AutoETS，statsforecast 2.1.1） |
| 库存 | 期初 **112**，口径 `unknown`（available = physical = 112） |
| 供应 | 在手情景 **0 收货**；同批次到货 129；跨批次到货 258 |
| 推演 | 10 月用掉 51.85 → 余 60.15；11 月需 155.55 只满足 60.15 → 未履约 **95.40**；12 月需求 160.73 + 结转 95.40 = **256.13**，无可发 |
| **建议** | **256.1 件**（`qty_min = qty_max`，两端未拉开）；需要时间 **2026-11** |
| 情景敏感性 | 到货成立与否：**256.1 → 127.1（同批次）→ 0（跨批次）** |

### 例 2 · 零缺口（条件）`C/Cord-Black-100-707-wow` @ WayfairCG-Cranbury仓

预测三个月均为 **0**、库存 18 恒定 → 缺口 **0**，需要时间「窗口内无缺口」。
⚠️ `forecast_rate = 0` 是 T5 对该 SKU×仓的等效率为 0，**不等于"不会有需求"**；保留在清单里供业务判断。

### 例 3 · 不可算（HOLD）`C/Cord-DKBlue-100-713-wow` @ 美中-FZH-DANEEY-退货产品仓

`scenario_id = S0_证据不足`；库存字段为空、WO `not_observed`、SO 重叠未证 → 建议量 **「不可算（证据不足）」**；
`forecast_rate` 为 **null**（原因：缺库存证据）。业务只能补证或明确本期不评估。

## 6. 本版能做什么 / 不能做什么

### 能做

1. **给条件建议与需要时间**：每行一个区间或「不可算」，以及首个未履约的月桶。
2. **定位缺证项与责任人**：六类待确认项已按角色分派，可直接拿去催办。
3. **逐行追溯**：预测方法/版本、库存口径、情景、假设、缺证全部在行上。

### 不能做

1. **不能当采购批准**：B 情景 ≠ 采购批准；复核人签字只代表"依据被复核"。
2. **不能跨 UOM 合计**：个/套不同单位，任何"总件数"都无意义（详见 `2026-10-23-map-evidence.md`）。
3. **不能证明到货**：`can_make_it` 全表为"无法判断"，本批没有 ETA/在途/WO 证据。
4. **不能把 271 个扩展候选并入**：三项评审全过 0（库存项因 `uom_basis` 全 unknown 一律未过）。
5. **不能把"不可算"读成 0**：HOLD 251 行是算不了，不是不缺。
6. **不能外推**：只覆盖 8/1 后 39 张有号 DN 的口径与 1,328 母集；8/1 前与多号 DN 分配仍然未知。
