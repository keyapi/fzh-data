# A 包：预测分型路由与全局模型对照

> **离线**：只读 `order_store.duckdb` 与 `destinations.json`；无生产访问、无写库、无扩样。
> 计算 **12.5 s**（预算 900 s）。所有方法在**同一批 (SKU, 起点) 单元**、**同一个 90 天窗口**上评分。

## 1. 特征盘点

| 特征 | 可得 | 来源 |
|---|---|---|
| 历史长度、零占比、ADI/CV² | 是 | monthly_series（截至起点） |
| 季节强度 | 是 | 月份均值方差占比（需 ≥24 月） |
| 销量分层、仓库数、主仓占比 | 是 | monthly_series + 顶部仓 |
| 品类 | 是 | item_attr.item_group（经 destinations 映射） |
| 促销/折扣、价格、上新/停产日历、竞品活动 | **否** | DB 无字段、无数据源 |

不可得项不参与路由，也不做代理变量臆造——这会让季节性/间歇性的判断偏粗。

## 2. 训练内路由（不看外层）

| 分型 | 判定（仅用起点前数据） | 候选 | SKU 数 |
|---|---|---|---:|
| short | 历史 < 24 月 | tsb, naive | 281 |
| simple | 其余 | naive, ma3 | 209 |
| seasonal | 季节强度 ≥ 0.3 | seasonal_naive, seasonal_yoy | 173 |
| intermittent | 零占比 ≥ 0.4 或 ADI ≥ 2.0 | tsb, croston | 111 |

- 型内取舍：在起点前 3 / 6 个月各做一次内层回测（内层窗口必须在起点内结束），取 MAE 更低者。
- **证据**：共同子集的 2,763 个单元**全部**由内层 MAE 选模（`method_source=inner_mae`），没有用外层信息；
  没有足够内层数据的单元回落到该型默认方法（本批 0 个）。

## 3. 同切点比较（共同子集 2,763 单元 / 774 SKU / 5 个起点）

| 方法 | n | WAPE | Bias | MAE | 80% 覆盖率 |
|---|---:|---:|---:|---:|---:|
| naive | 2,763 | 0.606 | 0.008 | 16.371 | 0.796 |
| ma3 | 2,763 | 0.631 | 0.085 | 17.052 | 0.797 |
| tsb | 2,763 | 0.590 | 0.118 | 15.936 | 0.794 |
| croston | 2,763 | 0.597 | 0.160 | 16.118 | 0.794 |
| seasonal_naive | 2,763 | 0.598 | 0.173 | 16.163 | 0.807 |
| seasonal_yoy | 2,763 | 0.601 | 0.052 | 16.252 | 0.790 |
| combo（固定等权） | 2,763 | 0.519 | 0.099 | 14.030 | 0.798 |
| routed（分型+内层选模） | 2,763 | 0.551 | 0.099 | 14.900 | 0.793 |
| **global_tree（MLForecast+LightGBM）** | 2,763 | **0.494** | **-0.049** | **13.336** | 0.794 |

- 起点：2025-03 / 2025-06 / 2025-09 / 2025-12 / 2026-03（2026-06 因目标窗超出标签覆盖被跳过）。
- 覆盖率是**滚动共形带**：只用更早起点的残差分位数（80%），不是模型自带区间；8 个方法的实测覆盖率都落在 0.79–0.81。
- 观测事实：在这批单元上全局树模型 WAPE 最低、偏差最接近 0；固定等权组合次之；路由优于任何单一基模型但不敌后两者。
  这是**本轮子集**的排序，不是"全局树最好"的普遍结论。

## 4. 每 SKU 支持证据与未评分覆盖

- `routing.csv`（1,237 行，SKU 哈希化）：品类、分型、选用方法、选模来源、证据起点、历史长度、零占比、
  ADI、CV²、季节强度、累计需求、仓库数、主仓占比、评分单元数、是否评分、原因。
- **评分 774 / 1,237**；未评分 **463**，原因全部是 `history_lt_min_train`（在任一使用起点都没有 18 个月历史）。
- 未评分不进任何指标；没有用夹值、同品类平均等方式"补"出预测。

## 5. 口径更正（已写入产物）

- `attribution_report.md` 的共同 **151 SKU / 446 窗**上，MAE 为 **TSB 12.063、SES 12.694、类目借力 13.118、naive 14.299**。
- 因此此前「类目借力最差」的结论**失效**；本轮只把它当对照，不宣称任何方法最优或适用所有品类。

## 6. 过程中发现并修掉的问题

1. **窗口求和 vs 月度均值**：初版把预测窗口算成"加权平均"，而实际值是"加权求和"，导致 Bias 系统性 −0.6。
   改成同样求加权和后，Bias 回到 −0.07 ~ +0.26 的合理区间。
2. **内层回测形同虚设**：最初内层起点要求 18 个月历史，绝大多数单元回落到默认方法（`rule_default: 774`）。
   把内层下限降到 12 个月后，2,763 个单元全部有真实的 MAE 选模依据。
3. **未评分统计重复计数**：按"SKU×起点"累加会把同一 SKU 记多次（显示 832 而实际未评分 463）。
   改为按 SKU 去重并给出单一口径原因。
4. **分页/排序**：与 B 包同样的 `name+idx` 超时问题在本任务不涉及（全部本地 DuckDB）。
