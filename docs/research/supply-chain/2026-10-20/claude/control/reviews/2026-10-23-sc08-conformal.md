# SC08：经验/共形分位替换正态 + CV

> 背景：上轮名义 95% 样本外只实现 0.5439–0.6980，误差尾远重于正态（实际/预测 q95 2.0–4.7、q99 13–47）。
> 本轮用**训练侧**「实际/预测」比值的**池化经验分位**替代 CV 标定，给出乘数、内层与外层实现率，并与现规则并列。
> 不替换默认、不出补货量、不 commit。

## 1. 协议（严格训练侧定乘数）

| 环节 | 窗口 | 用途 |
|---|---|---|
| 校准 | 内层切点 2025-09，2025-10..12 的「实际/预测」比值 | **只在这里定乘数**（池化到 tier × universe） |
| 内层评分 | 2026-01..03（同切点，预热 L+R=3 月） | 内层可实现率 |
| 外层评分 | 2026-07..09（切点 2026-03，预热 4–6 月） | **只评不调**，actual 不进入乘数 |

政策统一：`lost_sales`、R=1 月、L=2 月、期初 0、预热 L+R=3 月。
三种 sizing 并列：`CV`（现规则）/ `EMP`（经验分位 `S = f×(L+R)×q_τ`）/ `EMP3x`（比值截顶 3×）。

|---|---|---|---:|---:|
| 790 | T5* | 3.08 / 3.00 | 4.94 / 3.00 | **13.83** / 3.00 |
| 790 | combo | 2.54 / 2.54 | 4.63 / 3.00 | **57.04** / 3.00 |
| 790 | tree | 1.60 / 1.60 | 2.22 / 2.22 | 4.32 / 3.00 |
| 239 | T5* | 3.00 / 3.00 | 4.53 / 3.00 | **19.89** / 3.00 |

> 乘数就是"要多备几倍于预测的货"。τ=99 时 13.8–57×——比值在近零预测上放大，这是数据本身的重尾。

## 4. 事实与边界结论

1. **经验分位确实能提高外层实现率**：790 T5* 从 0.800 → 0.888（τ=0.95）、0.834 → 0.961（τ=0.99）；
   239 combo 从 0.778 → 0.994（τ=0.95）。
2. **但在 τ=95% 的乘数下，多数格仍达不到 95%**：790 三个档外层最高 0.888；239 只有 combo 达到 0.994，
   T5* 0.908、tree 0.857。
3. **要达到硬 95%，必须走 τ=99% 且乘数 4–57×**，平均库存随之变成 **8.8–40 倍**
   （790 组合 16.8 → 677.1；239 组合 13.4 → 555.1）——这是不实用的量级。
4. **截顶 3× 的敏感性**：多数格被 3× 顶住，外层 β 仅 0.61–0.84，仍低于 95%。
5. 诚实结论：**「用经验/共形分位就能硬 95%」在本数据上不成立**——能做到，但代价是把库存翻十几到几十倍；
   在可接受的库存量级内，外层 β 只能到 0.83–0.91。没有通过调参凑到目标。

## 5. 适用与失效条件

- **适用**：预测模型与训练窗不变、误差分布相对平稳（校准窗与评分窗同质）时，池化经验分位可迁移。
- **失效**：
  - **促销/大促**：需求尾部结构改变，校准窗分位低估；
  - **断货删失**：实际销量不是需求，比值被截断，乘数系统性偏低；
  - **短史**：239 档校准样本少，乘数方差大（combo q95 从 4.5 跳到 47）；
  - **换模型/重训**：误差分布改变，旧乘数失效；
  - **近零预测**：比值爆炸，τ=99 的乘数不可解释（这也是 combo 出现 57× 的原因）。
- 不含重训/选模方差；不替换默认；不出补货量。
