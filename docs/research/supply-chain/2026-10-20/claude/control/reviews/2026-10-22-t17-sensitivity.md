## 2. 分类结果（方向 / 区间 / 数量差分列）

| 分类 | 行数 | SKU | 全历史销量 | 销量占比（按 SKU，可重叠） |
|---|---:|---:|---:|---:|
| **① 0/正量分歧** | **308** | 298 | 131,935 | 37.89% |
| **② 同向·区间不重叠** | **74** | 70 | 50,133 | 14.40% |
| **③ 五口径一致** | **1,536** | 970 | 285,225 | 81.92% |
| ④ 同向·区间重叠·有数量差 | 140 | 129 | 68,173 | 19.58% |
| 库存未知（不计算） | 160 | 160 | 149,272 | 42.87% |
| 范围外 C（不计算） | 91 | 91 | 2,102 | 0.60% |

- 判据全部是**结构性**的，不设无依据阈值：方向按建议下限是 0/正量；区间按五口径
  `[下限, 上限]` 是否有共同交集（`:250`）；数量差 = `max(下限) − min(下限)`，
  相对差 = 绝对差 / 下限中位数；一致 = 五个下限在 **0.01** 内相同（数值舍入，不是政策阈值）。
- **清单③ 的 1,536 行全部是全零**（全正量 0 行）：在这组假设下，只要五个口径完全一致，
  就意味着都不需要补货；没有出现“五口径一致且都为正量”的行。因此清单③只能说明
  “这 970 个 SKU×仓在这些假设下对预测口径不敏感”，**不能**当作正确性或采购依据。

## 3. 三张清单

| 清单 | 条数（行 / SKU） | 排序 | 用途 |
|---|---:|---|---|
| ① 0/正量分歧 | **308 / 298** | 建议下限中位数降序，再按销量 | **最高优先人工核查**：口径间对“是否需要补”判断相反 |
| ② 同向但区间不重叠 | **74 / 70** | 数量差绝对值降序 | 复核：方向一致但五口径的区间没有共同量 |
| ③ 五口径一致 | **1,536 / 970** | 销量降序 | 全零=无需动作；本轮无全正量行，故不产生“一致优先核查”清单 |

示例（①，最大分歧）：
`CENCord995-DKGrey-97 / 美中-FZH-DANEEY`，可用 0、去重批 0，仓销量占比 0.9766；
五口径下限 MA3 694.72 / naive 140.47 / seasonal_naive 58.85 / 组合 298.01 / AutoETS 0.00，
数量差 694.72（相对 4.95），区间不重叠。

## 4. 输出字段

`model_sensitivity.csv`（2,309 行）逐 SKU×仓列出：

- 供给：`可用 / 在途 / PO未结 / 情景批 / PO去重状态 / 在途去重状态 / 在产 / MOQ / 包装倍数`；
- 销量：`销量_全历史 / 销量_近6月 / 该仓销量_近3月 / 仓销量占比`；
- 五口径：`建议下限_<口径> / 建议上限_<口径> / 标记_<口径>`（ok / fallback_MA3(原因) / na）；
- 判据：`方向一致性 / 区间重叠 / 数量差_绝对 / 数量差_相对 / 建议中位下限 / 分类 / 说明`。

未知库存与 C 类行的数量为**空**（null），不是 0。

## 5. 局限与措辞红线

- 只回答“换需求口径会怎样”，不回答“哪个口径对”；不是统计证明。
- 不构成采购批准、下单依据或主表修改；主表默认仍是 AutoETS。
- 五口径一致 = 对口径不敏感，**不等于正确**，也不等于可采购。
- MOQ/包装/成本缺失；在产不在快照；共享池默认不跨仓；退货/取消不可观测。
- 零需求单元格按 0 参与；未知库存写 null。
