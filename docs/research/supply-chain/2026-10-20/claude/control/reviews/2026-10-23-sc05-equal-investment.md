# SC05 同等库存 / 同等服务投入对照

> 解开上一轮「各档自己定库存」的混淆。同一冻结单元（`scored790` `e977e8311a69c428` 1,354 单元；
> `verifiable239` `066150d3bf4fb22d` 178 单元）、同一政策（R=1 月、L=2 月、`lost_sales`、
> 期初库存 0）、同一评分窗（2026-04..09 实际需求，预热 L+R=3 月剔除）。
> 不替换默认、不出补货量、不 commit。

## 方法

- **(A) 同 β 目标（95%）**：每档用自己的**预测均值 + 历史 CV** 做蒙特卡洛（200 条路径）标定
  order-up-to 水平 S，使**预测隐含**β 达到 95%；**标定完全不看实际需求**，再用实际需求评分。
  → 回答「同服务目标下谁压货少」。
- **(B) 同库存预算**：把各档 S 统一乘 k，使**平均期末库存**等于上一轮记录的 T5 水平
  （790：**12.55**；239：**13.54**），再比达成 β。→ 回答「同资金谁满足率高」。
- Bootstrap：SKU 整簇 2,000 次（seed 20261023），**只覆盖固定预测下的抽样方差，不含重训/选模方差**。

## 观测（只写事实）

1. **同资金（B）下 T5 的 β 最高**，两个宇宙都显著高于 combo / tree；差距 0.08–0.16。
2. **同名义目标（A）下三档都没有达到 95%**（实现 β 0.58–0.91）：用「预测均值 + 历史 CV」标定出的
   服务水平在样本外会被系统性高估——这本身是一个观察，不说明哪档预测更准。
3. **库存效率**（A）：tree 需要的库存略少（7.27 / 4.84），但 β 也最低；combo 在两个宇宙都需要
   **更多**库存（8.48 / 6.18）却拿不到相应 β。
4. **α 与 β 不一致**：790（B）里 tree 的 α 最高（0.8992）而 β 最低——不存在单一赢家。
5. 结论限定在这两套冻结单元；**790 与 239 分别报，不合并、不外推**。

## 边界

- 标定只用预测与历史 CV，**不使用实际需求**；评分只用实际需求，不含重训/选模方差。
- 不接生产、不改默认、不出补货量；未加 MOQ/箱规/预算；未 commit / 未 push。
- 保护期 L+R = 3 个月 = 预测窗 3 个月，已覆盖；更长保护期须标「未覆盖」。
