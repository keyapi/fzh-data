## 2. 新规则（当前产物即按此运行）

**充足** ⇐ 8 门全 ok ∧ `supply.lower.status == ok` ∧ `demand.upper.status == ok`
∧ `supply.lower.value ≥ demand.upper.value`

**短缺** ⇐ 8 门全 ok ∧ `supply.upper.status == ok` ∧ `demand.lower.status == ok`
∧ `supply.upper.value < demand.lower.value`

其余 → `insufficient_evidence`（待核实），并写明缺哪条证据。

四侧界的口径与可证条件：

| 侧 | 数量 | 何时算 ok |
|---|---|---|
| `supply.lower` | 在手 `available` | G1 身份 ∧ G2 单位已换算 |
| `supply.upper` | `available + PO 原始量 + 在产剩余 + 在途`（每条一次；重复只高估） | G2 ∧ G4 逐笔重叠已核 ∧ G7 无未上账替代供给 |
| `demand.lower` | `D1 = P50`（点估计，不是已证下界） | G8 需求下界已给出 |
| `demand.upper` | `D2 = P50 + 正向 SO` | G8 需求上界已给出 |

**G7 的意义**：Cover 未并入供给时，实际供给可能高于记录之和，所以记录之和**不一定是上界**；
只有“未上账可替代供给缺席”被证明，上界才成立。10/10 的 `cover.absence_proven = false`，
其中 4 个连映射都是 `scenario`。
