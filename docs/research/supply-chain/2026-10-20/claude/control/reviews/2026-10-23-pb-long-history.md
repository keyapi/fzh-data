## 2. 下单需求 / 接单时间　vs　履约发运量 / 时间

PB 渠道 13,380 个订单行全部同时有 `sale_date`（接单）与 `despatch_date`（发运）：

| 发运滞后 | 订单行 | 占比 | 件数 |
|---|---:|---:|---:|
| 0–3 天 | 13,111 | **98.0%** | 13,113 |
| 4–7 天 | 206 | 1.5% | 206 |
| 8–14 天 | 62 | 0.5% | 62 |
| 15–30 天 | 1 | 0.01% | 1 |
| >30 天 | 0 | 0% | 0 |

- **跨月顺延：666 行 / 666 件 = 4.98%**（占全部 13,380 行 / 13,382 件）。
- 结论：**PB 的补发/积欠效应小但非零**。把发运量当月度需求，会把约 5% 的量整体后移一个月；
  在本项目关心的月度尺度上，这足以改变"某月是高还是低"的判断。
- **更要紧的不是滞后，而是缺失**：被断货挡掉、从未生成的订单**根本不在 `gs_orders` 里**
  （这正是删失问题）。所以：
  - 接单量 = 需求的**下限**（缺掉被挡部分）；
  - 发运量 = 接单量再减掉未发部分、再加跨月顺延；
  - **两者都不是需求真值**，本报告任何地方都不用发运量直接当需求。

## 3. 主验收：人工截断实验

### 3.1 设计

在**可靠未受限片段**（无任何 checked0stock 信号月）上人工制造受限段，**原值保留作真值**：

| 维度 | 取值 |
|---|---|
| 序列 | 26 个冻结 SKU 的**接单月序列**（`sale_date`），2023-07 .. 2026-09 |
| 设置 A `interior` | 受限段两侧各有 ≥3 个月观测 → 考"插补/恢复" |
| 设置 B `terminal` | 受限段就在数据末端（到切点为止）→ 考"预测" |
| 放置点 | 每 SKU 3 个（序列末尾 −4 / −10 / −16 个月），避开真实信号月 |
| 受限段长度 L | 1 个月 / 3 个月 |
| **截断比例 r** | 0.0 / 0.2 / 0.4 / 0.6 / 0.8（r = 残留可观测比例，0 = 完全截断） |
| 方法 | `raw`（无视截断）、`lower_bound`（R2 单侧下限）、`neighbor`（受限段外 ±3 月中位数）、`seasonal_naive`（去年同月） |
| 规模 | 1,050 次运行、8,360 个评分格 |

所有方法**都对真值盲**：只看被污染后的序列。

### 3.2 结果（中位相对偏差；负 = 低估）

**设置 B `terminal`（到切点为止，最接近"正在断货"）**

| r | L | raw | lower_bound | neighbor | seasonal_naive |
|---:|---:|---:|---:|---:|---:|
| **0.0** | 1 | **−72.8%** | **−26.2%** | −29.3% | +9.5% |
| **0.0** | 3 | **−84.6%** | **−11.9%** | 0.0%* | +26.9% |
| 0.4 | 1 | −38.3% | −26.2% | −29.3% | +9.5% |
| 0.4 | 3 | −41.5% | −10.4% | 0.0%* | +26.9% |
| 0.8 | 3 | −15.3% | **−5.8%** | 0.0%* | +26.9% |

**设置 A `interior`（两侧都有观测，考插补）**

| r | L | raw | lower_bound | neighbor | seasonal_naive |
|---:|---:|---:|---:|---:|---:|
| **0.0** | 1 | −64.6% | −18.8% | −26.4% | +17.2% |
| **0.0** | 3 | −77.1% | −10.5% | −11.4% | +28.6% |
| 0.8 | 3 | −13.8% | **−4.2%** | −11.4% | +28.6% |

\* `neighbor` 在 terminal/L=3 的中位偏差恰为 0.000：样本里 8% 的格预测值与真值完全相等（整数小销量），
中位数落在 0 上——**不是零误差**，同一格的 ±20% 命中率只有 20.4%，不要读成"完美还原"。

**±20% 命中率（最实用的口径）**

| 设置 | 方法 | r=0.0 | r=0.8 |
|---|---|---:|---:|
| terminal L1 | raw | 4.2% | 29.2% |
| terminal L1 | lower_bound | 22.9% | 22.9% |
| terminal L3 | raw | 2.2% | 38.0% |
| terminal L3 | lower_bound | 24.8% | **27.7%** |
| interior L3 | raw | 3.0% | **42.7%** |
| interior L3 | lower_bound | 27.5% | 30.5% |

### 3.3 结论（主验收）

1. **损失方向成立 ✅**。无视截断（raw）在完全受限时低估 **65–85%**；单侧下限法把同样的情形压到 **10–26%**。
   六组设置里 `lower_bound` 的偏差**全部**小于 raw，方向与 b2217e4d 的修法一致。
2. **完整还原不成立 ❌**。最好的一格（interior L3 r0.8）仍有 **−4.2%** 中位偏差；完全截断时最好 **−11.9%**；
   ±20% 命中率最高 **43%**。**没有任何一档达到"能当需求真值"的水平。**
3. **下限法的偏差几乎不随截断比例变化**（terminal L1 始终 −26.2%）。这不是缺陷，是设计：
   它只要求"真值 ≥ 观测值"，不需要知道丢了多少。代价是**它给的是一个保守下限，不是一个点估计**。
4. **`seasonal_naive` 系统性高估 +9.5% ~ +28.6%**：去年同月常常高于今年，用它填补受限段会把历史整体抬高。
5. **`neighbor` 在短窗 + 有空隙时可用**（interior L3 −11.4%），但**在末端无右邻域时明显变差**（L1 −29.3%）。
6. **校正不伤未受损月**：同一拟合在未受损月的 WAPE——

| 设置 | raw | lower_bound |
|---|---:|---:|
| interior L1 | 0.3745 | **0.3690** |
| interior L3 | 0.3895 | **0.3295** |
| terminal L1 | 0.3566 | **0.3457** |
| terminal L3 | 0.3882 | **0.3297** |

   即下限法**同时改善了未受限月**，不存在"为了修补受限段而搞坏其它月份"的代价。

### 3.4 失败条件（什么时候不能用它）

| 条件 | 现象 | 本批证据 |
|---|---|---|
| **想要点估计** | 下限法给的是下限，不是中心 | 最好 −4.2%，最差 −26.2% |
| **完全截断（r=0）且窗长 ≥3** | 偏差仍在 −10% ~ −12% | terminal L3 r0.0 |
| **受限段贴着数据末端** | 无右邻域，`neighbor` 退化 | terminal L1 −29.3% |
| **强季节、且截断段落在季节峰** | `seasonal_naive` 高估近 30% | interior/terminal L3 +26.9% ~ +28.6% |
| **小销量 / 整数稀疏序列** | 相对误差被放大，中位数可能出现 0 的假象 | neighbor terminal L3 |
| **受限段与非受限段混在同一拟合里** | 本实验已隔离（窗口内无真实信号月），真实场景做不到 | 见 §4 |

## 4. 真实受限段（2026-06 / 2026-07）：只报范围

51 个 SKU×月有真实信号（**不造假真值**，只给观测下限与情景上沿）：

| 量 | 值 |
|---|---:|
| 观测合计（下限，已发运/已下单） | **438 件** |
| 中位情景上沿（同 SKU 同月型未受限月中位） | +**287.5** 件 |
| 上沿情景（同月型 P75） | +**404.5** 件 |
| 无需上修（观测已达参照水平）的行 | **16 / 51** |

- 参照水平 = 该 SKU **未受限月份中同月型**的中位数（无则退回全期正销量中位）；样本数 `ref_n` 逐行记录。
- **口径差（必须说明）**：§1.3 的"疑似受限 44 格"只覆盖 **cohort 口径的 24 个有销量 SKU**；
  本节 51 行覆盖**冻结 26 个**，多出的 7 行来自 3 个 `CENC/Linen-*`（在冻结集、不在 cohort）。
  两组数字服务于不同口径，**不要相加**。
- 读法：**观测值是下限**；需求落在"观测"与"情景上沿"之间的某处，真实位置**未知**。
  这不是置信区间，是**情景敏感性**；不得把中位情景当需求真值，也不得据此算补货量。
- 独立于模型的证据只有一条：同一批 SKU 在 2026-06/07 有 152 次 checked0stock 阻断事件——
  它证明**有订单被挡**，不证明挡掉了多少。

## 5. 边界

1. 只读离线；未访问生产、未扩样、未下单；无补货量。
2. 促销窗口是**供应商成本口径**，不是零售促销；零售效应未证。
3. 「恢复期」是本报告的定义（促销后第一个月），不是来源阈值。
4. 人工截断实验是**回顾性**的：真值来自历史，且实验刻意避开了真实信号月；
   真实场景里受限段与非受限段混在一起，误差会**大于**本实验。
5. 所有数字只对冻结 26 个 PB SKU、2023-07..2026-09 成立；不外推到 27/28 或全目录。
6. **不得**把 `lower_bound` 的输出标成"需求真值"或"可下单量"。
