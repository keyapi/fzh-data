# C 包：A+B 接回 1,328 建议的独立验收包

> **离线**：只读既有产物（decision_v2 / usability_audit / wo_dn_coverage / A 的 routing.csv /
> B 的 linkage_audit_v2.csv）与本地 DuckDB 的 `sku_item` 映射；**0 次 GET，无生产访问、无写库**。
> A/B 的数字原样引用，不重算、不改动。

## 1. 覆盖与分布

| 项 | 值 |
|---|---:|
| 行数（每 SKU×仓一行） | 2,309 |
| SKU | 1,328 |
| 原状态 A / B / B_pending_inventory / C | 0 / 2,058 / 160 / 91 |
| **决策状态 可决策 / 待补证 / 范围外** | **1,804 / 414 / 91** |
| L30 存在正缺口 | 254 |
| 在手未知（原状态 B_pending_inventory） | 160 |
| WO 数量已取得（仅这些行可做 WO 情景） | 32 |
| A 分型覆盖（行） | short 486 / seasonal 330 / simple 355 / intermittent 179 / A 未评分 868 / 无 A 记录 91 |
| B 关联覆盖（行） | linked 512 / absent 1,251 / ambiguous 546 |

**决策规则（写死在脚本里）**：
- `范围外` = 原状态 C（UOM/映射未证）；
- `可决策` = 原状态 B、在手已知、且 **L30 缺口（在手+在途+未结 PO）≤ 0** —— 即**在已知事实上确认“无需动作”**；
- `待补证` = 其余（凡是需要动作的，都依赖未证的供给）。

> 所以“可决策 78%”不是“78% 可以下单”，而是“78% 的行在现有事实下确认不需要动作”。

## 2. 三视图（分列，不混用）

| 视图 | 列 | 口径 |
|---|---|---|
| 终端销售预测 | `终端需求_月率`、`终端需求_P50L90`、`需求_L15/L30/L60` | 既有 T5 预测（AutoETS/MA3）；A 只提供分型与方法证据 |
| 内部 SO 补货/生产指令 | `内部SO_历史需求` | B 的显式关联累计，按既有需求摊派比例分到仓；**不计入终端需求、不从外部扣减** |
| 外部合同履约 | `外部SO_历史需求` | 同上 |

**两点必须随表说明**：
1. A 的产物是**路由证据**（分型/方法/特征），不含逐单元预测值——包里的数量仍来自既有 T5 预测，未用 A 重算。
2. 内部/外部 SO 数字是 **2024-11..2026-10 的历史累计**（B 没有 SO 未结字段），只用于判断“是否可能重复下单”，**不进入任何缺口公式**。

## 3. 已知 / 未知供应分列

| 字段 | 含义 | 是否证 |
|---|---|---|
| `在手` | 同仓可用库存 | 已证（缺失记 null） |
| `在途_无日期` | 在途数量，无到货日期 | 数量有、日期未证 |
| `PO未结_无日期` | 未结 PO 数量，无 ETA | 数量有、日期未证 |
| `WO_未证` | 在产 WO 剩余量（仅 32 行有材料） | 多数**未取得** |
| `B_DN净交付_历史` | B 的 DN 净交付累计 | 已证（仅 1:1 物料可归属） |

- `在途` / `PO未结` 为空 = **无该记录**，按 0 参与缺口计算；
- `WO_未证` 为空 = **未取得**，**不按 0 计**，相关结论一律记未证。

## 4. 时间情景（L15 / L30 / L60 三列并列，绝不相加）

- 需求：`L15 = 月率×0.5`、`L30 = 月率`、`L60 = 月率×2`（线性投影，标注为假设）。
- 缺口：`缺口_L15_保守` 只算在手；`缺口_L30_含在途PO` / `缺口_L60_含在途PO` 计入在途与未结 PO
  （**假设这批货能到**，无日期佐证）。
- **WO 三档**（每档都标未证）：`WO情景_不假设_L30`、`WO情景_假设L30可到_L30`、`WO情景_假设L60可到_L60`。
  WO 数量缺失时三列全为 null 并写原因，不填 0。
- 建议量：`建议量_L30_条件` / `建议量_L60_条件` 等于对应缺口（条件量），
  原状态 C 或在手未知时为 **null**；未套 MOQ/包装倍数。

## 5. 使用限制

1. 建议量是**条件量**，未套 MOQ/包装倍数（字段缺失），不能直接当采购单。
2. 绝大部分行的在产 WO 不在快照——依赖 WO 到货的判断必须先补证。
3. 在途/PO 无到货日期，L30/L60 的“能到”是假设，不是事实。
4. 内部 SO 是补货/生产指令，不计入终端需求；外部 SO 用历史累计，不代表未结。
5. B 的物料↔SKU 只有 1:1 才归属，多 SKU 物料记 `ambiguous`（546 行），不做摊派、不重复计入。
6. 本包不判断库存真实性、不判断到货及时性，也不构成下单指令。
