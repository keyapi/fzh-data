# 审核「派生成本/规则结果」的独立验证法

## Context

2026-10 审 7 月通途订单的两件事：(1) 老板质疑成本/运费/利润；(2) 核验 1.7.0 特殊规则执行结果。
两条链都**没有"官方结果"可对照**——派生值是 Colab 在内存里算的，规则结果**根本不落表**，
下游只有聚合产物。这种局面下，"用我自己的引擎跑一遍、结果自洽"**不构成审核**，只是自证。

## Guidance

### 1. 先划清"我能证什么"

| 能证 | 不能证 |
|---|---|
| 引擎**按公式**算对了（逐事件验算） | **公式本身**是否符合业务 |
| 生效日期 / 限定条件过滤生效 | 我快照的**规则表是否 = 对方运行时那份** |
| 与**独立产物**量级、方向一致 | 逐单逐分一致（没有官方留档时不可能） |

把上表直接写进审核意见。**不要**把"自洽"说成"已核验"。

### 2. 找**外部**证据，而不是加码重放

按性价比排序：

1. **换输入再跑一遍**（最便宜）：汇率是重放最容易错的一环。用**完整口径**（财务月表 20 币种）
   重跑 vs 用近似（订单列众数）。实测两者结果**分毫不差** → 汇率隐患排除。
   > 若那次差了呢？说明近似口径本来就错，是**真发现**，不是白跑。
2. **与独立产物对拍**：找一份**下游**产出的聚合表（透视表等），比对同一科目合计。
   实测：规则前表 − 重放 = **规则效果本身**（−120,366，正好吻合）；
   下游透视表 vs 重放只差 0.17%（该表名含"扣减成本归零"，本就有额外调整）。
   → 独立产物**站在重放这一边**，方向与量级都对上。
3. **口径外部核对**：把关键常数（汇率、单价）拿去和**权威源**（财务共享表）逐位比。
   实测 USD 6.8067 与财务月表**精确一致**。

### 3. 同名列是最大的坑：先分清"哪个系数"

两套系统**共用同一批列名**，极易把 A 的效果当成 B 的：

- **成本引擎**的 `绍兴成本系数`（≈0.9764）写进 `皮壳成本*系数`；
- **1.7.0 特殊规则**也写 `皮壳成本*系数`。

实测教训：我先生成把"重放 −116k"称作**假象**、把"表内两列差 +1,070"称作**真值**——**错了**。
两者测的是**两件事**（前者=1.7.0 规则，后者=成本引擎系数）。**同一批列名，两套语义。**

**判据**：`普通列 × 系数 == *系数列` 成立 → 那是**成本引擎**；要审规则，**只能重放**。

### 4. 审核范围/日期这类"看起来显然"的项也要机械验

- 生效日期：`month_active` 过滤后，"应用到但不在本月窗口的规则数" **= 0** ✅
- 限定条件：对每条应用规则 × 各自**非空**键列逐一比对命中订单 → 412 组合，**违反 0** ✅
- 命名/粒度：**"未被命中 2,157 单"是 6 列复合键粒度，会虚高**；按**订单号**是 8,930/11,049。
  → 报数前先问"这个分母是什么"。

### 5. 让"下次能逐分对拍"变成一次结构性修复

审核结论里的"根本局限"要配一条**可执行的消除方案**。
本例：在 Colab 的 1.7.0 应用单元格**后面**加一个**留档单元格**，把规则后整帧写进新 ws
（开关默认 `NO`、只读、失败不抛异常、可整块删除）。
→ 下月起有"官方规则后帧"，审核从**有条件通过**升级为**可完全通过**。

## Why This Matters

- 审核的产物是**可信度**，不是漂亮数字。"自洽"冒充"已核验"是最危险的交付。
- 同名列会把**一个系统的效果**记到**另一个系统头上**——结论直接反向。
- 缺留档时，"量级吻合"是**上限**，如实说出来的价值**高于**把结论讲满。

## When to Apply

- 任何"用脚本重放线上逻辑，然后宣称验证通过"的场合。
- 任何"两套系统疑似共用字段名"的核对。
- 报任何汇总数之前——先说清**分母与粒度**。

## Examples

```
① 换口径重跑（完整 20 币种月表）      → 与近似口径分毫不差  → 汇率隐患排除
② 独立产物对拍（下游透视表）          → 差 0.17%，远小于与规则前表的差 → 方向/量级吻合
③ 常数外部核对（财务月表 USD）        → 6.8067 精确一致
④ 逐事件验算                          → 32,388 通过 / 0 不通过
⑤ 生效日期 + 限定条件                 → 窗口外应用 0；412 组合违反 0
结论：**有条件通过**（算术/日期/条件全过；无官方留档，只能量级吻合）
```
