# docs/solutions 孤儿豁免清单
#
# 用途：`scripts/check_solutions_health.py` 会做「孤儿检测」——列出没有任何
#       skill / AGENT_HANDOFF / AGENTS.md / CONCEPTS.md 指过来的文档。
#       每篇孤儿只有两种合法归宿：
#         1) 挂到相关 skill 或模块文档（route —— 只写路径，不要把内容复制过去）
#         2) 写进本文件豁免（确实不该被任何 skill 路由的，例如仓库治理、一次性调研）
#       没有第三条：静默忽略不是选项，那正是这份清单要防的事。
#
# 格式：每行 `<仓库相对路径>  # 豁免原因`；`#` 开头为注释。
#
# 例：
#   docs/solutions/architecture-patterns/public-private-agent-knowledge-split.md  # 仓库治理，无业务模块归属
#
