## 8. 交叉复核补充（独立子代理复核，2026-10-08）

> 一次独立的只读复核（另一 agent，实读公式）与主档案**逐项吻合**，并补出以下事实/口径。

**8.1 修正与新增计数**
- **仓映射计数修正**：`订单发货仓库对应成本来源` 是 **47 数据行 + 表头（`get_all_values` 共 48 行）**；复核报告里"48 data rows"含表头，已修正（本档案原写"48 行"亦同此误）。
