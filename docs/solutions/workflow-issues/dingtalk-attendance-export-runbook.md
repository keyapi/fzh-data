# 钉钉考勤表导出操作手册（管理后台）

## Context

业务负责人需要月度考勤表，但反馈在钉钉里「找不到导出入口」。钉钉考勤入口不在考勤打卡首页，且是否能看到「导出报表」取决于账号权限。本文只记录**怎么操作**，不含任何考勤数据。

## Guidance

1. **入口路径（电脑端，功能最全）**
   `https://oa.dingtalk.com` → 工作台 → 考勤打卡 → **考勤统计 → 报表管理**。
   注意不是考勤打卡首页的「统计」按钮；新版后台在「考勤统计」下的「报表管理」里。

2. **权限先确认**
   - 可导出角色：主管理员、有考勤权限的子管理员、考勤组负责人、部门主管（仅本部门及下级）。
   - 子管理员若「考勤打卡」细分权限没勾**查看、导出报表**，导出页只会显示部分报表 —— 这是「找不到」的常见原因。
   - 主管理员路径：`oa.dingtalk.com` → 安全与权限 → 权限管理 → 子管理员 → 考勤打卡 → 细分 → 勾选。
   - 考勤组**子负责人只能在手机端**导出；部门主管不能导全公司。

3. **报表类型**
   - 月度汇总：每人一行，含出勤/休息天数、工作时长、迟到/早退、上下班缺卡、旷工、请假、加班、每日考勤结果。
   - 每日统计：每人每天一行，适合核对逐日异常。
   - 打卡记录：上下班打卡流水。
   - 原始记录：含定位/设备/Wi-Fi/照片，适合申诉核对，数据量最大。
   - 另有考勤证明、请假/出差/外出/补卡记录等。

4. **人员范围：先看考勤组，别只按部门选**
   人员范围可选：全公司 / **考勤组** / 部门人员 / 已离职人员。
   **同一个业务单位在钉钉里常被拆成多个考勤组**（例如不同班制/厂区/单休与生产分开）。
   导出前先到「考勤组管理」看各组的名称与人数，把属于该单位的组**全部勾选**；导出后按「考勤组」列统计人数，确认等于各组人数之和。
   只看部门会漏掉未加入考勤组的人，也可能把跨部门的人算进来。

5. **时间范围**
   电脑端后台**单次最多导出一个月**，跨月要分次导；标准版可导 180 天内历史，专业版/专属版更长。历史数据导出可能延迟，成功后通过「工作通知」发送。

6. **导出与下载**
   选好报表/日期/人员范围后点「导出报表」→ 在右侧「导出记录」或钉钉「工作通知」下载 Excel。
   用 Playwright MCP 操作时，下载文件落在 MCP server 的 `.playwright-mcp/` 目录（**不是当前工作目录**）；产物本轮可能是 `playwright-artifacts-*` 下的 GUID 文件，需自行复制并重命名。

7. **导出后必做核对**
   - 行数 = 所选考勤组人数之和；不一致就回到人员范围检查漏选/多选。
   - 日期列是否覆盖整月（1 日到月末，周末列可能显示为「六/日」）。
   - 是否有整月 0 出勤、全月旷工、出勤天数异常偏少的人 —— 标出来交业务方解释，不要自行改数。
   - 记录导出时间：导出是**快照**，之后审批通过的补卡/请假/加班不会回写。

8. **给业务方的说明模板**
   入口：`oa.dingtalk.com` → 工作台 → 考勤打卡 → 考勤统计 → 报表管理。
   手机端应急：工作台 → 考勤打卡 → 统计 → 团队统计 → 右上角「导出报表」。
   如果只看到「打卡记录」「原始记录」，是权限问题，找主管理员开「查看、导出报表」。

## Why This Matters

- **漏选考勤组 = 少人，且表面看不出来**：导出表不会提示「还有其他组」。用组人数对账是最便宜的防漏手段。
- **权限不足会被误判成「入口找不到」**：先确认角色和细分权限，再怀疑界面改版。
- **导出是快照**：工资核算前若还有未审批的补卡/请假，表会显示缺卡；应等审批处理完再导一次。
- **MCP 下载路径不是工作目录**：直接按工作目录找文件会以为「没下载成功」。

## When to Apply

- 需要给业务单位/工厂/分公司出月度考勤表时。
- 对方说「钉钉里找不到考勤表」时，先按第 2、8 条排查入口与权限。
- 需要区分「月度汇总 / 每日统计 / 打卡记录 / 原始记录」选用哪张表时。

## Examples

```text
# 操作路径（不含真实人员/数据）
oa.dingtalk.com
  → 工作台 → 考勤打卡
  → 考勤统计 → 报表管理
  → 选报表：月度汇总
  → 日期：本月 1 日 ~ 月末（单月）
  → 人员范围：考勤组 → 勾选该单位全部考勤组
  → 导出报表 → 导出记录/工作通知下载

# 核对
行数 == 各考勤组人数之和
日期列覆盖整月
标记整月 0 出勤 / 全月旷工 / 出勤异常偏少
记录导出时间点（快照）
```
