# 组合演示接力计划

## 用户纠正与执行边界

作品包含组员的知识问答与知识运营子项目，以及本仓库的受控操作助手。总介绍和全部演示共6–8分钟；不能将全部时间分给操作助手。用户要求简单操作预热后再演示复杂操作。2026-10-14用户在额度40%时要求停在规划，换Terra继续实施。

最新已发布源版本：独立仓库1560d1c、镜像c3a7267a。该版show遗漏知识库段落。本地show.html已开始纠正，尚未提交、未部署；不能把草稿当完成结果。本文件补充并优先于judging-experience-plan.md的单项目节奏。

## 已读背景与证据边界

已完整提取用户提供的申报Word、汇总Excel和修订PPT文字，并查看七张发文照片。文件留在用户本地，不复制进公开仓库。背景支持自主实施能力培养、专业化集约化支持、智能陪练、业务技术协同，以及常见问题/运营支持/专家处置分层。此前把有依据的价值背景整体删除是错误的。

这些材料的价值主张可用于内部讲稿；公开页面只用脱敏概括，不能带机构、赛事、人员、内部发文原句和内部规模数字。保留实施侧赋能、支持侧减负、组织侧经验沉淀的价值链，不声称项目直接创造资金收益。申报量化为试点前估算，不能当成已经实现的收益。

知识运营流程由另一子项目承担；目前未证实两系统共享知识、模型或身份。不能把两套系统同场演示写成接口已联通。已实际登录知识子项目，看到问答、知识库、上传素材、审核候选、反馈记录入口；已实测“余额查询报错”短问返回引用，以及一份模拟脱敏TXT上传后解析为一条候选。该候选自动显示“已通过”，因此未能证明逐条人工审核或审核发布隔离；这应作为试点前的治理缺口，不能写成已经具备的安全控制。访问地址与凭证仅使用会话或私有配置，不写入公开源码、文档或浏览器截图交付物。

## 默认7分30秒剧本

| 时间 | 环节 | 要看到什么 |
|---|---|---|
| 0:00–0:45 | 背景与价值 | 自主实施需要可复用专业支持；重复咨询与经验散落制约培养和交付 |
| 0:45–1:10 | 两部分分工 | 知识辅助处置判断；操作助手起草方案；人决定，确认后系统实施 |
| 1:10–2:25 | 财资助手短问与治理 | 问余额查询报错核查事项，打开来源；展示上传/待审画面，说明审核和发布边界 |
| 2:25–3:15 | 简单限额预热 | 20万元方案、确认前不变、人工确认、测试独立读回 |
| 3:15–5:55 | 复杂工单办理 | 001旧模板冲突、只补9443、5项差异、完整三页预演、确认、读回和模拟验收 |
| 5:55–6:40 | 安全与责任 | 岗位/范围/版本/有效期由后台核对；生产不能直改；人工能停止 |
| 6:40–7:30 | 价值与试点 | 分层支持、经验复用、同任务对照评价；真实接入仍需准入与治理 |

路由作为答疑备用，不在主线再重复执行。若业务朋友选路由作复杂例子，替换工单而非叠加。6分钟版压缩讲解与上传展示，不删人工确认/结果核验。8分钟版增加一项变化或失败恢复，不同时新增两套复杂例子。

上传内容必须为专门的模拟脱敏样例。现场处理时间过长可展示提前准备的候选，并明确不是刚上传的结果。禁止拿内部发文上传到外部知识库。正式资料审核规则与模型质量要分开：人工审核也不保证所有回答正确。

## Terra执行顺序与验收

1. 核对两仓远端与工作区；保留Cursor新增内容。本地show草稿仅是起点，恢复可修改的正文格式，不再重写已有解析器。修复标题、讲者备注和打印；草稿将路由放在小结之前，正式稿须移到附录，按主流程顺序排列。
2. 只读审看知识子项目，实测一条模拟短问及引用；再用模拟样例核验上传分类、处理中/失败状态、候选审核和发布。不要修改组员模型或删除其资料。无法核验的能力明确保留为待确认，不写成已完成。
3. 修订show与competition的作品总览：恢复知识段落、简单预热、复杂主线与价值背景。知识系统通过演示者私有配置/事先打开标签进入；公开仓库不写账号和私有系统地址。保留操作项目原说明及排练功能。
4. 同步讲稿与FAQ：人工决定不等于人工手动逐字段录入；模型起草、人员确认、后台执行、独立读回。不得将操作员确认说成独立复核审批。知识审核与配置批准分别说明。
5. 浏览器实际排练并计时：两个系统切换、引用展开、上传处理、限额确认、001五项预演和验收；看1366×768及常用投屏尺寸。失败与取消应有解释；不只验证HTTP200。
6. 记录真实耗时、失败和未实现项。先凭证/隐私扫描、索引同步、两PR提交推送，再备份并部署对应文件；保持.env、数据库、pip源、服务unit和虚拟环境。云端再次浏览器核验。

不新增Pi/MCP或知识框架来完成本轮叙事修复；先完善已存在两套系统的能力验证和演示衔接。接口统一是后续决策，不能为了讲稿临时伪装共享知识。
