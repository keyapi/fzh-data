# 演示脚本（6–8 分钟）

> 演示前先读[上场检查清单](#上场检查清单)。所有内容为模拟，开场一句话说明。

## 节奏表

| 时间 | 操作 | 讲者核心句 |
|---|---|---|
| 0:00–0:40 | 打开演示站，指出左侧「智能办理 / 接入工单」 | 「柜面后台已有表单，真正的难点是跨页核对规则、补缺、确认结果。今天我交给助手一份工单，不逐字段报参数。」 |
| 0:40–1:30 | 「接入工单」→ 选 `WO-DEMO-001` → 展开工单原文 → 点「建立任务」 | 「后台依据内置结构化工单建立任务，并标出旧模板与缺口；下一步模型会读取现状与现行规则，形成方案。此时没有保存业务配置。」 |
| 1:30–2:40 | 点「分析工单并形成方案」，等模型（约 8–13 秒） | 「它在读工单、读现行规范、读三页现状。注意：它没有执行能力，只能读、检索、追问、准备方案。」 |
| 2:40–3:10 | 缺项卡输入 `9443` →「提交并续办」 | 「结构化工单缺客户端端口，后台与模型都不会猜；其他目标值由现行档位规则决定。」 |
| 3:10–4:10 | 方案卡出现：展开 5 项操作与一处来源 | 「已有终端它复用而不是新建；五个新值每个都能点开看来源。它没有猜端口，用的是我刚给的值。」 |
| 4:10–4:40 | 点「预演三页填写」 | 「三页依次预演，但你看——数据库此刻没动。预演不等于保存。」 |
| 4:40–5:40 | 点「一次确认并执行整组」，展示报告 | 「一次确认，后台一个事务提交，然后**从数据库独立读回**，再跑本地模拟契约测试：读回、一致性、回调、幂等、超时、范围未扩大，逐项给结果。」 |
| 5:40–6:20 | 展开报告明细；指出备用链路未动 | 「保存成功 ≠ 验收通过，两个状态分开显示。备用链路 IP 和敏感占位都没被碰。」 |
| 6:20–7:00 | 讲失败变体（用 `WO-DEMO-003` 或已录结果） | 「配置合法也可能验收失败。系统不会显示'接入完成'，而是给一份可确认的恢复方案。」 |
| 7:00–7:30 | 收尾：展示项目说明页 | 「模型负责判断与方案，后台约束写入与验收；接真实系统需要正式身份、审批和接口改造。」 |

## 默认输入

- 工单：`WO-DEMO-001`（标准档，缺端口）
- 端口补答：`9443`
- 分析按钮文案即默认指令；无需在聊天框打字
- 变体（答疑备用）：`WO-DEMO-002`（保守档，端口已填 8443）、`WO-DEMO-003`（回调被拒，验收失败→恢复）

## 答疑切换（任选一两个）

| 追问 | 怎么演示 |
|---|---|
| 「为什么不用模板里的 30 秒、重试 2 次？」 | 聊天框输入该问题 → 助手引用旧模板 superseded 与现行 2.0 档位，**不生成方案** |
| 「这算不算让 AI 自己改生产？」 | 指出模型无执行工具；生产无写入路径；确认由人点 |
| 「它会不会乱编来源？」 | 展开方案来源；后台逐字段校验 evidence 归属、版本、目标字段与精确值 |
| 「重复办理怎么办？」 | 指出已达标时后台返回 `NO_CHANGE`，不重复新增参数 |
| 「出错了能退吗？」 | 用 003 演示恢复；恢复也须再确认，且不覆盖他人后续修改 |

## 延迟 fallback

- 现场模型 **> 15 秒**：先讲工单原文与冲突点，等结果。
- **> 30 秒**：明确说「本次模型较慢」，展示已记录的[实际测试结果](competition-v2-results.md)继续讲范围与恢复。
- **模型不可用**：展示[测试结果记录](competition-v2-results.md)，不播放录像冒充本轮实时结果。

## 上场检查清单

1. `cd D:/Work/web-ai-assistant-review-20261012 && python server.py`（默认 `127.0.0.1:8766`；端口见 `.env`）。
2. 浏览器打开演示站，登录 `operator`（口令 `demo2026`）。
3. 先执行一次「重置」清库，保证结果可重复。
4. 点一次「接入工单」，确认工单下拉与「建立任务」按钮可用（登录后按钮应可点）。
5. 确认页面显示「真实模型」标签与模型名。
6. 预跑一遍 001，确认缺项只问一次、预演后回到确认卡。
7. 备用：先在当前终端设置 `DEMO_LOGIN_PASSWORD` 为演示口令，再运行 `python scripts/task_eval.py`。脚本每次使用独立工作区；评测记录可作为模型延迟时的替代展示，不冒充本次浏览器操作。
8. 强调：演示库与生产隔离；本机/内网演示，HTTP 演示口令不可作为公网门槛。
