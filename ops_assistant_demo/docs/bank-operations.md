# 渠道接入三页面实现与实际验收

## Context

四张运营后台拍屏可辨认的流程是终端注册、注册参数维护、固定IP配置。用户要求功能和特色交互同时落地。照片、真实租户、地址和敏感值均不进入仓库；模糊字段不宣称准确还原，所有记录独立生成并明确标记模拟。

## Guidance

| 页面 | 已实现 | 后台约束 |
|---|---|---|
| 终端注册 | 编号/名称筛选、分页、查看、新增、修改、删除 | 唯一编号、并发整数、协议与地址一致；有下游参数/IP不能删除 |
| 注册参数 | 按终端筛选、分页、新增、修改、删除 | 终端内参数名唯一；数字文本校验；密码/密钥类型自动遮蔽 |
| 固定IP配置 | 按终端筛选、分页、新增、修改、删除 | 关联终端存在；端口1–65535；只允许文档网段、测试网段与回环地址 |

`bank_ops.py`使用原Store事务，共用工作区、会话岗位、确认摘要、十分钟时效、状态版本和审计。`bank_agent.py`只开放读取状态、查规则、准备操作，模型没有执行工具。`bank_ui.js`维护页面交互，保存走原执行API，由后台路由对应执行器。

一句话 → 本轮最新数据库状态与模拟规则 → 模型准备具体差异 → 鼠标移动、高亮、逐字填写 → 对话允许或页面确认 → 事务保存 → 独立数据库读回与结果强调。只有一次执行确认，没有额外审批层。人工新增/编辑调用同一后台，并明确标记未调用模型。

新增10字段总字符动画预算约1.1秒，字段间移动120毫秒；修改只动画变更字段。侧栏最多展示三项差异，完整差异留在页面。办理中禁止切页、行选择和编辑，防止视觉内容与确认摘要不一致。当前终端选择可跨页面延续。

重置同时恢复三类记录、递增版本、取消旧确认、清除旧办理结论，保留审计历史。敏感参数只接受`DEMO_`模拟占位，后台存固定演示值，读回/确认/审计全部遮蔽；这不是生产密码管理或密钥轮换。地址不发起网络连接，配置保存不等于真实网络连通性或压测成功。

## Examples

主剧本仍五分钟，新增三页适合答疑扩展；选一段多字段新增，不必展示所有页：

1. 终端注册点击“让助手新增终端”：真实模型填写10字段，停在确认处；确认前列表不新增。
2. 允许后核对列表新行与独立读回证据。
3. 参数页说“把终端 DEMO-001 的 timeout_seconds 参数改为75”，只准备这一项。
4. 固定IP点击“让助手配置IP”，填写两个地址与两个端口，确认后读回。
5. 切换只读岗要求修改，页面与后台均拒绝；有下游记录的终端不能删除。

## Verification

真实使用`deepseek-v4-flash`与浏览器，未用固定脚本冒充模型：

| 验收 | 实际观察 |
|---|---|
| 终端自然语言新增 | 10字段约6秒准备完成，确认前未保存，允许后独立读回 |
| 参数自然语言修改 | 30→75，仅该字段差异，确认后读回75 |
| IP自然语言新增 | 模拟地址及443/8443端口，确认后读回 |
| 三实体增删改 | 浏览器逐项办理；更新核对新值，删除核对记录消失 |
| 查询、分页、空结果 | 空筛选正确；8参数分两页，第二页2条 |
| 敏感参数 | 密码框遮蔽，不返回输入模拟秘密文本 |
| 只读岗真实模型 | 后台拒绝，按钮禁用，数据不变 |
| 非法值 | 端口99999与真实外网地址被拒绝 |
| 同值重复请求 | 无需重复保存，不新增确认单 |
| 修改后重置追问 | 页面恢复30，模型回答当前30，未引用旧75为当前状态 |
| 原柜面回归 | 50万→20万，一次对话允许保存，生产仍50万 |

先观察新HTTP404、无差额确认和负数来源检查失败，再实现修复。76项自动化通过、0跳过，包含权限、隔离、摘要、过期、状态变化、并发、事务失败、脱敏、HTTP入口及旧功能回归。JS语法、Python编译和diff检查通过。指定用例不能替代生产安全认证。

在主仓模块无私有`.env`的环境复跑时，发现旧HTTP测试依赖本机模型配置，两个权限测试先返回模型未配置。测试现使用虚拟网关与dummy值，所有上游调用仍mock；独立仓与主仓模块各76项通过，不要求测试者提供真实Key。

### 云上复核

云上已逐项复核真实模型终端新增、参数30→80与IP新增，确认前数据库不变，确认后读回`passed=true`。终端10字段逐项记录高亮/鼠标，文本字段观察到中间字符，单字段约106–133毫秒；办理中点其他行或旧导航没有改变页面。参数页说“把超时改成80秒”正确保持注册参数场景，没有误入联调配置。

## Prevention

- 新模块文件必须一起部署；静态白名单只增加`/bank_ui.js`，不开放运行目录。
- 角色来自后台会话，页面隐藏和模型提示不能授权。
- 读回`passed=false`不得显示核验成功。
- 数值来源检查只证明值出现在近期用户文本，不是完整自然语言授权证明；最终差异确认必需。
- 缺少文本目标先追问，推荐不能直接当用户要求；多终端时先选择目标终端。
- 公网模拟身份、口令与HTTP边界仍见安全说明，本轮不涉及银行SSO。
