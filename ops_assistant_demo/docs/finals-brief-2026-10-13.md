# 决赛 6–8 分钟总说明

面向工银科技第四届创新大赛·价值创造赛，赛道是智能办公效率。成果名称用申报口径：**资金管理系统实施智能体——基于「工单驱动 + 知识自沉淀」的配置与排障助手**。

书面材料已经交过四维表和约 1800 字申报正文。台上这 6–8 分钟不要再念材料。评委要看到的是：分行实施时先问得着，再在测试环境改得了，而且改之前必须有人点头。

## 最终要证明的一件事

司库全面推广之后，分行要自己做实施，工银科技不能靠群聊逐条答同一类报错。这个成果把两件事接成一条：

1. **财资助手**负责「这报错、这配置，手册和既往案例怎么说」，回答必须带出处。
2. **操作助手**负责「按这个口径，在测试环境准备改哪几项」。人在页面上确认之后，系统才写入测试并读回；生产只形成申请，不能直接改。

台上用一句话收口：**问答解决“还得问人”，确认式办理解决“问完仍不敢改、改了说不清”。人确认，人担责。**

这和行内材料里的分工同向，但不要说成已经替代了运营中心或专家团队：常见咨询和操作指导走助手；标准化排障和复杂转接仍由人；重大故障仍由专家处理。我们演示的是助手把前一段做完，并把改配置停在确认之前。

## 现在各自能演示什么

| 部分 | 现场能做 | 不要说成已经完成 |
|---|---|---|
| 财资助手 Web | 问答、知识库（已发布 / 草稿 / 已废弃）、上传素材、候选审核（待审、通过、驳回、疑似重复）、踩赞 | 不要打开含具体客户环境、系统版本排查的草稿条目当主线 |
| 浏览器插件 | 申报口径是嵌在工单、日志、配置页里选中即问 | 若现场没装好插件，不要临时安装，改口说 Web 是同一套问答 |
| 操作助手网页 | 演练工单三张差异、缺一项就追问、确认后只写测试并读回；或按点名准备余额 / 明细 / 票据的路由整组方案 | 自助提单、生产工单对接、全行铺开都是规划，不计入本段已交付 |
| 朋友的演示稿 | 仍在改，外链需要登录，本轮没读到正文 | 计时不要依赖这份稿；它最多承担开场一页 |

知识库里适合上台的干净问题是「什么是银企直连」和「余额查询报错先查什么」。带具体客户环境的排查留在审核或答疑，不放进计时主线。

## 评委口味：必须落到嘴上的话

行内材料的口径是：总行统筹，分行主导，工银科技支持；司库业务要分行自己具备实施和运营能力，工银科技做平台化、集约化的技术支持。标准云服务项目原则上分行自主实施。

所以台上优先说这些，不必展开文件：

- 痛点是银企直联参数相互依赖，证书、验签、报文、授权一类报错反复出现在群里，经验带不走。
- 创新不是再造一个大模型，而是三件事：嵌在作业现场问、聊天人审入库而手册免审入库、回答带引用并可踩赞回炉。
- 算力和模型复用现有能力，不另起一套。
- 代操作只发生在规定的模拟页面，每一步和最后提交都要人确认。
- 时长、工时那些数是立项时的保守估算。说「预期把约 30 分钟的共性排查压到 10–15 分钟」，马上补「试点后用命中率、有用率和前后对照替换这个估算」。

不要说：已经满足监管、所有攻击都能拦住、助手可以代替审批人、已经全行上线、无人值守改生产、把估算说成已经省下的工时。

## 6–8 分钟怎么排

知识库要露一手，但时间压短。赢面放在两次可操作：先改一个限额，让大家看懂确认；再办一张缺端口的工单。不要在同一段里换岗、做安全测试、再开路由。

模型若超过约 20 秒没有结果，口播往下走，屏幕停在已打开的引用或已填好的方案上，不要干等。投屏用 `/show.html`，朋友改该文件里的 `slides` 即可。公开页面不写单位和赛事名称。

| 时间 | 做什么 | 评委应看到 |
|---|---|---|
| 0:00–0:40 | 一句定位：问答之外，变更做到测试环境，而且要人点头 | 投屏标题页 |
| 0:40–2:00 | 财资助手问「余额查询报错，一般先查什么」。点开引用，指一下有帮助 | 答案有出处。一句带过：聊天要人审，手册免审 |
| 2:00–4:00 | 操作预热：把测试限额改成 20 万。确认前不变，确认后测试是 20 万，生产仍是 50 万 | 它会动手，但只有一次确认，生产不动 |
| 4:00–6:40 | 复杂例：缺客户端端口的演练工单。只追问这一项，预演，一次确认，读回 | 知识库做不到的跨页办理 |
| 6:40–7:30 | 收口：有据、有人点头、生产不在这里改。估算等试点替换 | 三句话，不展开安全测试 |

工单模型卡住时，复杂例改成「只开通余额查询，不要明细和票据」。安全测试和换岗留到提问。

## 两段之间怎么接

预热结束后不要说「下面换一个系统」。说：

「刚才它告诉实施同事先查证书和密钥，依据在知识库里。真正改配置时，不能让它自己点下去。所以下一段是同一类报错进了演练工单：它只准备测试环境要改的项，缺端口就只问端口，人确认后才写入，生产不动。」

若有人问为什么不一开始就改配置：因为评委要先看见「答得有据」，再看见「动得有界」。先改配置，前两分钟像在看一个参数后台。

## 书面材料和上台各占什么

申报正文和汇总表给评委读，台上不复述 200 字。朋友的演示稿还在改，不能当成计时主线。我们的网页承担后半段可操作演示；财资助手承担前半段问答。两边不要互相登录到对方系统里现场拼。

知识库站点的账号只用于准备，不写进口播，不投到屏幕上。
