# 安全边界与质疑解答

本文描述目标控制与验收方式。柜面页已接上受控执行；公开 `/v1` 和敏感文件仍然拒绝。线上状态见 [交接](handoff-2026-10-12.md)。

这是受控操作机制的 POC，不是正式银行身份、合规认证或生产安全验收。业务和检测结果全部模拟；真实模型供应商会收到送入模型的模拟文本。

## 控制与预期结果

| 质疑 | 控制 / 可验证的预期结果 |
|---|---|
| 前端换角色能越权吗 | 后台会话身份决定权限，提交角色不能升级权限 |
| 模型给错动作怎么办 | 白名单及字段、单位、范围检查；未知动作拒绝 |
| 确认后偷偷多改字段呢 | 确认绑定不可变提案摘要，篡改执行请求被拒绝 |
| 别人改过配置怎么办 | 执行前版本复查，旧提案失效；十分钟后也失效 |
| 点两次怎么办 | 同一提案幂等，不能重复建单 |
| 生产审批后就上线了吗 | 复核仅处理模拟申请，生产写入口始终关闭 |
| 配置变了但工单失败呢 | SQLite事务中止后无部分提交；安全测试核验旧值 |
| 资料说忽略权限怎么办 | 资料不授予权限；模型错误提案仍经过执行检查 |
| 浏览器自己宣称成功呢 | 重新读取后台配置，审计由后台记录 |
| 网络或模型故障怎么办 | 不能生成或执行未确认动作，已有结果可查询 |
| 客户资料会泄露吗 | 本演示没有真实客户资料；真实上线还需出域控制与数据分类 |
| 是不是简单脚本 | 真实模型理解任务和使用读工具；业务动作刻意固定以便管控 |

本轮39项自动化通过且0跳过；线上八项安全实测得到预期结果，具体范围见[交接](handoff-2026-10-12.md)。`/api/safety-test` 是明确标记的故障/攻击模拟入口。注入测试不证明真实模型百分百抵抗提示注入；它检验错误动作到达执行层后仍被限制。

## 身份与会话

operator、reader、reviewer使用公开演示口令；它证明角色检查，不证明请求人是对应员工。后台按浏览器工作区隔离模拟数据，同一浏览器切换身份携带工作区。正式接入需企业SSO、用户身份映射、会话管理、可靠资源授权与审批职责分离，不能照搬共享账号。

POST的固定请求标记与同源检查降低跨站请求风险，不是密码；浏览器同源脚本、被窃取会话及服务端控制权限仍需正式安全设计。预算限制不是计费平台，分布式限流和抗DDoS不在本POC证明范围。

预算使用进程内滚动窗口，默认24小时250次实际模型调用、2并发；每IP聊天60次/小时、每工作区30次/小时、每IP POST150次/分钟、登录40次/分钟。重启会重置，不是每天硬账单上限。可选私有访问码本次部署未设置，公开演示账号仍可被无关访客使用。

目标值防线检查用户文本中是否出现拟执行数值，不能据此证明已完整理解否定、引用或条件语义；具体旧值/新值确认是最后一道必要步骤。不支持无关联参数变更的独立工单。

## 资料与审计

演示资料刻意包含有效、过期与不可信文本。正式知识库还需文档级访问控制、来源追溯、更新负责人及效果评估。小型检索不代表大规模知识库质量。

SQLite审计可供演示追踪，但管理员可修改数据库；不能称不可篡改审计。真实上线需集中日志、保留策略、时间同步和职责管控。数据库重置仅用于模拟演练。

## 部署剩余风险

静态文件白名单与取消公开模型代理阻止相应直接读取和无会话转发。Key仍只在服务器，但此前配置暴露风险无法通过封堵撤销。用户明确暂不轮换Key，本次不擅自轮换；Git未泄露不等于未被HTTP读取。

当前公开地址为HTTP，未提供传输加密。共享口令公开；私有访问码可减少无关访问但不等于企业认证。正式演示建议HTTPS/受信网络和来源限制。不能把本POC包装成已具备银行生产安全条件。
