# 创建赛狐报告


| reportType | 报告名 |
| --- | --- |
| PRODUCT_SALE_REPORT | 销量统计报告 |

- **销量统计报告**

**reportType** : PRODUCT_SALE_REPORT

**可选参数**

| 字段名 | 参数名 | 参数类型 | 是否必须 |参数说明 | 参数示例 |
| --- | --- | --- | --- | --- | --- |
| startDate | 下单开始时间 | Date | 是 | yyyy-MM-dd 下单时间范围不能超过90天 | 2023-01-01|
| endDate | 下单结束时间 | Date | 是 | yyyy-MM-dd 下单时间范围不能超过90天| 2023-01-01|
| updateTimeStart | 更新开始时间 | DateTime| 否 | yyyy-MM-dd HH:mm:ss | 2023-01-01 00:00:00|
| updateTimeEnd | 更新结束时间 | DateTime| 否 | yyyy-MM-dd HH:mm:ss | 2023-01-01 23:59:59|
