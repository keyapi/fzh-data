## 下载配置（全部统一）

每次下载都选一样的配置：

| 配置项 | 选什么 |
|--------|--------|
| 广告类型 | **Sponsored Products（商品推广）** |
| 日期范围 | **最近 30 天** |
| 粒度 | **每日** |
| 格式 | CSV 或 XLSX 都行 |

---

## 下载步骤（有截图更好，先文字版）

1. 登录 Amazon 广告后台 → [advertising.amazon.com](https://advertising.amazon.com)
2. 左侧菜单 → **广告活动管理**
3. 左侧菜单 → **报告**（或 "衡量和报告" → 报告）
4. 点击 **创建报告**
5. 在弹窗里选报告类型 → 配好参数 → 运行报告
6. 等报告生成完 → **下载**
7. 下载好的文件**不要改名**（文件名里已有关键词，脚本靠这个识别）
8. 全部放到这个目录：`advertise\数据源\`

## 其他数据源（优麦云 + 卖家精灵）

除了 Amazon 后台，还可以从以下工具导出数据：

| 工具 | 能导出什么 | 怎么导出 |
|------|-----------|---------|
| **优麦云** | 广告活动/搜索词/投放（永久保留）+ 分时销售 + 库存 | 登录 → 广告管理/销售 → 导出 Excel |
| **卖家精灵** | 竞品关键词反查 + 流量词对比 + 关键词挖掘 | 登录 → 对应功能 → 导出 Excel |
