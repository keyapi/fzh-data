# Tracking API 概述

## 基本信息

| 项目 | 说明 |
|------|------|
| API 文档源 | `/config/track.yaml` |
| 基础 URL | `https://test-api.vitedirect.com` |
| 认证 | `x-api-key` |

## 用途

提供多承运商统一包裹追踪服务，支持 USPS、FedEx、UPS 等。

## 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/track` | 查询包裹追踪信息 |

> 详细信息请参考 API 文档源文件 `/config/track.yaml`
