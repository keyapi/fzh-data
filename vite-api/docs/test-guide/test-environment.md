# 测试环境说明

## 测试 API 服务

| 项目 | 值 |
|------|-----|
| Base URL | `https://test-api.vitedirect.com` |
| 协议 | HTTPS (TLS 1.2) |
| 认证 | x-api-key 请求头 |
| 数据 | 测试数据（非真实数据） |

## 测试系统 (EEVEE)

| 项目 | 值 |
|------|-----|
| 系统名称 | EEVEE |
| 系统地址 | https://easygo-dev.vitedirect.com/labelHistory |
| 功能 | 查看标签历史、管理 API 设置、充值、费用查询 |

## 测试环境能力

### 可执行操作
- ✅ 查询运费报价 (Rate)
- ✅ 创建测试标签 (Label)
- ✅ 批量创建标签
- ✅ 查询标签状态
- ✅ 取消标签
- ✅ 查询账户余额
- ✅ Webhook 配置

### 限制
- ❌ 测试数据为模拟数据，不代表真实价格
- ❌ 标签 PDF 可能无法实际下载
- ❌ 追踪号非真实物流追踪号

## 测试环境与生产环境对比

| 项目 | 测试环境 | 生产环境 |
|------|----------|----------|
| API URL | `test-api.vitedirect.com` | 联系技术支持获取 |
| 数据 | 模拟数据 | 真实数据 |
| 费用 | 虚拟余额 | 真实扣费 |
| 标签 | 测试标签 | 真实面单 |

## Webhook 配置路径

1. 登录 EEVEE 系统
2. 进入组织管理页面（需管理员权限）
3. 填写 Webhook URL
4. 确认后，系统会发送一条订阅确认消息
5. 访问响应中的 `SubscribeURL` 完成订阅
