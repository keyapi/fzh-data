# 测试数据注意事项

## 已知问题

| 问题 | 说明 |
|------|------|
| 价格不真实 | 测试环境的运费为模拟数据，不代表真实价格 |
| 标签 PDF | 测试环境生成的标签 PDF 可能无法下载 |
| 追踪号 | 追踪号非真实物流追踪号，无法在承运商官网查询 |
| 订单 ID | orderId 为测试环境生成，格式可能与生产环境不同 |
| 余额 | 余额为测试余额，可反复使用 |

## 测试限制

- API 响应时间可能与生产环境不同
- 测试环境的并发限制可能较低
- 部分高级功能可能仅在测试环境中可用

## 建议

- 测试时关注 **接口格式** 和 **响应结构**
- 不要依赖测试环境的 **具体数值**（价格、余额等）
- 使用测试环境验证 **requestId 唯一性** 逻辑
- 确保生产环境切换时更新 API Key 和 Base URL
