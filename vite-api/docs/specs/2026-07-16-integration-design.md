# FZH 集成方案设计

## 概述

FZH 公司需要在 Vite API 平台上集成回标标签功能，支持多个电商平台（TEMU, TIKTOK, SHEIN, EBAY, AMAZON, WALMART）的退货标签生成。

## 承运商选择

| 优先级 | 承运商 | 用途 | 优先级说明 |
|--------|--------|------|------------|
| ★★★ | GOFO Express | 回标标签 (GFUS/YT) | 核心承运商，立即集成 |
| ★★☆ | USPS V2 | 美国国内发货 | 后续集成 |
| ★★☆ | FedEx V2 | 国内+国际发货 | 后续集成 |
| ★☆☆ | 其他承运商 | 按需启用 | 按业务需求扩展 |

## 渠道策略

| 平台 | 渠道 | 说明 |
|------|------|------|
| TEMU | GFUS | 首批接入 |
| TIKTOK | GFUS | 首批接入 |
| SHEIN | GFUS | 首批接入 |
| EBAY | GFUS | 首批接入 |
| AMAZON | YT | 首批接入 |
| WALMART | YT | 后续接入 |

## 集成流程

```
[电商平台] → [FZH 适配层] → [Vite API]
                  ↓
           [Webhook 回调]
                  ↓
           [面单打印/存储]
```

## 测试策略

1. **基础连通性测试**: 验证 API Key 和 Base URL
2. **功能测试**: 逐个场景测试（运费、标签、查询、取消）
3. **渠道测试**: 分别测试 GFUS 和 YT 渠道
4. **回标流程测试**: 端到端回标标签创建和获取
