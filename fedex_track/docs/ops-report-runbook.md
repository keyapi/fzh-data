# 运营异常报表 runbook

给运营的交付物：`fedex_track/ops_report.py` 生成一个**多工作表 + 配色 + 汇总**的 Excel，服务 Amazon 运营判断 FedEx 单的**迟发/漏发/卡件/延误/取消/数据异常**。

## 生成

```bash
set -a && . ./.env && set +a
uv run python -m fedex_track.ops_report \
  --summary fedex_track_output/fedex_full_20260904_v2.summary.csv \
  --tt "D:\Work\王忠于\成本核算\通途非FBA订单202608 202609030947 无需填0售价 加预估尾程.xlsx" \
  --out fedex_track_output/fedex_ops_report_<date>.xlsx
```

参数：`--summary` 全量 query 产物；`--tt` 通途原始表（带 订单号/包裹号/渠道账号 等）；`--out` 输出文件。

## 工作表

| Sheet | 内容 |
|---|---|
| 总览 | KPI(总/异常/漏发/迟发/延误/卡件/取消/数据异常) + 分类表(中文+数量+所属Sheet) + 配色图例 |
| 异常处理 | 异常子集，含「建议动作/处理状态」(待办) |
| 漏发未交接 | 漏发+建标未收件；建议：通知仓库/货代核查 |
| 迟发 | 含 营业日延迟 / Amazon是否判迟；按 轻/中/重 分级 |
| 承运异常 | FedEx延误 + 卡件；记录 / 开 trace / 索赔 |
| 取消·其他 | 已取消 / 数据异常·查无 |
| 全部明细 | 全量(含正常/在途/复用旧票)，审计 |
| 口径说明 | 定义/阈值/节假日历/配色/动作 |

每行：跟踪号 / 分类(EN) / 分类(中文) / 等级 / 订单号 / 包裹号 / 渠道账号 / 渠道 / 平台SKU / 通途SKU / 产品名称 / 发货仓库 / 执行发货人 / 是否补发货 / 销售站点 / 买家姓名 / 国家·城市·州 / 发货日期 / 建标时间 / 站点收件时间 / 交付时间 / 日历延迟 / 营业日延迟 / 承运延迟 / Amazon是否判迟 / 所属Sheet / 建议动作 / 处理状态。

## 口径（Amazon LSR 对齐）

- **起点** = 建标时间(面单创建)；**确认发货** = 站点收件时间(FedEx 首次取件扫描)。
- **ship-by = 下单日 + 处理时间(营业日)**；周末与美国联邦节假日**不计入**。
- **营业日延迟 = 建标→站点收件的营业日数 − 处理时间**（默认 1 营业日）。`Amazon是否判迟` = 营业日延迟 > 0。
- 建标在周五/节前、次一营业日才收件 → 营业日延迟 = 0 → **不判迟**。

## 阈值（`ops_report.py` 顶部可调）

| 常量 | 默认 | 含义 |
|---|---|---|
| `HANDLING_DAYS` | 1 | 处理时间(营业日)，迟发判定的减项 |
| `TRANSIT_SLOW_DAYS` | 6 | 收件→交付 营业日 > 6 → FedEx 延误 |
| `TRANSIT_SEVERE_DAYS` | 12 | 延误 > 12 → 严重(可索赔) |
| `STUCK_DAYS` | 7 | 在途 > 7 天无新扫描 → 卡件 |
| `MISSING_AFTER_DAYS` | 3 | 有发货日期但 > 3 天无站点收件 → 漏发/未交接 |
| `US_HOLIDAYS` | 2026 | 美国联邦节假日(排除的营业日) |

## 分类与配色

- 漏发/未交接(红)、建标未收件(黄)、迟发(轻/中/重→黄/橙/红)、FedEx延误(橙/严重红)、卡件(红)、已取消(灰)、数据异常(灰)、复用旧票(蓝)、正常(绿)、在途(黄)。
- `复用旧票(缺建标)`：复用号的无建标一票，**排除出异常处理**，以有建标那票为准。

## 已知坑

- 一单可能**既迟发又延误**：当前按单类主判定(延误>7天优先)，明细里已带 `承运延迟(营业日)` 列；如需"多标记"再加 `是否迟发/是否延误` 两列。
- `发货日期`(通途表第 0 列)是"标记发货日"，**未必是真实出库日**；报表已改用**建标时间**为基准。
- FedEx 反爬对自动化返回假报错；查单个号请用真实浏览器/API 或同会话暖机重试。
