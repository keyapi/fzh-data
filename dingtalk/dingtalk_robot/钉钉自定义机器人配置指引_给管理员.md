# 钉钉自定义机器人配置指引（给钉钉管理员）

> 以下话术与步骤可直接转发给你的钉钉管理员同事。

---

## 一、背景（给管理员的说明）

你好，我需要你在钉钉里帮我建一个**「自定义机器人」**，用来接收我们 ERPNext 数据管道（fzh-data 项目）处理完成的自动通知（例如销售出库单 DN 的物料汇总结果）。

- **用途**：接收 Agent 自动推送的"任务完成通知"（纯文本 / markdown，不含账号密码等敏感凭证）。
- **不需要企业应用资质**：标准的群自定义机器人即可，不是自建应用。
- **建好之后**：把机器人的 webhook 地址发回给我，Agent 会用它推送消息。

---

## 二、操作步骤

### 1. 建一个群（推荐"自通知群"）
- 钉钉 → 发起群聊 → 选**你自己一个人**建群（命名如「FZH 数据通知」），或用一个你常用的运维群。

### 2. 添加自定义机器人
- 进入群 → 右上角「**...**」→「**智能群助手** / **群机器人**」→「**添加机器人**」→ 选「**自定义**」（通过 webhook 接入）。
- 机器人名称填如 `FZH-Data-Bot`，头像可选。
- **安全设置（三选一，推荐第 2 种）**：
  - **自定义关键词**：填一个词（如 `FZH`），Agent 发的消息必须包含该词。
  - **加签（推荐）**：系统生成一段 secret，请复制保存；Agent 发消息时需用它签名。
  - **IP 地址段**：填 Agent 出口 IP（一般未知，不推荐）。
- 点击「完成」，复制生成的 **Webhook 地址**（形如 `https://oapi.dingtalk.com/robot/send?access_token=xxxx`）。

### 3. （如贵司禁用了自定义机器人）后台开启
- 钉钉管理后台 <https://oa.dingtalk.com> → 工作台 / 安全 → 搜索「**自定义机器人**」→ 开启「允许成员添加自定义机器人」。
- 若按 IP 限制，把 Agent 所在服务器出口 IP 加入白名单（选「加签」可跳过此步）。

---

## 三、请把以下信息发回给我

- **Webhook 地址**：`（整串，含 access_token）`
- 若选了「**加签**」：**secret** `（整串）`
- 若选了「**关键词**」：**关键词** `（如 FZH）`

收到后我会立即用一条完成摘要做**连通性测试**（先发一条测试消息确认你能收到），确认无误后再正式推送。

---

## 四、安全与边界

- Webhook 等同"能往群里发消息的钥匙"，**不要公开到代码仓库或群聊之外**。
- Agent 仅在本地使用它，不会写入仓库；如需长期自动推送，我会把它存到本地 `.env`（已被 gitignore 保护，不会进仓）。
- 群机器人只能发**文本 / markdown / 链接**等，**不能直接发送本地 Excel 文件**；若想把汇总表 `.xlsx` 真发到钉钉，需要改用「工作通知 + 媒体上传」（需企业自建应用 `appKey`/`appSecret` + 你的 `userid`），可另行安排。
