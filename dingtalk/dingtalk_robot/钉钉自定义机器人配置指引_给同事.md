# 钉钉自定义机器人 + 文件附件发送 配置手册

> 两步走：**你自己**在钉钉建机器人；**你的 WorkBuddy** 用本项目的脚本上传文件并推送卡片。

---

## 第一步：你在钉钉创建机器人（不需要管理员）

### 1. 建一个只有你自己的群
- 钉钉 → 右上角 **+** → **发起群聊** → 只选你自己
- 群名随意，比如「WorkBuddy通知」

### 2. 添加自定义机器人
- 进入群 → 右上角 **...** → **机器人** → **添加机器人**
- 选 **「自定义（通过webhook接入自定义服务）」**
- 名称填 `WorkBuddy-Bot`，头像随意

### 3. 安全设置 — 选「加签」
- 勾选 **加签**，钉钉自动生成一段 secret
- **复制保存 secret 和 Webhook 地址**，后面要用
- 点 **完成**

### 4. 确认你有 ERPNext API Key
- 登录 [erpnext.vilavi.cn](https://erpnext.vilavi.cn)
- 右上角头像 → **My Settings** → **API Access**
- 如果已有 `api_key` / `api_secret`，记下来
- 如果没有，点 **Generate Keys** 生成

---

## 第二步：配置凭证

把以下内容填入你本机 fzh-data 项目的 `.env` 文件：

```bash
# 钉钉机器人（从第一步获取）
DINGTALK_WEBHOOK=https://oapi.dingtalk.com/robot/send?access_token=替换成你的
DINGTALK_SECRET=SEC替换成你的

# ERPNext API（从 ERPNext → My Settings → API Access 获取）
ERP_API_KEY=替换成你的
ERP_API_SECRET=替换成你的
```

---

## 第三步：让 WorkBuddy 发文件

**对你的 WorkBuddy 说：**

> 我在 fzh-data 项目的 `dingtalk/dingtalk_robot/` 目录下有三个脚本：
>
> - `send_file_card.py` — 上传文件到 ERPNext + 发钉钉 ActionCard
> - `upload_to_erpnext.py` — 只上传文件到 ERPNext，返回下载链接
> - `send_dingtalk.py` — 只发钉钉消息（markdown / ActionCard）
>
> `.env` 里已经配好了 `DINGTALK_WEBHOOK`、`DINGTALK_SECRET`、`ERP_API_KEY`、`ERP_API_SECRET`。
>
> 当你生成了 Excel 报表后，运行：
> ```bash
> cd dingtalk/dingtalk_robot && python send_file_card.py <报表文件路径> "标题" "正文内容"
> ```
>
> 就会自动上传文件到公司 ERPNext 服务器，并通过钉钉卡片推送给我，我点击卡片即可下载。
>
> 如果你想设置定时任务，用同样的命令定时执行即可。

---

## 安全提醒

- `.env` 不要提交到 git（项目已配置 `.gitignore`）
- Webhook、Secret、API Key 不要发到群里
- ERPNext API Key 是你个人账号的，权限仅限于你，比企业应用凭证安全
- 文件上传到公司自己的 ERPNext 服务器，不会传到公网第三方
