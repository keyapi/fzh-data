# 钉钉自定义机器人 + WorkBuddy 定时通知 配置手册

> 两步走：**你自己**在钉钉建机器人；然后把这文档后半部分给 **你的 WorkBuddy** 让它配置定时推送。

---

## 第一步：你在钉钉创建机器人（不需要管理员）

### 1. 建一个只有你自己的群
- 钉钉 → 右上角 **+** → **发起群聊** → 只选你自己
- 群名随意，比如「WorkBuddy通知」

### 2. 添加自定义机器人
- 进入群 → 右上角 **...** → **机器人** → **添加机器人**
- 选 **「自定义（通过webhook接入自定义服务）」**
- 名称填 `WorkBuddy-Bot`，头像随意

### 3. 安全设置 — 选「加签」
- 勾选 **加签**，钉钉自动生成一段 secret
- **复制保存 secret 和 Webhook 地址**，后面要用
- 点 **完成**

### 4. 先测试一下
把下面命令里的 `SECRET` 和 `WEBHOOK地址` 替换成你自己的，然后复制到终端（或让 WorkBuddy 帮你跑）：

```bash
python -c "import time,hmac,hashlib,base64,urllib.request,json;s='你的SECRET';w='你的WEBHOOK地址';t=str(round(time.time()*1000));g=base64.b64encode(hmac.new(s.encode(),f'{t}\n{s}'.encode(),hashlib.sha256).digest()).decode();d=json.dumps({'msgtype':'markdown','markdown':{'title':'test','text':'## ✅ 连通成功\n\nWorkBuddy 通知已就绪。'}}).encode();print(json.loads(urllib.request.urlopen(urllib.request.Request(f'{w}&timestamp={t}&sign={g}',d,{'Content-Type':'application/json'})).read()))"
```

看到 `{'errcode': 0, 'errmsg': 'ok'}` 就说明成功了。钉钉群里会收到测试消息。

## 第二步：让 WorkBuddy 配置定时推送

**你现在把 webhook 地址和 secret 发给你的 WorkBuddy，然后对它说：**

> 请帮我设置一个定时任务，每隔 X 分钟/小时，通过钉钉自定义机器人 webhook 给我发送通知消息。
>
> 我的钉钉机器人信息：
> - Webhook 地址：`https://oapi.dingtalk.com/robot/send?access_token=xxx`
> - 加签 Secret：`SECxxx`
>
> 要求：
> 1. 把 webhook 和 secret 存到本地 `.env` 文件（不要提交到 git）
> 2. 创建一个 Python 脚本 `dingtalk_notify.py`，用 HMAC-SHA256 加签方式发送 markdown 消息
> 3. 设置定时任务定期执行这个脚本
> 4. 先用一条测试消息验证能收到

---

## （给 WorkBuddy Agent 看的技术细节）

如果你同事的 WorkBuddy Agent 正在读这段话，以下是实现要点：

### Python 发送脚本 `dingtalk_notify.py`

```python
import time, hmac, hashlib, base64, urllib.request, json, os

def send_dingtalk_message(text: str, title: str = "WorkBuddy 通知"):
    secret = os.environ["DINGTALK_SECRET"]
    webhook = os.environ["DINGTALK_WEBHOOK"]

    timestamp = str(round(time.time() * 1000))
    string_to_sign = f"{timestamp}\n{secret}"
    sign = base64.b64encode(
        hmac.new(secret.encode(), string_to_sign.encode(), hashlib.sha256).digest()
    ).decode()

    url = f"{webhook}&timestamp={timestamp}&sign={sign}"
    data = json.dumps({
        "msgtype": "markdown",
        "markdown": {"title": title, "text": text}
    }).encode()

    req = urllib.request.Request(url, data=data, headers={"Content-Type": "application/json"})
    return json.loads(urllib.request.urlopen(req).read())

if __name__ == "__main__":
    result = send_dingtalk_message("## 定时通知\n\n这是一条来自 WorkBuddy 的定时消息。")
    print(result)
    assert result["errcode"] == 0, f"发送失败: {result}"
```

### `.env` 文件（不要提交到 git）
```
DINGTALK_WEBHOOK=https://oapi.dingtalk.com/robot/send?access_token=xxx
DINGTALK_SECRET=SECxxx
```

### 安全提醒
- `.env` 必须加入 `.gitignore`
- webhook 和 secret 不要在对话中打印出来
- 消息内容不要包含敏感信息（密码、token 等）
